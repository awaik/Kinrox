# Kinrox milestone and release history

Chronological status log moved from [AGENTS.md](../../AGENTS.md) on 2026-11-12 to keep the
agent context small. Entries are historical records; current rules and owner decisions live
in AGENTS.md. Each release adds one entry at the end, in the same style.

Section references (for example "Section 3.5") point to AGENTS.md.

- M1 implemented 2026-10-25: libmpv + OpenGL, opening via ⌘O, playback of MP4/MKV, events and clean teardown. MPVKit placed inside PlayerMac with bridging header per owner confirmation. Checks and limitations — [M1 Report](../runbooks/M1-VERIFICATION.md).
- M2 implemented 2026-10-26 in design from Figma: controls panel, shortcuts, fullscreen, drag-and-drop, menus, recent files, folder playlist and auto-advance. Remote screens (M5) built in advance on demo data, without network; server and protocol — M4.
- M3 implemented 2026-10-26: MediaPlayer system commands, "Now Playing", artwork, and teardown cleanup. Automated tests and manual limits — [M3 Report](../runbooks/M3-VERIFICATION.md).
- M4.1 implemented 2026-10-26 and handed off for review: message models, JSON codec, version negotiation, and reference JSON fixtures. Checks — [M4.1 Report](../runbooks/M4.1-VERIFICATION.md).
- M4.2 implemented 2026-10-26 after dedicated specification approval (§6.5.1): CryptoKit, handshake state machines, protected frames, and independent test vectors. Checks — [M4.2 Report](../runbooks/M4.2-VERIFICATION.md).
- M4.3 implemented 2026-10-26 after M4.2 review: Bonjour, Network.framework WebSocket, secure exchange, heartbeat, and local subnet enforcement. Player integration — M4.4; [M4.3 Report](../runbooks/M4.3-VERIFICATION.md).
- M4.4 implemented 2026-10-27: server connected to player, remote preferences and real PIN, tokens in Data Protection Keychain. Team signing with macOS profile configured, pairing and revocation verified. Results and limitations — [M4.4 Report](../runbooks/M4.4-VERIFICATION.md). M4 accepted by owner task assignment for M5 on 2026-10-27; transition authorized.
- M4 completed in scope M4.1–M4.4. By owner decision 2026-10-27 `kinrox-cli` (former M4.5) moved to [a separate optional task](../TODO/05-kinrox-cli.md); its absence does not block M6 or app release.
- M5 implemented 2026-10-27: real remote, Bonjour, Keychain, control, and reconnection. Automated tests passed; owner confirmed manual checklist of Mac + physical iPhone: "Double-checked everything, everything works." Results and remaining limitations — [M5 Report](../runbooks/M5-VERIFICATION.md).
- M6 release workflow implemented 2026-10-28: pinned portable libmpv dependencies, Developer ID export, library signing, notarization, stapling, DMG, dependency sources, and checksums. First Mac version: 0.1.0, Apple Silicon, macOS 14+. Procedure and validation boundaries — [release runbook](../runbooks/RUNBOOK-RELEASE.md), [release notes](0.1.0.md). iPhone App Store publication is separate.
- Mac track selection implemented 2026-10-29 after owner approval of Figma page 04: audio/subtitle selectors, recursive external-track discovery, search scope, and folder preferences. Included in Mac release 0.2.0, build 4, requested by the owner on 2026-10-29. Checks — [Tracks Verification](../runbooks/TRACKS-VERIFICATION.md); [release notes](0.2.0.md).
- Mac update reminders implemented 2026-10-29 after owner approval of Figma page 05: Sparkle 2 with gentle reminders — welcome banner, paused-player pill, and "Check for Updates…" with a version badge; Sparkle's standard windows download and install. The HTTPS appcast is an approved exception to principle 4. Released in Mac 0.3.0 (build 5) on 2026-10-30; users of earlier versions install this first checker build manually once. Checks — [Updates Verification](../runbooks/UPDATES-VERIFICATION.md).
- Tasks for contributors (M3, M4, localization, updates) — in [docs/TODO](../TODO/).
