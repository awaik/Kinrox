# Kinrox 0.1.0

First downloadable Mac release. Requires an **Apple Silicon Mac with macOS 14
Sonoma or later**. Intel Macs are not supported.
Version 0.1.0, build 3.

Download `Kinrox-0.1.0-arm64.dmg`, open it, and drag Kinrox to Applications.
The app is Developer ID signed and notarized by Apple. All playback libraries
are bundled; Homebrew and Xcode are not needed to use the player.

- Local MP4, MKV, MOV, M4V, AVI, WebM, and TS playback with libmpv.
- Hardware decoding, fullscreen, keyboard shortcuts, and system media keys.
- Recent files, folder playlists, and automatic next-file playback.
- Encrypted local-network control from the companion iPhone app.
- Interface translations in 30 languages, with English fallback.

The iPhone remote is currently available to build from source. Its App Store
release is separate. The Mac player works on its own.

This release does not include track selectors, playback-position memory, network
streams, Intel support, or automatic updates.

Validation: 118 protocol/transport tests and 69 Mac tests passed. Mac tests were
repeated against the bundled library versions and include video decoding,
rendering, fullscreen transitions, remote pairing, and real Keychain access.
Packaging tests verify transitive relocation, independent execution, missing
dependencies, overwrite protection, and rejection of incompatible OS versions.
The signed-app startup regression reproduced a Hardened Runtime crash from mpv's
unused built-in Lua scripts. Those scripts are disabled; the release requires no
JIT, unsigned executable memory, or library-validation exemptions.
Runtime verification was performed on macOS 26.5.2; macOS 14 is the deployment
target and has not been tested on a separate Mac in this release session.

`Kinrox-0.1.0-dependency-sources.tar.gz` contains the corresponding sources,
build recipes, and patches for bundled dependencies. Licenses are also included
inside the app. `SHA256SUMS.txt` provides release-asset checksums.
