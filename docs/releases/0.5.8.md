# Kinrox 0.5.8

Mac player release for Apple Silicon (arm64), macOS 14 or newer.
Released together with Kinrox Remote 0.2.2 for iPhone.

## What's New

- **Similar from your iPhone.** Kinrox Remote 0.2.2 can start and stop Similar on the Mac. Starting keeps the current track and tracks you added yourself, replaces the remaining source tracks with similar ones and keeps topping up the queue. Stop keeps what was already added.
- **Not interested from your iPhone.** While Similar runs, the remote can hide a track or its artist. The Mac removes matching upcoming tracks and skips a matching current track; Undo removes the exclusion.
- **Get the iPhone remote.** The Connect iPhone window and Settings → Remote show a QR code and an Open in App Store link for Kinrox Remote. Help → Kinrox Remote for iPhone… opens them. The QR code is generated on the Mac and makes no network request.
- **Lock Screen controls on iPhone.** Kinrox Remote 0.2.2 adds pause, previous/next or ±10 seconds and volume to the iPhone Lock Screen. No Mac setting is needed.

## Requirements and Notes

- macOS 14.0 or newer on Apple Silicon (arm64).
- Older remotes keep working with this Mac release; Similar controls on the iPhone require Kinrox Remote 0.2.2. A remote talking to an older Mac explains that the Mac needs an update.
- Standalone Spotify playback continues to use separately downloaded Spotify Soloist, with Spotify.app fully closed. Spotify Premium, your own Client ID, a Soloist API key and one-time phone pairing are required; Soloist is not bundled with Kinrox.
- Runtime verification is limited to macOS 26.5.2 (Apple Silicon). Minimum-OS metadata is checked for bundled binaries; no separate macOS 14 runtime test was performed.
- Automated checks, notarization and mounted-app startup evidence are recorded in [Mac 0.5.8 Verification](../runbooks/0.5.8-VERIFICATION.md).
- To install manually, open `Kinrox-0.5.8-arm64.dmg` and drag `Kinrox.app` to `Applications`. Existing installations of Kinrox 0.3.0 or newer can also update through `Kinrox → Check for Updates…`.
- `Kinrox-0.5.8-dependency-sources.tar.gz` contains corresponding sources, build recipes, patches and license texts for bundled open-source libraries. `SHA256SUMS.txt` lists release-asset checksums.
