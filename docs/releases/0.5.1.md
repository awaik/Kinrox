# Kinrox 0.5.1

Mac player release for Apple Silicon (arm64), macOS 14 or newer.
The companion iPhone remote is not published to the App Store in this release.

## What's New

- **Audible standalone Spotify playback by default.** Newly configured Soloist engines start at 100% Kinrox volume instead of muted `0%`, and persist volume adjustments across sessions so starting a track plays audibly right away.
- **Music setup and consent recovery.** Installing the Soloist engine from Settings now records current Spotify document consent when credentials are saved, and startup recovery surfaces actionable `Settings` or `Retry` actions whenever account restoration or engine setup is incomplete.
- **Cached queue playlist filtering.** Hydrating the local SQLite library cache on launch now excludes the private `Kinrox Queue` playlist from user playlist sidebars, matching live Spotify refreshes.
- **Stable window traffic-light controls.** Hovering the close, minimize, or zoom buttons—or moving into the top titlebar area—keeps the window controls visible, prevents the pointer-exit timer from hiding them under the cursor, and immediately reveals them when hidden during video playback.

## Included in 0.5.1

- Standalone Spotify playback through separately downloaded **Spotify Soloist**, with `Spotify.app` fully closed, plus local queue management, favorites with undo, and encrypted LAN iPhone remote controls.
- Local video playback for MP4, MKV, MOV, M4V, AVI, WebM, and TS powered by bundled libmpv 0.41.0, FFmpeg 9.0.1, OpenGL, and VideoToolbox hardware acceleration.
- Audio and subtitle track selection, recursive external subtitle/audio discovery, and per-folder track preferences.
- Matrix screensaver (`Screensaver → Matrix`) and Sparkle 2 update reminders (`Kinrox → Check for Updates…`).
- Shared localization in 30 languages with English fallback.

## Requirements and Notes

- macOS 14.0 or newer on Apple Silicon (arm64).
- Runtime verification for this release was performed on macOS 26.5.2 (Apple Silicon). Minimum-OS metadata was verified for all bundled binaries; a separate macOS 14 machine was not tested.
- To install manually, open `Kinrox-0.5.1-arm64.dmg` and drag `Kinrox.app` to `Applications`. Existing installations of Kinrox 0.3.0 or newer can also update through `Kinrox → Check for Updates…`.
- `Kinrox-0.5.1-dependency-sources.tar.gz` contains the corresponding source archives, build recipes, patches, and license texts for the bundled open-source libraries.
- `SHA256SUMS.txt` lists SHA-256 checksums for the release assets.
