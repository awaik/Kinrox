# Kinrox 0.4.2

Welcome-screen layout fixes and faster Spotify library and playback controls.
Requires an **Apple Silicon Mac with macOS 14 Sonoma or later**.
Version 0.4.2, build 8.

Download `Kinrox-0.4.2-arm64.dmg`, open it, and drag Kinrox to Applications.
All video playback libraries are bundled; Homebrew and Xcode are not required.
Users of 0.3.0 or later can use Check for Updates.

## Fixed

- Recent files could widen the welcome screen beyond the window, pushing its
  heading, Open File button and Show all action off-screen. The grid now uses
  its actual column width, and the decorative glow no longer widens small windows.
- A regression test checks empty, single-file and longer recent lists while
  shrinking and growing the same window between 640 and 1440 points.

## Spotify improvements

- A local SQLite metadata cache restores the library progressively and reduces
  repeated loading. It stores metadata only, expires unvalidated resources after
  seven days, is limited to 100 MiB, and is removed on disconnect.
- Library indexing, shared requests and request priorities reduce repeated work
  and let playback controls take precedence over background library loading.
- Resume and unchanged-order track changes avoid rewriting the private queue.
  Manual queue insertion preserves playback; paused edits do not start music.
- A local clock advances playback progress. Kinrox checks after commands and at
  the expected track boundary instead of continuously polling Spotify.
- Updated connection terms and privacy disclosures explain the cache in all
  30 languages. Existing users must accept the new terms before reconnecting.

Spotify setup remains as described in the [0.4.0 release notes](0.4.0.md).
Changes made directly in Spotify are observed on the next Kinrox command or
expected track boundary. The companion iPhone app is released separately.

## Compatibility and verification

The welcome-screen regression failed before the fix and passed afterward;
rendered normal and narrow windows were inspected. The Mac suite passed with
220 tests in 44 suites using both development and portable release libraries.
Music-package tests (36), protocol/transport
tests (126), release-tooling tests (46), localization and generated-site checks
also passed. Live Spotify and optional Music screenshot tests are opt-in and
were not enabled.

The app and DMG passed Apple notarization. The mounted app passed signature,
Gatekeeper, stapling and bundled-library verification. Its actual welcome screen,
synthetic MP4/MKV playback, pause, seeking and fullscreen entry/exit were checked
interactively with Kinrox volume set to zero. Automated tests cover secure remote
pairing; no new interactive pairing check was performed.

Verification uses macOS 26.5.2. macOS 14 remains the deployment minimum;
live Spotify playback and a physical iPhone have not been rechecked for this
release. Detailed cache behavior, synthetic measurements and limitations are
recorded in the [performance report](../runbooks/SPOTIFY-PERFORMANCE-VERIFICATION.md).

`Kinrox-0.4.2-dependency-sources.tar.gz` contains dependency sources, build recipes
and patches. Licenses are included in the app. `SHA256SUMS.txt` provides asset
checksums; matching application source is available at tag `v0.4.2`.
