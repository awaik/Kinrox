# Kinrox 0.5.5

Mac player release for Apple Silicon (arm64), macOS 14 or newer.
The companion iPhone remote is not published to the App Store in this release.

## What's New

- **Spotify v3 three-column navigation and drill-down.** Renamed the mode tab to **Spotify**, redesigned the left sidebar with full-column drill-down (`Show all →` and `‹ Back to library`), inline filtering, playlist ownership filters (`All`, `Mine`, `Subscribed`), and thematic playlist discovery (`#Cosmic`, `#Harp`, `#Psybient`, `#Techno`), and replaced the static middle album list with a dynamic workspace (`TrackTable`, `AlbumsWorkspaceView` with expandable album cards, and `DiscoveryWorkspaceView`).
- **Persistent compact queue with drag-and-drop expansion.** Added a dedicated right-hand `CompactQueueColumn` displaying `Now Playing`, `Added manually` (`Clear manual`), and `From the source list`. Tracks, albums, and owned/collaborative playlists can be dropped at any position or at the tail of the queue (automatically expanding albums and playlists into playable tracks), reordered via drag handles or hover `↑`/`↓` buttons, or removed with one click (`×`).
- **Similar & Discovery engine.** Added `Similar & discovery` (`✦ Similar`) seeded by any track, album, playlist, or artist, with `Same spirit`, `Underground` (`tag:hipster`), and `Fresh` (`tag:new`) album discovery modes, `Hide liked` filtering, genre chips, `Mixes & compilations` cards (`appears_on` and `compilation` releases), and `Why this track` recommendation badges.
- **Clear handling of subscribed playlist restrictions and search filters.** Subscribed playlists owned by other users remain visible in the library while surfacing a clear notice and `Open in Spotify` link when Spotify's Development Mode API restricts `/playlists/{id}/items`. Global Spotify searches now reset local collection filters, single-album artist/search views keep the album selector visible and preload tracks, and all 25 new UI strings are localized across all 30 supported languages.

## Included in 0.5.5

- Standalone Spotify playback through separately downloaded **Spotify Soloist**, with `Spotify.app` fully closed, plus local queue management, favorites with undo, artist/album popovers, per-collection sorting, and encrypted LAN iPhone remote controls.
- Local video playback for MP4, MKV, MOV, M4V, AVI, WebM, and TS powered by bundled libmpv 0.41.0, FFmpeg 9.0.1, OpenGL, and VideoToolbox hardware acceleration.
- Audio and subtitle track selection, recursive external subtitle/audio discovery, and per-folder track preferences.
- Matrix screensaver (`Screensaver → Matrix`) and Sparkle 2 update reminders (`Kinrox → Check for Updates…`).
- Shared localization in 30 languages with English fallback.

## Requirements and Notes

- macOS 14.0 or newer on Apple Silicon (arm64).
- Runtime verification for this release was performed on macOS 26.5.2 (Apple Silicon). Minimum-OS metadata was verified for all bundled binaries; a separate macOS 14 machine was not tested.
- To install manually, open `Kinrox-0.5.5-arm64.dmg` and drag `Kinrox.app` to `Applications`. Existing installations of Kinrox 0.3.0 or newer can also update through `Kinrox → Check for Updates…`.
- `Kinrox-0.5.5-dependency-sources.tar.gz` contains the corresponding source archives, build recipes, patches, and license texts for the bundled open-source libraries.
- `SHA256SUMS.txt` lists SHA-256 checksums for the release assets.
