# Kinrox 0.5.13

Mac player release for Apple Silicon (arm64), macOS 14 or newer.

## What's New

- **Much lower startup and idle memory.** Kinrox now creates its video engine and OpenGL context only when you actually start watching a video, instead of at launch. When you open Kinrox in Home or listen to Spotify or local music, idle memory drops roughly in half.
- **Flat memory during long viewing sessions.** Fixed an OpenGL fence leak inside the video rendering bridge that caused memory to grow continuously during long playback sessions on Apple Silicon.
- **Automatic parking for hidden paused videos.** If a video stays paused in the background or behind Home for 30 minutes, Kinrox releases the video engine and restores your exact position, end-of-file state and selected audio or subtitle tracks (including external subtitle files and Off) seamlessly when you return. A visible paused video keeps its current frame on screen.
- **Lighter media caches and cleaner Spotify sessions.** Local video and audio demuxer caches are now bounded to trim peak RAM usage without affecting responsiveness, and Soloist releases its WebSocket URLSession cleanly when playback stops.

## Requirements and Notes

- macOS 14.0 or newer on Apple Silicon (arm64).
- Standalone Spotify playback continues to use separately downloaded Spotify Soloist, with Spotify.app fully closed. Spotify Premium, your own Client ID, a Soloist API key and one-time phone pairing are required; Soloist is not bundled with Kinrox.
- Runtime verification is limited to macOS 26.5.2 (Apple Silicon). Minimum-OS metadata is checked for bundled binaries; no separate macOS 14 runtime test was performed.
- Automated checks, memory measurements, notarization and mounted-app evidence are recorded in [Mac 0.5.13 Verification](../runbooks/0.5.13-VERIFICATION.md).
- To install manually, open `Kinrox-0.5.13-arm64.dmg` and drag `Kinrox.app` to `Applications`. Existing installations of Kinrox 0.3.0 or newer can also update through `Kinrox → Check for Updates…`.
- `Kinrox-0.5.13-dependency-sources.tar.gz` contains corresponding sources, build recipes, patches and license texts for bundled open-source libraries. `SHA256SUMS.txt` lists release-asset checksums.
