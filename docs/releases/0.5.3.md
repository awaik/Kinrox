# Kinrox 0.5.3

Mac player release for Apple Silicon (arm64), macOS 14 or newer.
Companion iPhone remote 0.2.1 (build 3) is delivered to TestFlight; App Store publication remains separate.

## What's New

- **Active music transport controls on launch.** Restoring a cached Spotify library on startup now enables the configured standalone Soloist engine once the saved setup, credentials, and consent are verified, instead of leaving transport controls disabled until Settings is opened.
- **Reliable track-end progression and near-EOF seeking.** Soloist occurrence state preserves natural track completion when final buffering is followed by an autoplay context timeout, without latching premature pause state on normal near-end progress frames or blocking pause and seek commands near the end of a track.
- **Stable iPhone remote connection across mode and window changes.** Switching between Music and Video modes when device volume is not yet confirmed no longer produces an invalid LAN state frame, and closing the Mac player window publishes an idle remote snapshot consistent with command availability.

## Included in 0.5.3

- Standalone Spotify playback through separately downloaded **Spotify Soloist**, with `Spotify.app` fully closed, plus local queue management, favorites with undo, artist/album popovers, per-collection sorting, and encrypted LAN iPhone remote controls.
- Local video playback for MP4, MKV, MOV, M4V, AVI, WebM, and TS powered by bundled libmpv 0.41.0, FFmpeg 9.0.1, OpenGL, and VideoToolbox hardware acceleration.
- Audio and subtitle track selection, recursive external subtitle/audio discovery, and per-folder track preferences.
- Matrix screensaver (`Screensaver → Matrix`) and Sparkle 2 update reminders (`Kinrox → Check for Updates…`).
- Shared localization in 30 languages with English fallback.

## Requirements and Notes

- macOS 14.0 or newer on Apple Silicon (arm64).
- Runtime verification for this release was performed on macOS 26.5.2 (Apple Silicon). Minimum-OS metadata was verified for all bundled binaries; a separate macOS 14 machine was not tested.
- To install manually, open `Kinrox-0.5.3-arm64.dmg` and drag `Kinrox.app` to `Applications`. Existing installations of Kinrox 0.3.0 or newer can also update through `Kinrox → Check for Updates…`.
- `Kinrox-0.5.3-dependency-sources.tar.gz` contains the corresponding source archives, build recipes, patches, and license texts for the bundled open-source libraries.
- `SHA256SUMS.txt` lists SHA-256 checksums for the release assets.
