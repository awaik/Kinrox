# Kinrox 0.5.2

Mac player release for Apple Silicon (arm64), macOS 14 or newer.
The companion iPhone remote is not published to the App Store in this release.

## What's New

- **Lower Music CPU and memory footprint.** The playback clock now ticks at 1 Hz aligned to whole seconds, pauses when the player window is hidden or occluded, and uses a native SwiftUI capsule slider instead of AppKit `NSSlider`. The source sidebar uses `LazyVStack` and lighter row modifiers, eliminating eager instantiation of off-screen artist and playlist rows.
- **`Added` column and per-collection track sorting.** Liked Songs and Playlists now display the date each track was added (`Added`) and support sorting by track number, title, artists, album, date added, or duration, with sort order remembered independently per collection.
- **Interactive artist and album popovers.** Clicking an artist or album name in the track table or player deck opens a metadata popover with follower/save toggles, release details, and direct navigation to the artist or album inside Kinrox or in Spotify.
- **Persisted browsing state and immediate favorite updates.** Kinrox restores your selected source, album, and focused track across launches, updates favorite icons immediately on click while keeping unliked rows visible in Liked Songs until navigation or refresh, and refreshes collection contents after confirmed mutations.

## Included in 0.5.2

- Standalone Spotify playback through separately downloaded **Spotify Soloist**, with `Spotify.app` fully closed, plus local queue management, favorites with undo, and encrypted LAN iPhone remote controls.
- Local video playback for MP4, MKV, MOV, M4V, AVI, WebM, and TS powered by bundled libmpv 0.41.0, FFmpeg 9.0.1, OpenGL, and VideoToolbox hardware acceleration.
- Audio and subtitle track selection, recursive external subtitle/audio discovery, and per-folder track preferences.
- Matrix screensaver (`Screensaver → Matrix`) and Sparkle 2 update reminders (`Kinrox → Check for Updates…`).
- Shared localization in 30 languages with English fallback.

## Requirements and Notes

- macOS 14.0 or newer on Apple Silicon (arm64).
- Runtime verification for this release was performed on macOS 26.5.2 (Apple Silicon). Minimum-OS metadata was verified for all bundled binaries; a separate macOS 14 machine was not tested.
- To install manually, open `Kinrox-0.5.2-arm64.dmg` and drag `Kinrox.app` to `Applications`. Existing installations of Kinrox 0.3.0 or newer can also update through `Kinrox → Check for Updates…`.
- `Kinrox-0.5.2-dependency-sources.tar.gz` contains the corresponding source archives, build recipes, patches, and license texts for the bundled open-source libraries.
- `SHA256SUMS.txt` lists SHA-256 checksums for the release assets.
