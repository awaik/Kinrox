# Kinrox 0.3.0

Matrix screensaver, live folder playlists, and update reminders for Mac.
Requires an **Apple Silicon Mac with macOS 14 Sonoma or later**.
Version 0.3.0, build 5.

Download `Kinrox-0.3.0-arm64.dmg`, open it, and drag Kinrox to Applications.
All playback libraries are bundled; Homebrew and Xcode are not required.

## New

- **Matrix screensaver:** choose Screensaver → Matrix. A playing movie pauses
  before the falling green code appears. Esc returns to the paused movie without
  leaving fullscreen. Matrix also works with no video open.
- **Live folder playlists:** newly available videos appear in Next/Previous
  navigation without reopening the current file. Changes also reach the iPhone
  remote and system media controls. Playback position is preserved.
- **Update reminders:** Kinrox checks for updates daily and offers a welcome-screen
  banner, a compact reminder while paused, and Check for Updates in the app menu.
  Sparkle verifies and installs updates when you choose to update.
- **Project links:** the About panel and Help menu link to the website, source,
  license, support, issue tracker, and privacy policy.

## Reliability

- Matrix waits for the playback engine to confirm pause. Remote start requests
  report errors or cancellation instead of acknowledging an unconfirmed start.
- Starting Matrix dismisses the Connect iPhone card; pairing cards retain Esc priority.
- Folder watching recovers after directory replacement or temporary unavailability,
  and checks for new episodes at the end of playback.
- Release startup verification leaves Sparkle's saved update preferences untouched.

## Updating from 0.2.0

Versions 0.2.0 and earlier have no built-in updater. Install 0.3.0 manually once;
subsequent releases can be offered inside the player.

Playback and remote commands stay on the local network. Update checks read an
HTTPS feed on GitHub Pages without unique identifiers, system profiling, or
telemetry. Installing an update downloads its signed DMG from GitHub Releases.
See the [privacy policy](https://awaik.github.io/Kinrox/privacy/).

This is a Mac release. The iPhone App Store release is separate; Matrix remote
controls require a companion build with the Screensavers section.

Runtime verification targets macOS 26.5.2. macOS 14 is the deployment target;
a separate macOS 14 machine was not used for this release.

`Kinrox-0.3.0-dependency-sources.tar.gz` contains corresponding dependency sources,
build recipes, and patches. Licenses are included inside the app.
`SHA256SUMS.txt` provides release-asset checksums. The matching application source
is available at the `v0.3.0` tag.
