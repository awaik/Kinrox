# Kinrox 0.2.0

Choose audio and subtitle tracks directly on your Mac, including external files
stored in nested folders. Requires an **Apple Silicon Mac with macOS 14 Sonoma
or later**. Version 0.2.0, build 4.

Download `Kinrox-0.2.0-arm64.dmg`, open it, and drag Kinrox to Applications.
The app is Developer ID signed and notarized by Apple. All playback libraries
are bundled; Homebrew and Xcode are not required.

## New

- Audio and subtitle selectors in the controls bar and native menus, with language,
  title, codec, and channel details. Subtitles can be turned Off.
- Recursive discovery of external audio and subtitle files, with a searchable
  browser, manual loading, and a configurable search folder.
- Per-folder preferences that restore the selected language or release group
  when moving to the next episode. Subtitle Off is remembered as well.
- Control-Command-A and Control-Command-S shortcuts to cycle tracks.
- Translated track controls in all 30 supported interface languages.

## Reliability

- Track preferences retain bracketed studio/type labels and handle explicit
  episode numbers in metadata without confusing numbered studios or channel layouts.
- Refreshing or changing the search folder retries unavailable preferences while
  preserving successful and manual choices.
- Enabling remembering saves the user's previously confirmed selection.
- Symlink paths resolve consistently for preferences and external track details.
- Track file dialogs close when playback changes to another video; file choosers
  cannot overlap. Folder filters recover when a scanned folder disappears.

Track selection is currently a Mac feature. The iPhone remote protocol is unchanged;
this release does not publish a new iPhone app. Network streams, playback-position
memory, Intel Macs, and automatic updates remain outside this release.

Validation: 89 Mac tests against the bundled library versions, 118 protocol/transport
tests, 48 iPhone simulator tests, and 13 packaging/workflow tests passed.
The final DMG passed mounted-app signature, Gatekeeper, startup, playback,
track-selection, and local remote-control checks. See the
[verification report](../runbooks/0.2.0-VERIFICATION.md).

Runtime verification was performed on macOS 26.5.2. macOS 14 is the deployment
target and was not tested on a separate Mac during this release.

`Kinrox-0.2.0-dependency-sources.tar.gz` contains corresponding dependency sources,
build recipes, and patches. Licenses are also included inside the app.
`SHA256SUMS.txt` provides release-asset checksums. The matching application source
is available at the `v0.2.0` tag.
