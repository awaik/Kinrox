# Kinrox 0.5.9

Mac player release for Apple Silicon (arm64), macOS 14 or newer.

## What's New

- **Lighter and smoother Similar.** Finding similar music now ranks large libraries with an indexed pass instead of comparing every track with every other one, builds large previews off the main thread, keeps fewer disposable results in memory and creates row tooltips only when needed. The interface stays responsive while Similar works, and memory no longer spikes during startup with a big library.
- **Not interested from your iPhone, without side effects.** Hiding a track or artist from the remote, or undoing it, while the Mac is not showing Spotify no longer leaves Similar empty or partly filled when you return; results refresh when you open the view.
- **Better duplicate detection.** A song that appears both on a compilation and on its original album is recognised as the same recording, so Similar does not suggest it twice.
- **Accessibility.** Icon-only buttons in the library, album and Similar lists have VoiceOver labels again, and moving the pointer quickly between rows no longer leaves the wrong row highlighted.
- **View → Spotify with the window closed** no longer starts hidden background work; Similar refreshes when the window opens.

## Requirements and Notes

- macOS 14.0 or newer on Apple Silicon (arm64).
- The remote protocol is unchanged: Kinrox Remote 0.2.2 and older remotes keep working with this release.
- Standalone Spotify playback continues to use separately downloaded Spotify Soloist, with Spotify.app fully closed. Spotify Premium, your own Client ID, a Soloist API key and one-time phone pairing are required; Soloist is not bundled with Kinrox.
- Runtime verification is limited to macOS 26.5.2 (Apple Silicon). Minimum-OS metadata is checked for bundled binaries; no separate macOS 14 runtime test was performed.
- Automated checks, measurements, notarization and mounted-app startup evidence are recorded in [Mac 0.5.9 Verification](../runbooks/0.5.9-VERIFICATION.md).
- To install manually, open `Kinrox-0.5.9-arm64.dmg` and drag `Kinrox.app` to `Applications`. Existing installations of Kinrox 0.3.0 or newer can also update through `Kinrox → Check for Updates…`.
- `Kinrox-0.5.9-dependency-sources.tar.gz` contains corresponding sources, build recipes, patches and license texts for bundled open-source libraries. `SHA256SUMS.txt` lists release-asset checksums.
