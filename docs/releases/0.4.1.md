# Kinrox 0.4.1

Spotify playback reliability and fullscreen video fixes.
Requires an **Apple Silicon Mac with macOS 14 Sonoma or later**.
Version 0.4.1, build 7.

Download `Kinrox-0.4.1-arm64.dmg`, open it, and drag Kinrox to Applications.
All video playback libraries are bundled; Homebrew and Xcode are not required.
Users of 0.3.0 or later can use Check for Updates.

## Fixed

- A delayed Spotify poll response could overwrite the state of a completed playback
  command or stop further polling. Superseded responses and errors are now ignored;
  current playback failures still report normally.
- Fullscreen video now fills the window without reserving space for the Video/Music
  mode picker. The picker returns when leaving fullscreen, preserving the video view.

## Compatibility and verification

Spotify setup and features remain as described in the [0.4.0 release notes](0.4.0.md).
The SQLite cache and playback-latency work is a reviewed implementation plan and is
not included in this release. The companion iPhone app is released separately.

Release verification uses macOS 26.5.2. macOS 14 remains the deployment minimum;
live Spotify playback and a physical iPhone have not been rechecked for this patch.
The full Mac suite passed on rerun (183 tests; two intentionally skipped), alongside
27 music-package tests, 126 protocol/transport tests, and 45 release-tooling tests.
The first Mac run encountered a Matrix transport disconnection; that suite passed
in isolation and the subsequent full run passed. Localization and formatting checks
also passed.

Both the app and DMG passed Apple notarization. The mounted app passed signature,
Gatekeeper, stapling and bundled-library checks, and its welcome window opened.
The additional interactive pairing/playback smoke check could not finish because
the computer-use tool became unavailable. Automated Mac tests cover pairing,
playback and the fullscreen layout regression.

`Kinrox-0.4.1-dependency-sources.tar.gz` contains dependency sources, build recipes
and patches. Licenses are included in the app. `SHA256SUMS.txt` provides asset
checksums; matching application source is available at tag `v0.4.1`.
