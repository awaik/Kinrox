# Kinrox 0.5.10

Mac player release for Apple Silicon (arm64), macOS 14 or newer.

## What's New

- **Make Kinrox your default video player.** A new card at the top of Settings opens MOV, MP4, M4V, MKV, WebM, AVI and TS files in Kinrox with a double-click in Finder, in one click. It shows which formats still open in other apps and changes only those. Nothing changes until you press the button; you can switch back any time in Finder (Get Info → Open with → Change All).
- **No more "Apple could not verify … is free of malware" for your own videos.** macOS shows this warning when a downloaded video, or a screen recording saved by QuickTime, is set to open in another app through "Open With" for that one file. Opening it through the default player avoids the warning, so making Kinrox the default lets such videos play right away.

## Requirements and Notes

- macOS 14.0 or newer on Apple Silicon (arm64).
- The remote protocol is unchanged: Kinrox Remote 0.2.2 and older remotes keep working with this release.
- Standalone Spotify playback continues to use separately downloaded Spotify Soloist, with Spotify.app fully closed. Spotify Premium, your own Client ID, a Soloist API key and one-time phone pairing are required; Soloist is not bundled with Kinrox.
- Runtime verification is limited to macOS 26.5.2 (Apple Silicon). Minimum-OS metadata is checked for bundled binaries; no separate macOS 14 runtime test was performed.
- Automated checks, notarization and mounted-app evidence are recorded in [Mac 0.5.10 Verification](../runbooks/0.5.10-VERIFICATION.md).
- To install manually, open `Kinrox-0.5.10-arm64.dmg` and drag `Kinrox.app` to `Applications`. Existing installations of Kinrox 0.3.0 or newer can also update through `Kinrox → Check for Updates…`.
- `Kinrox-0.5.10-dependency-sources.tar.gz` contains corresponding sources, build recipes, patches and license texts for bundled open-source libraries. `SHA256SUMS.txt` lists release-asset checksums.
