# Kinrox 0.5.12

Mac player release for Apple Silicon (arm64), macOS 14 or newer.

## What's New

- **Your Mac library, ready for the iPhone remote.** Kinrox on the Mac can now share its Home media library with Kinrox Remote: Continue Watching, movies and series, local albums and tracks, search, posters and album covers, and starting or resuming playback from the phone. Videos started from the remote open in the normal player window, not fullscreen, and pause whatever else is playing. Items on a disconnected drive stay visible but cannot be started. Only opaque identifiers, titles and catalog details are sent; file paths never leave your Mac. A Kinrox Remote update will use this; the current remote keeps working exactly as before.
- **Local music for newer remotes.** For remotes that support the media library, local music on your Mac appears as music with its queue, shuffle and repeat, track format and cover, instead of looking like a video.
- **Steadier remote connection.** An iPhone connection is no longer dropped when a network update reports the Mac's Bonjour service name instead of a resolved address; the address approved when the phone connected is checked instead.
- **Lighter when no phone is connected.** The library is indexed for the remote only while a remote is connected and released when it disconnects, so Kinrox uses no extra memory when you don't use the remote.

## Requirements and Notes

- macOS 14.0 or newer on Apple Silicon (arm64).
- The remote protocol gains an additive extension (`library.v1`). Kinrox Remote 0.2.2 and older remotes, including Lock Screen controls, keep working unchanged with this release; for them local music on Mac is still shown as before.
- Standalone Spotify playback continues to use separately downloaded Spotify Soloist, with Spotify.app fully closed. Spotify Premium, your own Client ID, a Soloist API key and one-time phone pairing are required; Soloist is not bundled with Kinrox.
- Runtime verification is limited to macOS 26.5.2 (Apple Silicon). Minimum-OS metadata is checked for bundled binaries; no separate macOS 14 runtime test was performed.
- Automated checks, performance measurements, notarization and mounted-app evidence are recorded in [Mac 0.5.12 Verification](../runbooks/0.5.12-VERIFICATION.md).
- To install manually, open `Kinrox-0.5.12-arm64.dmg` and drag `Kinrox.app` to `Applications`. Existing installations of Kinrox 0.3.0 or newer can also update through `Kinrox → Check for Updates…`.
- `Kinrox-0.5.12-dependency-sources.tar.gz` contains corresponding sources, build recipes, patches and license texts for bundled open-source libraries. `SHA256SUMS.txt` lists release-asset checksums.
