# Kinrox 0.4.0

Spotify music mode, queue editing, favorites and localized connection documents.
Requires an **Apple Silicon Mac with macOS 14 Sonoma or later**.
Version 0.4.0, build 6.

Download `Kinrox-0.4.0-arm64.dmg`, open it, and drag Kinrox to Applications.
All video playback libraries are bundled; Homebrew and Xcode are not required.
Users of 0.3.0 can use Check for Updates. Earlier versions can install this DMG directly.

## New

- Music library with albums, tracks, catalogue search and a compact three-column view.
- Track likes, saved albums and followed artists, with favorite undo and playlist options.
- Editable queue with duplicate occurrences, shuffle, repeat, reordering and removal.
- Official Spotify Connect playback through a private Kinrox Queue playlist.
- Coordinated video/music playback and shared system media keys.
- Music controls, queue and favorites through the encrypted iPhone LAN connection.
  These require a companion build containing music support; this release does not
  publish a new iPhone app to the App Store.
- Spotify attribution, playback restrictions, recovery actions and bundled connection
  terms/privacy documents in all 30 supported app languages.
- Updated component licensing and project information. The Mac remains GPL-3.0-only;
  new iPhone source revisions use the personal-use license described in LICENSING.md.

## Spotify setup and behavior

Spotify is optional. It requires Spotify Premium, the official Spotify app on the
same Mac, and your own Spotify developer app Client ID. Add
`http://127.0.0.1:43821/callback` to that app's redirect URIs. Development Mode
accounts must be allowed by that developer app.

In Kinrox Settings → Spotify, read and accept the connection terms, enter the
public Client ID, then connect in your browser. No client secret is requested.
Open Music with Command-2; Command-F searches and Command-R refreshes.

Audio plays in Spotify.app. Kinrox sends Spotify requests only from Mac; iPhone
controls stay on the LAN, while user-activated Spotify links open externally.
Credentials remain in the Mac Keychain. Disconnect clears local credentials and
cache but leaves the helper playlist and intentional library edits in Spotify.
Unliking a track removes its copies from editable playlists; Command-Z can undo
the latest favorite action. Artist follows remain independent.

Read the [connection terms](https://kinrox.app/spotify-terms/) and
[privacy policy](https://kinrox.app/privacy/) before connecting.

## Limits and verification

Spotify API polling can delay updates. Duplicate playlist occurrences cannot
always be distinguished after external playback changes. No album artwork is
shown. Spotify availability and developer-app access are controlled by Spotify;
this release does not imply Spotify approval.

Runtime checks use macOS 26.5.2. macOS 14 and iOS 17 are deployment targets, not
separately tested devices in this release session. Earlier physical-iPhone music
checks are documented in [Music Verification](../runbooks/MUSIC-VERIFICATION.md).

`Kinrox-0.4.0-dependency-sources.tar.gz` contains dependency sources, build recipes
and patches. Licenses are included in the app. `SHA256SUMS.txt` provides asset
checksums; matching application source is available at tag `v0.4.0`.
