# Kinrox 0.5.0

Spotify playback now runs directly on your Mac through Spotify Soloist, with
Spotify.app fully closed. Requires an **Apple Silicon Mac with macOS 14 or later**.
Version 0.5.0, build 10.

Download `Kinrox-0.5.0-arm64.dmg`, open it, and drag Kinrox to Applications.
Users of 0.3.0 or later can use Check for Updates. Video libraries are bundled;
Homebrew and Xcode are not required.

## Spotify setup

Spotify Premium, your own Spotify developer Client ID and a personal
[Soloist API key](https://developer.spotify.com/dashboard/soloist) are required.
Accept the updated connection terms in Settings, enter the key and download the
engine directly from Spotify. Pair once using Spotify on iPhone on the same local
network. After pairing, Spotify on both Mac and iPhone can be closed.

Soloist is downloaded separately and is not bundled or redistributed by Kinrox.
Its builds expire after 90 days; Settings provides an engine update action.
Keys stay in the Mac Keychain, but are passed to Soloist in process arguments
readable by other programs under the same user account. The local playback socket
has no authentication. The connection terms explain these limitations and cleanup.

## Changes

- Play, pause, seek, volume and track changes use the native engine. There is no
  Spotify.app or embedded browser fallback.
- Kinrox owns the queue locally, including repeated tracks, shuffle and repeat.
  Playback no longer creates or rewrites a Spotify helper playlist; existing
  helper playlists remain untouched and excluded from bulk favorite changes.
- After 20 seconds paused, the audio process stops. Play restores the saved
  position; recovery after a long pause typically takes 2–3 seconds.
- iPhone controls remain on the encrypted local connection. The updated remote
  handles unknown volume and recovery states; App Store publication is separate.
- Fixed video opening failing when the music engine had never started, and
  recovery after an audio process or its supervisor exited unexpectedly.
- Improved recovery from interrupted engine setup, stale playback endpoints and
  externally resumed playback after a pause.
- Setup and recovery screens, connection terms and privacy documents support
  all 30 application languages.

## Verification and limitations

Live tests ran with Spotify.app absent. The owner confirmed audible playback.
A 30-minute run measured Soloist at 24.73–27.30 MiB and about 1% of one CPU core.
On a physical iPhone, 1,003 commands completed without failure; 200 Next samples
had p95 3.095 seconds, within the owner-approved 3.2-second limit. The slowest
Next in that run took 4.066 seconds. Cold/warm startup p95 was 2.93/2.23 seconds.

MP4/MKV rendering, audio-output changes, a brief network interruption and process
crash recovery were verified. Physical Mac sleep and system reboot checks were
waived by the owner for this release and remain untested. Runtime verification
used macOS 26.5.2; macOS 14 is the deployment minimum, without a separate runtime
check. These boundaries and automated results are recorded in
[Standalone Spotify Verification](../runbooks/SOLOIST-VERIFICATION.md).

`Kinrox-0.5.0-dependency-sources.tar.gz` contains the bundled open-source dependency
sources, build recipes and patches; it contains no Soloist binary or archive.
Licenses are included in the app. `SHA256SUMS.txt` provides asset checksums;
matching application source is available at tag `v0.5.0` after publication.
