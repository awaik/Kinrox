# M4.3 Verification Report — Bonjour and Network.framework Transport

Date: 2026-10-26. Review of M4.2 completed by owner.
Milestone M4.3 implemented in `RemoteTransport`. Uncommitted on `main`.

## Implementation

Sources: [RemoteTransport](../../Packages/RemoteProtocol/Sources/RemoteTransport/).

- `BonjourAdvertiser`: Advertises `_kinrox._tcp` in `local.` domain with TXT record containing `v/id/pv`. Lifecycle tied to NWListener; random port assigned by kernel.
- `BonjourBrowser`: Discovers players via `.bonjourWithTXTRecord`, resolving service endpoints and persistent serverId. Offline services marked `isAvailable = false`.
- `TransportServer`: Handles up to 4 concurrent connections using shared `PairingGate` and callbacks.
- `TransportClient`: Single-attempt client driving `ClientHandshake`.
- `ServerSession`: Integrates WebSocket with `ServerHandshake`/`SecureChannel`. First protected frame is handshake confirmation.
- `WebSocketPeer`: Manages serial callbacks onto main queue, framing binary messages up to 65,536 bytes. Outgoing buffer capped at 32 queued frames.
- Heartbeat: Ping every 5s; absence of incoming traffic closes connection after 15s (client) or 20s (server). Control frames bypass encryption layer and do not advance AEAD nonce.
- Network policy: `acceptLocalOnly`, local subnet verification via `getifaddrs`, rejection of public addresses.
