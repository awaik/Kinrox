# Mac 0.2.0 Release Verification

Date: 2026-10-29. Version **0.2.0, build 4**, Apple Silicon, macOS 14+.
The owner requested publication of the updated Mac player to GitHub after the
track-selection review. The release includes the Mac feature, fixes, tests,
translations, release documentation, and download-page updates. Accumulated
iPhone App Store submission changes remain outside this release commit.

## Automated checks

- PlayerMac: **89 tests in 18 suites passed** against the pinned portable libraries.
  Result: `DerivedData/PortableTests/Logs/Test/Test-PlayerMac-2026.10.29_15-03-03-+0700.xcresult`.
- RemoteProtocol/RemoteTransport: **118 tests in 20 suites passed**.
- RemoteiOS simulator: **48 tests in 9 suites passed**. Its version remains 0.1.0 (1).
  Result: `DerivedData/Logs/Test/Test-RemoteiOS-2026.10.29_15-08-59-+0700.xcresult`.
- Packaging and release workflow: **13 Python tests passed**.
- Dependency archive and extracted-library integrity checks passed; all 43 source
  archives and license material were verified.
- Localization: 30 locales and 231 UI keys verified. Strict Swift formatting,
  shell syntax, and whitespace checks passed. Landing-page download links and
  JSON-LD versions agree with the new DMG.

## Distribution and runtime checks

- Release archive and Developer ID export succeeded. The app bundles 44 libraries
  with no Homebrew load paths, with library validation and Hardened Runtime enabled.
- Real startup checks passed before submission and from the read-only mounted DMG.
- App notarization: Accepted, `9aec0fba-06a4-424a-9b17-6e4755c36a56`.
- DMG notarization: Accepted, `9d816d39-8cbb-45b4-82f7-76921b498986`.
- App and DMG tickets were stapled and validated. Signature, Gatekeeper, portable
  dependency, and disk-image verification passed, including the mounted app.
- Mounted-app verification covered MP4 playback, automatic advance to HEVC MKV,
  video rendering, pause, seek, fullscreen enter/exit, and resume at Kinrox volume 0.
- A temporary local client paired, reauthenticated through Data Protection Keychain,
  and issued playback commands. Its access was revoked afterward; the two existing
  paired devices were preserved.
- The mounted app restored saved track preferences, selected audio from a nested
  external MKA, displayed nested external subtitles, and switched subtitles Off.

Runtime checks used macOS 26.5.2. macOS 14 deployment metadata was verified, but no
separate macOS 14 machine or physical-iPhone retest was used. The existing Xcode
archive warning about the optional App Category remains. No iPhone build was uploaded.
Artifacts, signing/export logs, notary receipts, and the temporary verification
client are retained in ignored `dist/0.2.0-build4/`; only the DMG, dependency source
archive, and checksum list are release assets.
