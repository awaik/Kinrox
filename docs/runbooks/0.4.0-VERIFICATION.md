# Mac 0.4.0 Release Verification

Date: 2026-11-01. Version **0.4.0, build 6**, Apple Silicon, macOS 14+.
The owner explicitly authorized committing all accumulated project changes and
publishing a downloadable Mac release. No iPhone App Store upload is included.

## Automated checks

- Python release, packaging and website checks: 45 tests passed.
- MusicCore / SpotifyWebAPI: 27 tests in 6 suites passed.
- RemoteProtocol / RemoteTransport: 126 tests in 22 suites passed.
- iPhone simulator: 60 tests in 12 suites passed.
- Mac: 180 tests in 39 suites exercised using pinned portable libmpv libraries.
  The first full run had one LivePlaylistObserverTests connection timeout. The
  second passed that suite but had one ScreensaverRemoteTests notConnected error.
  An isolated rerun of both suites passed all 5 tests, including parameterized
  scenarios. Neither full run was entirely green; no timeout or assertion was
  weakened and production code was not changed to hide these LAN timing failures.
- Strict Swift formatting and git diff whitespace checks passed.
- Localization: 30 locales / 348 UI keys passed.
- Website: 120 generated pages verified; 8 website and 5 Spotify document tests
  passed after updating release-era copy.
- Candidate repository files were scanned for common private-key and access-token
  patterns; none were detected. Ignored credentials and build artifacts stay local.

Logs: `/tmp/kinrox-release04-{python,music,protocol,ios,mac,mac-rerun,mac-network,lint}.log`.
Build artifacts and notarization receipts are retained in `dist/0.4.0-build6/`.

## Validation boundaries

Runtime environment: macOS 26.5.2. macOS 14 remains the deployment target, without
an independent macOS 14 machine test. Physical-iPhone and live Spotify evidence
from implementation is documented in [Music Verification](MUSIC-VERIFICATION.md);
this release does not repeat Spotify authorization or mutate the owner's library.

## Packaged app

- App and DMG notarization: Accepted; stapling, Gatekeeper, code signatures and
  DMG checksum validation passed. The read-only mounted app passed signature,
  stapler and all 44 bundled-library checks.
- Mounted application: H.264 MP4 playback, HEVC MKV auto-advance, PIN pairing,
  Data Protection Keychain reauthentication, pause, absolute seek, fullscreen and
  resume passed. Kinrox volume was set to zero before test playback; system
  volume was not changed.
- The first interactive smoke client timed out while the file-picker UI was being
  operated. A second run opened the test recent directly and passed every command.
  Both temporary paired devices were revoked afterward; existing phones remain.
- Bundled Spotify terms opened with the expected English version 2026-11-01.
  Spotify consent was not accepted and restoration was disabled for the check.
- macOS deployment metadata is 14.0; version/build are 0.4.0/6. All required
  component-license documents are present in the signed app.
