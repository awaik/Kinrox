## Performance measurements

Orchestrator measurements with Spotify.app terminated (never launched), no playback and
system volume untouched; 1 s `proc_pid_rusage` sampling of cold starts of installed 0.5.8
versus a Release build of this package:

| Scenario | 0.5.8 | 0.5.9 |
|---|---|---|
| Video view cold start, peak footprint | 122.9 MiB | 124.1 MiB |
| Video view, steady after 150 s | 120.7 MiB, 0.0 % CPU | 109.9 MiB, 0.0 % CPU |
| Spotify view (⌘2 at 5 s), peak | 124.4 MiB | 128.7 MiB |
| Spotify view, steady (180–225 s) | 98.3 MiB, 0.0 % CPU, 0 wakeups/s | 107.2 MiB, 0.0 % CPU, 0 wakeups/s |

0.5.9 showed a transient 157.1 MiB peak when switching back to the video view. Neither run
reproduced the 848–849 MiB 0.5.8 startup spike documented in the research, so these runs do
not by themselves demonstrate its fix; that evidence is the research's local Release cold
starts (123.3/120.8 MiB).
