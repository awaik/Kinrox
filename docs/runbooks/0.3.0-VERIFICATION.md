# Mac 0.3.0 Release Verification

Date: 2026-10-30. Version **0.3.0, build 5**, Apple Silicon, macOS 14+.
The owner requested a Mac commit, deployment, and release after the review fixes.
The release source includes the Mac features, shared protocol and localization,
related companion controls, tests, and distribution documentation. App Store
submission records and delivery tooling remain outside this Mac release commit.

## Automated checks

- **133 Mac tests in 27 suites passed** against the pinned portable libraries.
  Results are retained under `DerivedData/Release030Tests/Logs/Test/`.
- The preceding review verification passed **120 protocol/transport tests** and
  **53 iOS simulator tests**. No application behavior changed after those checks;
  this release advances only the Mac version/build settings.
- **25 release/appcast/packaging Python tests passed** in the full 32-test script run.
- Dependency integrity passed for 44 bundled dylibs, 43 source archives, and notices.
- Localization: 30 locales, 263 UI keys. Strict Swift format, shell syntax,
  whitespace, and both landing pages' download/JSON-LD consistency checks passed.

## Distribution checks

- Archive and Developer ID export passed. Sparkle helpers and all playback libraries
  are signed, Hardened Runtime is enabled, and library validation remains enabled.
- App notarization: Accepted, `9d4252fb-bf5d-48bb-9cc0-ec8d8b052f47`.
- DMG notarization: Accepted, `110b31be-d60f-4808-8d3d-2a0f8f004114`.
- Both tickets were stapled and validated; signatures, Gatekeeper, and DMG checksum passed.
- The mounted read-only DMG passed signature, Gatekeeper, staple, dependency,
  version/build, and actual player-startup checks.
- The generated appcast's enclosure length and EdDSA signature match the final DMG.
- The smoke-test environment skips Sparkle initialization; framework loading is
  still verified. Public update-feed checks follow deployment.

## Mounted-app runtime verification

- H.264 MP4 playback and automatic folder advance to HEVC MKV rendered correctly.
  Kinrox volume was zero before opening media; system volume was untouched.
- A temporary local client paired with the Developer ID app, then reauthenticated
  using the token persisted by the Mac Data Protection Keychain.
- Pause, absolute seek, native fullscreen enter/exit, resume, Matrix start/stop,
  confirmed active state before acknowledgement, and retained paused position passed.
- The test device was revoked afterward; the two existing paired devices remained.
- A fresh pairing request appeared over Matrix. Esc rejected the request with
  `pairingRejected` and left Matrix running; a second Esc returned to paused playback.
  An earlier attempt ended before UI interaction with `notConnected`; its log is
  retained in `dist/0.3.0-build5/pairing-escape.log`. The immediate retry passed.

Runtime verification used macOS 26.5.2. No separate macOS 14 or physical-iPhone
acceptance run was performed. The optional App Category archive warning remains.
No iPhone build was uploaded. Logs, archives, notary receipts, and the temporary
verification client are retained in ignored `dist/0.3.0-build5/`.
