# Mac 0.5.12 Verification

Release authorized by the owner on 2026-11-20 ("принимаем, запускай релиз" — accept the
measured results and run the release), invoked through `general-release`. Mac version
0.5.12, build 22, Apple Silicon, minimum deployment target macOS 14.0. Runtime checks ran on
macOS 26.5.2 (25F84); no separate macOS 14 runtime test was performed. Kinrox Remote is
unchanged (0.2.2, build 4).

## Contents

- Remote media library, Part A — protocol and Mac server
  ([research record](<../RESEARCHES/DONE/DONE - 2026-11-20_08-24_Remote-media-library-protocol-and-Mac.md>),
  Figma `18 · Remote — Медиатека на пульте`, `334:304`): additive v1 `library.v1` feature
  declaration in `requestState`, optional `state.library` / `state.sources`,
  `MusicState.origin`, `RemoteMusicTrack.format`, six application messages
  (`requestLibrary` / `library`, `requestLibraryItem` / `libraryItem`, `requestArtwork` /
  `artwork`), commands `playLibrary` and `resumeSource`, error code `unavailable` for offline
  drives, and opaque HMAC identifiers (no paths, bookmarks or cache file names on the wire).
  Mac side: `RemoteLibraryBridge` (index, browse, details, artwork with per-connection limits),
  `RemoteLocalMusicBridge`, per-connection state projection that keeps the legacy local-audio
  representation for remotes without `library.v1`, and `PlayerSession` playback wiring through
  `PlaybackCoordinator` (normal window, never fullscreen, Matrix exit).
- Release review fixes (agy review, agy Gemini 4 Neon apply, orchestrator control): range
  checks for tag integers and protocol counts, a lazily built and released remote library
  index with handle-based lookups, metadata-change coalescing, a non-caching remote artwork
  read, progress-aware page revisions for Continue Watching and unwatched videos, and
  `playLibrary` / `resumeSource` edge cases (partially offline series, shuffled start on the
  chosen track, restart of the loaded video, loading or disallowed resume, ad-hoc recents).
- `WebSocketPeer`: a path update that reports the unresolved Bonjour service endpoint no longer
  closes a ready connection; the approved resolved address is re-checked instead.
- Agent runners in `.agents/skills/{general-release,research-execute}` and
  `.agents/templates/investigate.md` moved from Codex to agy Gemini 4 Neon (owner decision
  2026-11-20), with stage timeouts and a failed apply stage no longer advancing to control.
- Opt-in Release benchmark `PlayerMacTests/RemoteLibraryReleaseBenchmarkTests.swift`
  (disabled by default).

## Performance measurements

Completed by the orchestrator on macOS 26.5.2 (25F84) (`arm64`, `-configuration Release`,
`ENABLE_TESTABILITY=YES`, fresh derived data) via `RemoteLibraryReleaseBenchmarkTests`, with
isolated `UserDefaults` and storage, `FakeNowPlayingCenter`, Kinrox volume `0` for video and
local audio, and Mac system volume untouched. Library: 2,001 videos (200 with distinct
480 px posters, 34 in progress) and 5,001 tracks in 501 albums; client over the real
encrypted transport declaring `library.v1`.

- Idle, no remote connected: physical footprint added by `connectLibrary` `−0.03 MiB`
  (the index is built only for a connected remote); `0.28%` of one core and `9.97`
  interrupt wakeups/s with the library versus `0.45%` and `9.99`/s without it.
- `requestLibrary` 50-item pages, 40 round trips each, p50 / p95 / max:
  `continueWatching` 5.44 / 8.72 / 8.72 ms; `videos` 6.98 / 10.27 / 10.67 ms; `videos` at
  offset 1,000 6.81 / 11.73 / 12.82 ms; `albums` 6.45 / 9.44 / 10.41 ms; `tracks` search
  20.47 / 21.83 / 22.08 ms. Maximum `@MainActor` 10 ms timer gap `30.01 ms`.
- Artwork, 200 cold requests at 4 in flight: p50 / p95 / max 10.25 / 12.45 / 26.97 ms; 200
  JPEGs, largest 28,454 bytes; peak physical footprint `+11.78 MiB`; `+8.65 MiB` 60 s after
  the burst (4 MiB remote thumbnail cache cap).
- `playLibrary` → confirmed `state`: local album cold `144.39 ms`; video (pausing local audio)
  `27.72 ms`; local album after video `62.74 ms`; video never fullscreen.
- Spotify playback, Music memory and Soloist are not changed by this release; standalone limits
  remain as recorded in [Soloist Verification](SOLOIST-VERIFICATION.md) and were not re-measured.

## Verification boundaries

Runtime checks ran on macOS 26.5.2 (25F84) only; Mach-O minimum-OS metadata (`14.0`) is
checked for bundled binaries, and no separate macOS 14 runtime test was performed per the
owner's 2026-11-03 decision. The only `RemoteiOS` source change is one exhaustive demo
`switch` branch, compile-verified for `generic/platform=iOS`; no physical iPhone was connected,
so no `RemoteiOS` device build or test ran (no iOS Simulator was used, per Rule 11). The
library protocol is exercised by Mac tests and the loopback benchmark; an end-to-end check with
a library-aware remote waits for the RemoteiOS update. An active `/Applications/Kinrox.app` +
`Soloist` session was running on the release Mac and was not disturbed. Interactive
mounted-DMG playback and physical-phone pairing against the release DMG were not performed.
Physical sleep/reboot checks remain waived, not passed.
