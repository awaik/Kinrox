# Mac 0.5.7 Verification

Release authorized by the owner on 2026-11-10. Mac version 0.5.7, build 17,
Apple Silicon, minimum deployment target macOS 14.0. Runtime checks were performed
on macOS 26.5.2 (25F84); no separate macOS 14 runtime test was performed.

## Automated checks

- KinroxMusic: 65 tests passed across 12 suites.
- RemoteProtocol: 127 tests passed across 22 suites.
- Release, packaging, website and document scripts: 54 Python tests passed.
- PlayerMac with pinned portable libmpv: 355 tests total, 345 passed, 10 skipped,
  zero failures. Opt-in rendering, credentialed Spotify/Soloist and performance
  probes were not enabled. Real MP4/H.264, MKV/H.264 and MKV/HEVC playback,
  pause/seek, rendering, fullscreen and LAN server tests ran with player volume zero.
- RemoteiOS on the iPhone 17 simulator: 63 tests total, 60 passed, 3 skipped,
  zero failures. The physical-phone acceptance and opt-in live pairing/storage
  cases were skipped; no new physical iPhone acceptance is claimed.
- Full recursive strict Swift formatting passed. Changed Swift files remain
  within the 500-line limit; staged whitespace checks passed.
- Localization: 30 locales and 455 UI keys verified. Offline website generation
  verified 120 pages in 30 languages, including the updated Spotify documents.

The first portable Mac run ended with two unfinished tests because the runner
exited with code 0: `LivePlaylistObserverTests.connectedRemote(paused:)` and
`WelcomeLayoutTests.recentFilesDoNotDisplaceWelcome(itemCount:)`. No assertion
failure established a product defect. A full repeat after release compilation,
with `-parallel-testing-enabled NO`, passed without source changes. Both results
are retained; the original interruption's cause was not established.

## Signed distribution

`Scripts/build-release.sh 0.5.7 17` completed successfully. The app and helpers
use Developer ID signing and Hardened Runtime, without library-validation or
executable-memory exemptions. All 44 bundled libraries passed architecture,
minimum-OS and portable dependency checks. Soloist distribution artifacts are
absent; the Kinrox-owned host helper is included.

Apple notarization accepted both submissions:

- App: `5c75240c-eaed-41db-9378-54045dd2e587`.
- DMG: `4d0e4f61-ffa2-42f0-b328-c0a97fc8917c`.

Both tickets were stapled and validated. The final DMG passed its checksum and
code-signature checks. Its read-only mounted app passed deep strict signature,
Gatekeeper, stapler, portable-library and Soloist-bundle checks, and a real startup
smoke test requiring `KINROX_PLAYER_READY`, bundled libmpv/Sparkle and no loaded
Homebrew dependencies. Its Info.plist reports version 0.5.7, build 17 and minimum
macOS 14.0. Both release asset hashes match `SHA256SUMS.txt`. Sparkle's DMG signature
was generated with the existing Keychain key matching the app's public key.

All 515 recorded build inputs remained unchanged through final verification.

## Verification boundaries

Discovery behavior is covered by deterministic local HTTP and engine fixtures.
Live Spotify/ListenBrainz result quality, request counts, time to first results,
new command-latency measurements and startup/playback/pause/sustained memory/CPU
measurements were not repeated. Standalone playback requirements and prior
accepted limits remain in [Soloist Verification](SOLOIST-VERIFICATION.md).
Mounted-app startup is a smoke test; interactive mounted-app video controls and
physical-phone pairing were not repeated. The automated portable playback/LAN
tests above passed. Physical sleep/reboot checks remain waived, not passed.
No iPhone App Store or TestFlight upload is part of this release.
