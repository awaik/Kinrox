## Summary

Implemented 15 message types and 10 commands defined in AGENTS.md 6.3.

- `Codec`: Canonical, sorted-key UTF-8 JSON without escaping `/`, without trailing newline, ISO 8601 timestamps, Base64 binary serialization. Empty bodies encode as `{}`; `recent` body is an array.
- Bounds: Up to 65,536 bytes strictly enforced before parsing and after encoding. Volume clamped 0–100.
- Negotiation: `Version.negotiate` selects highest common protocol version; non-intersecting ranges produce `incompatibleVersion`.
