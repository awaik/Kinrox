ข้อกำหนดการเชื่อมต่อ

สิทธิ์เข้าถึง Spotify: คลังเพลง การเล่น รายการโปรด และเพลย์ลิสต์ที่แก้ไขได้ การเลิกถูกใจจะนำเพลงออกจากเพลย์ลิสต์ที่แก้ไขได้ด้วย ข้อมูลเข้าสู่ระบบอยู่ในพวงกุญแจ Mac การยกเลิกการเชื่อมต่อจะลบข้อมูล Spotify ในเครื่องและเก็บเพลย์ลิสต์ Spotify ไว้ ไม่มีเซิร์ฟเวอร์ Kinrox หรือการวิเคราะห์การใช้งาน

ไทย · 2026-11-03

ข้อกำหนดการเชื่อมต่อ Spotify

ข้อกำหนดนี้ใช้เมื่อคุณเปิดใช้ Spotify ใน Kinrox ผู้ดูแล Kinrox คือ awaik (https://github.com/awaik/Kinrox) ติดต่อฝ่ายช่วยเหลือหรือสอบถามเรื่องความเป็นส่วนตัวได้ที่ https://github.com/awaik/Kinrox/issues Kinrox เป็นอิสระจาก Spotify และไม่ได้รับการรับรองจาก Spotify ข้อกำหนดนี้มีผลเมื่อคุณยอมรับในแอป

บัญชีและทางเลือกของคุณ

การเชื่อมต่อเป็นทางเลือก ใช้แอปนักพัฒนา Spotify ของคุณเองและบัญชี Spotify Premium ที่ได้รับอนุญาต Spotify เป็นผู้ควบคุมการเข้าถึง API และโควตา การเข้าถึงอาจเปลี่ยนแปลงหรือสิ้นสุดลง ข้อกำหนดของ Spotify เองยังคงมีผล เสียงเล่นผ่าน Spotify Soloist ซึ่งดาวน์โหลดจาก Spotify ไปยัง Mac โดยตรงตามคำขอของคุณ ผู้ใช้แต่ละคนต้องระบุคีย์ API ของ Soloist ส่วนตัว การจับคู่ครั้งแรกใช้ Spotify บน iPhone หลังจากนั้นจะเล่นได้แม้ปิด Spotify บน Mac และ iPhone แล้ว Soloist จัดการการถอดรหัสและแคชเสียงของตัวเอง Kinrox ไม่บันทึกหรือส่งออกเสียง บิลด์ Soloist จะหมดอายุหลัง 90 วันและต้องอัปเดต

การเปลี่ยนแปลงคลัง

การกระทำของคุณอาจบันทึกหรือนำเพลงและอัลบั้มออก ติดตามหรือเลิกติดตามศิลปิน สร้างเพลย์ลิสต์ และเปลี่ยนแปลงเพลย์ลิสต์ที่คุณเป็นเจ้าของหรือแก้ไขได้ การนำเพลงออกจากรายการโปรดยังนำเพลงนั้นทุกตำแหน่งออกจากเพลย์ลิสต์ที่คุณแก้ไขได้ด้วย การเลือกอัลบั้มไม่ได้บันทึกเพลงแต่ละเพลงแยกกัน การเปลี่ยนแปลงมีผลในบัญชี Spotify ของคุณและอาจปรากฏในไคลเอนต์ Spotify อื่น

คิวการเล่น

Kinrox เก็บคิวเล่นไว้ในเครื่องและเริ่มกระบวนการ Soloist หนึ่งกระบวนการสำหรับแต่ละรายการในคิว โดยไม่สร้างเพลย์ลิสต์ช่วยเล่น เพลย์ลิสต์ Kinrox Queue ที่มีอยู่จะยังอยู่ใน Spotify ตัวระบุที่ไม่เป็นความลับของเพลย์ลิสต์เหล่านั้นจะเก็บไว้ในเครื่องเพื่อยกเว้นจากการเปลี่ยนแปลงคลัง คุณสามารถลบเพลย์ลิสต์เหล่านั้นเองใน Spotify ได้

สิทธิของ Spotify

เว้นแต่กฎหมายที่ใช้บังคับจะอนุญาตเป็นอย่างอื่น คุณต้องไม่ดัดแปลงหรือสร้างงานดัดแปลงจากแพลตฟอร์ม บริการ หรือเนื้อหาของ Spotify หรือถอดคอมไพล์ ถอดแอสเซมบลี ทำวิศวกรรมย้อนกลับ หรือแปลงสิ่งเหล่านั้นเป็นซอร์สโค้ดหรือรูปแบบอื่นที่มนุษย์อ่านได้ ข้อจำกัดนี้เกี่ยวกับวัสดุของ Spotify และไม่จำกัดสิทธิในโค้ด Kinrox ที่ให้ไว้ตามใบอนุญาตของส่วนประกอบ รวมถึงใบอนุญาต GPL ของเครื่องเล่นบน Mac

ความรับผิดและการรับประกัน

ผู้ดูแล Kinrox เป็นผู้รับผิดชอบต่อ Kinrox เท่าที่กฎหมายอนุญาต Spotify และบุคคลที่สามอื่นไม่มีหน้าที่รับผิดชอบหรือความรับผิดทางกฎหมายต่อ Kinrox Kinrox ไม่ให้คำมั่นหรือการรับประกันแทน Spotify เท่าที่กฎหมายอนุญาต จะไม่รวมการรับประกันโดยนัยทั้งหมดเกี่ยวกับแพลตฟอร์ม บริการ และเนื้อหา Spotify รวมถึงความสามารถในการจำหน่าย ความเหมาะสมสำหรับวัตถุประสงค์เฉพาะ และการไม่ละเมิดสิทธิ สิทธิผู้บริโภคที่กฎหมายบังคับให้มีไม่ได้รับผลกระทบ

ความเป็นส่วนตัวและการบังคับใช้

การเก็บและใช้ข้อมูลอยู่ภายใต้นโยบายความเป็นส่วนตัวที่แสดงพร้อมข้อกำหนดนี้ Spotify เป็นบุคคลที่สามผู้รับประโยชน์ตามข้อกำหนดและนโยบายดังกล่าว และสามารถบังคับใช้ข้อกำหนดนี้ได้โดยตรง ใช้ การตั้งค่า → Spotify → ยกเลิกการเชื่อมต่อ เพื่อสิ้นสุดการเชื่อมต่อ คุณยังเพิกถอนการเข้าถึงได้จากหน้าแอปในบัญชี Spotify: https://www.spotify.com/account/apps/.

การเปลี่ยนแปลง

ต้องยอมรับข้อกำหนดการเชื่อมต่อเวอร์ชันใหม่ก่อนที่ Kinrox จะเชื่อมต่ออีกครั้ง การเล่นวิดีโอในเครื่องและการควบคุมระยะไกลผ่านเครือข่ายภายในยังใช้ได้โดยไม่ต้องยอมรับข้อกำหนดการเชื่อมต่อ Spotify

นโยบายความเป็นส่วนตัว — การเชื่อมต่อ Spotify

เวอร์ชัน 2026-11-03 ผู้ดูแล Kinrox คือ awaik เป็นผู้รับผิดชอบการประมวลผลข้อมูลของ Kinrox ที่อธิบายไว้ที่นี่ ส่วนเพิ่มเติมนี้ใช้กับการผสาน Spotify ซึ่งเป็นทางเลือก นโยบายความเป็นส่วนตัวทั่วไปของ Kinrox อยู่ที่ https://kinrox.app/privacy/ ติดต่อ: https://github.com/awaik/Kinrox/issues อย่าโพสต์โทเคน เนื้อหาคลังส่วนตัว หรือข้อมูลส่วนตัวอื่นในรายงานปัญหาสาธารณะ

การเข้าถึงและวัตถุประสงค์

หลังจากคุณยอมรับข้อกำหนดและอนุญาต Spotify แล้ว Kinrox บน Mac จะอ่านตัวระบุบัญชีและชื่อที่แสดง เพลงและอัลบั้มที่บันทึก ศิลปินที่ติดตาม เพลย์ลิสต์ที่เข้าถึงได้และเนื้อหา สถานะการเล่น และอุปกรณ์ที่ใช้ได้ โดยใช้ข้อมูลนี้เพื่อแสดงคลังและควบคุม Spotify เมื่อคุณใช้ตัวควบคุมที่เกี่ยวข้อง แอปสามารถบันทึกและนำรายการโปรดออก ติดตามศิลปิน สร้างเพลย์ลิสต์ และแก้ไขเพลย์ลิสต์ของคุณหรือเพลย์ลิสต์ร่วมกัน การนำรายการโปรดออกยังนำรายการนั้นออกจากทุกตำแหน่งในเพลย์ลิสต์ที่แก้ไขได้

การจัดเก็บและผู้รับข้อมูล

ข้อมูลรับรองสำหรับต่ออายุการเข้าถึงจัดเก็บใน Data Protection Keychain ของ Mac โทเคนการเข้าถึงยังคงอยู่ในหน่วยความจำ เมทาดาทาคลังจะถูกแคชในฐานข้อมูล SQLite ภายในเครื่องในโฟลเดอร์ Caches ของแอปบน Mac ตัวระบุบัญชีที่ตรวจสอบแล้วและชื่อที่แสดงจะถูกบันทึกในค่ากำหนดของ Mac Client ID ที่ให้ไว้ การเชื่อมโยงเพลย์ลิสต์ช่วยเหลือ และเวอร์ชันเอกสารที่ยอมรับจัดเก็บในค่ากำหนดของ Mac Kinrox ไม่มีเซิร์ฟเวอร์ การวิเคราะห์ หรือเทเลเมทรี และผู้ดูแลไม่ได้รับข้อมูล Spotify เหล่านี้ Spotify รับคำขอโดยตรงจาก Mac และจัดการตามนโยบายความเป็นส่วนตัวของตน: https://www.spotify.com/legal/privacy-policy/ Spotify เห็นข้อมูลเครือข่าย เช่น ที่อยู่ IP สาธารณะของ Mac คีย์ API ของ Soloist ส่วนตัวเก็บอยู่ในพวงกุญแจ เซสชัน Connect เก็บอยู่ในโฟลเดอร์ส่วนตัวของบัญชี Soloist ใช้แคชเสียงแยกต่างหากที่จำกัดไว้ที่ 200 MB คีย์ถูกส่งให้กระบวนการ Soloist ที่มีลายเซ็นผ่านอาร์กิวเมนต์การเริ่มทำงาน ซึ่งกระบวนการอื่นภายใต้บัญชีผู้ใช้เดียวกันสามารถอ่านได้ ซ็อกเก็ตควบคุมลูปแบ็กของ Soloist ไม่มีการยืนยันตัวตนหรือการตรวจสอบ Origin โปรแกรมในเครื่องหรือหน้าเว็บที่เข้าถึงลูปแบ็กได้จึงสามารถส่งคำสั่งเล่นได้

iPhone และลิงก์

iPhone ที่จับคู่ได้รับเมทาดาทาเพลง อัลบั้ม ศิลปิน และเพลย์ลิสต์ สถานะคิว และตัวควบคุมการเล่นผ่านการเชื่อมต่อเครือข่ายภายในที่เข้ารหัสของ Kinrox โดยไม่เคยได้รับข้อมูลรับรอง Spotify หรือเรียก Spotify Web API หากคุณแตะ เปิดใน Spotify iPhone หรือ Mac จะเปิดรายการที่เกี่ยวข้องใน Spotify หรือเว็บไซต์ของ Spotify การส่งต่อนี้อาจใช้อินเทอร์เน็ตและอยู่ภายใต้นโยบายความเป็นส่วนตัว Spotify เมทาดาทาของรีโมทเก็บในหน่วยความจำและล้างเมื่อยกเลิกการเชื่อมต่อหรือรีเซ็ตแหล่งที่มาหรือบัญชี

การยกเลิกการเชื่อมต่อและการเก็บรักษา

ใน Kinrox บน Mac ให้เปิด การตั้งค่า → Spotify → ยกเลิกการเชื่อมต่อ Kinrox หยุดกระบวนการ Soloist และคำขอของตัวเอง ลบข้อมูลรับรองการต่ออายุ คีย์ API ของ Soloist รวมถึงเซสชันและแคชเสียงของตัวเอง และล้างข้อมูลบัญชีจากหน่วยความจำ ตัวระบุที่ไม่เป็นความลับของเพลย์ลิสต์คิวเดิมและเอนจินที่ดาวน์โหลดไว้จะยังคงอยู่ การเชื่อมต่อใหม่อัตโนมัติจะหยุดลง เวอร์ชันที่ยอมรับเป็นค่ากำหนดที่ไม่ผูกกับบัญชี การเปลี่ยนแปลงที่ทำแล้วใน Spotify รวมถึงเพลย์ลิสต์และรายการโปรดยังคงอยู่ การยกเลิกการเชื่อมต่อไม่ได้เพิกถอนการอนุญาตที่ Spotify หากต้องการเพิกถอน ให้ลบแอปที่ https://www.spotify.com/account/apps/ คุณสามารถลบเพลย์ลิสต์ช่วยเหลือที่เหลืออยู่ได้โดยตรงใน Spotify เมทาดาทาที่แคชไว้จะหมดอายุหลังจาก 7 วันหากไม่มีการตรวจสอบซ้ำ การตัดการเชื่อมต่อจะลบแคช SQLite ไฟล์ประกอบ และการเชื่อมโยงบัญชีที่บันทึกไว้โดยอัตโนมัติ

คุกกี้และข้อมูลทั่วไปของ Kinrox

Kinrox ไม่เพิ่มการวิเคราะห์หรือคุกกี้ เซสชัน Spotify API ไม่ใช้คุกกี้ถาวรหรือแคชคำตอบบนดิสก์ การเข้าสู่ระบบผ่านเบราว์เซอร์และเว็บไซต์ Spotify อาจใช้คุกกี้ของตนเอง ให้จัดการในเบราว์เซอร์และการตั้งค่าความเป็นส่วนตัว Spotify นโยบายทั่วไปของ Kinrox อธิบายบุ๊กมาร์กไฟล์ในเครื่อง ข้อมูลรับรองการจับคู่ การอัปเดต Sparkle และโฮสติ้ง GitHub Spotify เป็นบุคคลที่สามผู้รับประโยชน์ตามนโยบายนี้และข้อกำหนดการเชื่อมต่อ การเปลี่ยนแปลงสำคัญของส่วนเพิ่มเติมนี้จะแสดงก่อนเปิดใช้การเชื่อมต่อใหม่
