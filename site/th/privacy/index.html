นโยบายความเป็นส่วนตัว

มีผลบังคับใช้เมื่อมีการเผยแพร่หน้านี้ อัปเดตเมื่อวันที่ 30 ตุลาคม 2026

Kinrox เป็นเครื่องเล่นวิดีโอในเครื่องสำหรับ Mac และรีโมทคู่หูสำหรับ iPhone แอปจะไม่ส่งข้อมูลส่วนบุคคล ประวัติการเล่น หรือการวิเคราะห์การใช้งานไปยังนักพัฒนา ไม่มีบัญชี SDK โฆษณา หรือบริการคลาวด์ในแอป

ข้อมูลบนอุปกรณ์ของคุณ

เครื่องเล่น Mac เก็บบุ๊กมาร์กไฟล์ล่าสุดและการตั้งค่าไว้ใน Mac ของคุณ รีโมท iPhone จะจัดเก็บตัวระบุอุปกรณ์แบบสุ่ม Mac ที่เลือก และการตั้งค่าการเชื่อมต่อบน iPhone ของคุณ ข้อมูลรับรองการจับคู่จะถูกจัดเก็บไว้ในพวงกุญแจของอุปกรณ์แต่ละเครื่อง รีโมทรับสถานะการเล่นและชื่อไฟล์ล่าสุดและระยะเวลาจาก Mac ของคุณ เส้นทางระบบไฟล์และไฟล์วิดีโอแบบเต็มจะไม่ถูกส่งไปยัง iPhone

การสื่อสารผ่านเครือข่ายท้องถิ่น

เมื่อได้รับอนุญาตจากคุณ Kinrox จะค้นพบเครื่องเล่นที่ใช้ Bonjour และแลกเปลี่ยนคำสั่งควบคุมและข้อมูลการเล่นผ่านเครือข่ายท้องถิ่นของคุณ เซสชันที่จับคู่ใช้การเข้ารหัส ชื่ออุปกรณ์และบริการสามารถมองเห็นได้ในระหว่างการค้นพบเครือข่ายท้องถิ่น การค้นพบนั้นไม่ใช่ช่องทางที่เข้ารหัส แอปไม่ได้ใช้เซิร์ฟเวอร์รีเลย์ที่ดำเนินการโดยนักพัฒนา

การตรวจสอบการอัพเดต Mac

เริ่มตั้งแต่เวอร์ชัน 0.3.0 เครื่องเล่น Mac จะใช้ Sparkle เพื่ออ่านฟีดอัปเดตสาธารณะบน GitHub Pages วันละครั้ง และเมื่อคุณเลือก Check for Updates การตรวจสอบไม่รวมตัวระบุอุปกรณ์ ประวัติการเล่น หรือโปรไฟล์ระบบ เมื่อคุณเลือกที่จะติดตั้งการอัปเดต Sparkle จะดาวน์โหลดตัวติดตั้งที่เซ็นชื่อจาก GitHub Releases GitHub อาจประมวลผลข้อมูลคำขอ เช่น ที่อยู่ IP ภายใต้นโยบายความเป็นส่วนตัว การเล่นและการควบคุมระยะไกล iPhone ไม่จำเป็นต้องเชื่อมต่ออินเทอร์เน็ต

การเก็บรักษาและทางเลือกของคุณ

ข้อมูลการจับคู่จะถูกเก็บไว้จนกว่าคุณจะลบ เลือก «ลืม» ในการตั้งค่าแอปบน iPhone เพื่อลบข้อมูล Mac ที่บันทึกไว้ใน iPhone หากต้องการเพิกถอนสิทธิ์บน Mac ให้ลบสิทธิ์ของ iPhone ในการตั้งค่ารีโมตของเครื่องเล่นบน Mac ทั้งสองอย่างเป็นการดำเนินการแยกกัน การลืม Mac บน iPhone ไม่ได้เพิกถอนสิทธิ์ที่บันทึกไว้บน Mac คุณสามารถล้างรายการไฟล์ล่าสุดในเครื่องเล่นบน Mac ได้ และสามารถปิดสิทธิ์เครือข่ายภายในได้ในการตั้งค่าระบบ ข้อมูลใน Keychain อาจยังคงอยู่หลังจากถอนการติดตั้งแอป หากต้องการลบข้อมูลการจับคู่ที่บันทึกไว้ ให้ลบการจับคู่ก่อนถอนการติดตั้งแอป

การสนับสนุนและเว็บไซต์นี้

หากคุณเลือกที่จะติดต่อเราผ่าน GitHub Issues ข้อมูลที่คุณส่งจะได้รับการจัดการโดย GitHub ภายใต้นโยบายความเป็นส่วนตัวและอาจเปิดเผยต่อสาธารณะ ห้ามโพสต์โทเค็นการจับคู่ ชื่อไฟล์ส่วนตัว หรือข้อมูลที่ละเอียดอ่อนอื่นๆ เว็บไซต์นี้โฮสต์บน GitHub Pages; ผู้ให้บริการโฮสติ้งอาจประมวลผลข้อมูลคำขอ เช่น ที่อยู่ IP ภายใต้คำชี้แจงความเป็นส่วนตัวของ GitHub Kinrox ไม่มีสคริปต์การวิเคราะห์หรือคุกกี้เพิ่ม

ติดต่อและเปลี่ยนแปลง

หากมีคำถามเกี่ยวกับความเป็นส่วนตัว โปรดติดต่อผู้ดูแลผ่านทางเครื่องมือติดตามปัญหา Kinrox เราจะอัปเดตหน้านี้เมื่อการจัดการข้อมูลของแอปเปลี่ยนแปลง
