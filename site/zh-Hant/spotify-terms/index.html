連線條款

Spotify 存取權限：音樂庫、播放、收藏和可編輯的播放清單。取消收藏也會從可編輯的播放清單移除該曲目。 登入憑證儲存在 Mac 鑰匙圈中。中斷連線會清除本機 Spotify 資料，但保留 Spotify 播放清單。沒有 Kinrox 伺服器或使用分析。

Spotify 連線條款

在 Kinrox 中啟用 Spotify 時，適用這些條款。Kinrox 由 awaik 維護（https://github.com/awaik/Kinrox）；支援與隱私問題請聯絡：https://github.com/awaik/Kinrox/issues。Kinrox 獨立於 Spotify，未經 Spotify 背書。你在 App 中接受後，這些條款即生效。

你的帳號與選擇

連線是選用功能。請使用自己的 Spotify 開發者應用程式及獲准使用的 Spotify Premium 帳號。Spotify 控制 API 存取權限與配額；存取權限可能變更或終止。Spotify 自身的條款仍然適用。 音訊透過 Spotify Soloist 播放。依您的要求，Soloist 會直接從 Spotify 下載至 Mac。每位使用者須提供個人 Soloist API 金鑰。首次配對使用 iPhone 上的 Spotify；之後，即使 Mac 和 iPhone 上的 Spotify 均已結束執行，也能播放。Soloist 負責解碼並管理自身的音訊快取；Kinrox 不錄製或匯出音訊。Soloist 建置版本會在 90 天後到期，屆時需要更新。

資料庫變更

你的操作可以儲存或移除歌曲與專輯、追蹤或取消追蹤藝人、建立播放清單，以及變更你擁有或有權編輯的播放清單。從喜好項目中移除歌曲，也會從你可編輯的播放清單中移除該歌曲的所有出現項目。選取專輯不會個別儲存其中的歌曲。變更會套用到你的 Spotify 帳號，並可能顯示於其他 Spotify 用戶端。

播放佇列

Kinrox 在本機儲存播放佇列，並為佇列中的每一個項目啟動一個 Soloist 程序。它不會建立用於播放的輔助播放清單。現有的 Kinrox Queue 播放清單會保留在 Spotify 中。其非機密識別碼會保留在本機，以將這些清單排除於資料庫變更之外；您可以自行在 Spotify 中刪除這些清單。

Spotify 的權利

除非適用法律另有允許，你不得修改 Spotify 的平台、服務或內容，不得據此創作衍生著作，也不得對其進行反編譯、反組譯、逆向工程，或將其轉換為原始碼或其他人類可讀的形式。這些限制針對 Spotify 的資料，不限制 Kinrox 各元件授權條款授予的程式碼使用權，包括 Mac 播放器的 GPL 授權所授予的權利。

責任與保證

Kinrox 的維護者對 Kinrox 負責。在法律允許的範圍內，Spotify 和其他第三方對 Kinrox 不負任何責任。Kinrox 不代表 Spotify 作出承諾或保證。在法律允許的範圍內，排除有關 Spotify 平台、服務及內容的所有默示保證，包括適售性、特定用途適用性及不侵權保證。消費者的法定強制性權利不受影響。

隱私與條款執行

資料收集及使用受與這些條款一同顯示的隱私權政策約束。Spotify 是這些條款及該隱私權政策的第三方受益人，可直接要求履行這些條款。若要結束連線，請使用「設定 → Spotify → 中斷連線」。你也可以在 Spotify 帳號的應用程式頁面撤銷存取權限：https://www.spotify.com/account/apps/。

變更

Kinrox 重新連線前，必須接受這些連線條款的新版本。即使不接受 Spotify 連線條款，本機影片播放及區域網路遙控仍然可用。

存取與目的

接受條款並授權 Spotify 後，Mac 上的 Kinrox 會讀取你的帳號識別碼與顯示名稱、已儲存的歌曲與專輯、已追蹤的藝人、可存取的播放清單及其內容、播放狀態和可用裝置。這些資訊用於顯示資料庫及控制 Spotify。當你使用對應控制項時，它可以儲存或移除喜好項目、追蹤藝人、建立播放清單，以及編輯你擁有的或協作播放清單。移除喜好項目也會從可編輯的播放清單中移除其出現項目。

儲存與接收方

用於更新存取權限的憑證儲存在 Mac 的 Data Protection Keychain 中。 存取權杖保留在記憶體中。資料庫中繼資料會快取至 Mac App 的 Caches 資料夾中的本機 SQLite 資料庫。已驗證的帳號識別碼和顯示名稱儲存在 Mac 偏好設定中。 提供的 Client ID、輔助播放清單關聯及已接受的文件版本儲存在 Mac 偏好設定中。Kinrox 沒有伺服器、分析或遙測，維護者不會收到這些 Spotify 資料。Spotify 直接接收來自 Mac 的請求，並依其隱私權政策處理：https://www.spotify.com/legal/privacy-policy/。Spotify 會看到網路資訊，例如 Mac 的公用 IP 位址。 個人 Soloist API 金鑰儲存在鑰匙圈中。Connect 工作階段儲存在帳號的私有資料夾中；Soloist 使用獨立的音訊快取，上限為 200 MB。金鑰透過啟動引數傳遞給已簽署的 Soloist 程序，同一使用者帳號下的其他程序可以讀取這些引數。Soloist 的迴路控制通訊端沒有身分驗證或 Origin 檢查；能存取迴路介面的本機程式或網頁可以傳送播放命令。

iPhone 與連結

已配對的 iPhone 透過 Kinrox 的加密區域網路連線接收歌曲、專輯、藝人及播放清單中繼資料、佇列狀態和播放控制項。它絕不會收到 Spotify 憑證，也不會呼叫 Spotify Web API。點一下「在 Spotify 中開啟」後，iPhone 或 Mac 會在 Spotify 或其網站開啟對應項目。此跳轉可能使用網際網路，並受 Spotify 隱私權政策約束。遙控端中繼資料保留在記憶體中，並在中斷連線或重設來源或帳號時清除。

中斷連線與保留

在 Mac 上的 Kinrox 中，開啟「設定 → Spotify → 中斷連線」。 Kinrox 會停止其 Soloist 程序和請求，刪除更新憑證、Soloist API 金鑰以及自身的工作階段和音訊快取，並清除記憶體中的帳號資料。舊佇列播放清單的非機密識別碼和已下載的引擎會保留。自動重新連線也會停止。接受的版本是一項不關聯帳號的偏好設定。已在 Spotify 作出的變更，包括播放清單及喜好項目，仍會保留。中斷連線不會撤銷 Spotify 中的授權；若要撤銷，請在 https://www.spotify.com/account/apps/ 移除應用程式。你可以直接在 Spotify 中刪除保留的輔助播放清單。 快取的中繼資料若未重新驗證，將在 7 天後到期。中斷連線會自動刪除 SQLite 快取、其附屬檔案和已儲存的帳號關聯。

Cookie 與 Kinrox 一般資料

Kinrox 不加入分析或 Cookie。其 Spotify API 工作階段不使用持續性 Cookie 或磁碟回應快取。瀏覽器登入及 Spotify 網站可能使用自己的 Cookie；請在瀏覽器及 Spotify 隱私設定中管理。Kinrox 一般政策說明了本機檔案書籤、配對憑證、Sparkle 更新及 GitHub 託管。Spotify 是本政策及連線條款的第三方受益人。本補充政策的重大變更會在啟用新連線之前顯示。
