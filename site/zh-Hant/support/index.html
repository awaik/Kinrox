Kinrox 支持

Kinrox Remote 控制 Mac 上的 Kinrox 視訊播放器。它需要 iOS 17 或更高版本以及運行 Kinrox 的兼容 Mac。兩個設備必須位於同一本地網路上。 iPhone 應用程式不會播放或串流影片。

連接您的 iPhone

  1. 從官方發佈頁面下載 Mac 播放器並啟動。
  2. 在Mac上啟用Kinrox的遠端控制，然後開啟連接iPhone以顯示配對碼。
  3. 將 iPhone 連接到同一本地網絡，並在出現提示時允許兩個應用程式存取本地網路。
  4. 在Kinrox Remote中選擇Mac，然後輸入Mac上顯示的六位數代碼。如果代碼已過期，請使用新代碼。
  5. 在 Mac 上開啟本機影片。用 iPhone 暫停、跳到其他時間點、調整音量，或開啟仍可存取的最近檔案。

Mac沒有出現？

檢查 Kinrox 是否正在運作且遠端控制已啟用。檢查兩台裝置上的本機網路權限。訪客 Wi-Fi、用戶端隔離、VPN 和防火牆設定可以防止設備相互發現。嘗試使用相同的普通家庭網絡，並在配對時將兩個應用程式保持在前台。

嘗試沒有 Mac 的控制

開啟 Kinrox Remote 中的“設定”，然後選擇“在沒有 Mac 的情況下嘗試示範”。該演示使用虛構媒體，不連接或控制真實的 Mac。當您準備好配對時，請在「設定」中退出示範。

連接或最近的檔案問題

如果 Mac 上的配對已被撤銷，請使用新代碼再次配對。最近的檔案必須在 Mac 上仍然可用；無法從遠端開啟移動或刪除的檔案。下一個和上一個跟隨當前 Mac 資料夾中的視訊檔案。

聯絡方式

回報問題或尋求協助。包括您的 iOS 和 macOS 版本、Kinrox 版本、您嘗試過的操作以及錯誤訊息。請勿包含配對令牌、私人檔案名稱或其他敏感資訊。 GitHub 問題是公開的。
