Dasar Privasi

Berkesan apabila halaman ini diterbitkan. Dikemas kini pada 30 Oktober 2026.

Kinrox ialah pemain video tempatan untuk Mac dan alat kawalan jauh pendamping untuk iPhone. Apl tidak menghantar data peribadi, sejarah main balik atau analitis penggunaan kepada pembangun. Tiada akaun, SDK pengiklanan atau perkhidmatan awan dalam apl.

Data pada peranti anda

Pemain Mac menyimpan penanda halaman dan keutamaan fail terbaharu pada Mac anda. Alat jauh iPhone menyimpan pengecam peranti rawak, Mac yang dipilih dan pilihan sambungan pada iPhone anda. Bukti kelayakan berpasangan disimpan dalam Rantai Kunci setiap peranti. Alat kawalan jauh menerima status main balik dan tajuk dan tempoh fail terkini daripada Mac anda. Laluan sistem fail penuh dan fail video tidak dihantar ke iPhone.

Komunikasi rangkaian tempatan

Dengan kebenaran anda, Kinrox menemui pemain menggunakan Bonjour dan bertukar-tukar arahan kawalan dan maklumat main balik melalui rangkaian tempatan anda. Sesi berpasangan menggunakan penyulitan. Nama peranti dan perkhidmatan kelihatan semasa penemuan rangkaian tempatan; penemuan itu sendiri bukan saluran yang disulitkan. Apl tidak menggunakan pelayan geganti yang dikendalikan oleh pembangun.

Semakan kemas kini Mac

Bermula dengan versi 0.3.0, pemain Mac menggunakan Sparkle untuk membaca suapan kemas kini awam pada GitHub Pages sekali sehari dan apabila anda memilih Semak Kemas Kini. Semakan tidak termasuk pengecam peranti unik, sejarah main balik atau profil sistem. Apabila anda memilih untuk memasang kemas kini, Sparkle memuat turun pemasang yang ditandatangani daripada GitHub Releases. GitHub boleh memproses maklumat permintaan seperti alamat IP di bawah dasar privasinya. Main balik dan alat kawalan jauh iPhone tidak memerlukan akses internet.

Pengekalan dan pilihan anda

Bukti kelayakan berpasangan kekal sehingga anda mengalih keluarnya. Gunakan Lupakan dalam tetapan apl iPhone untuk mengalih keluar bukti kelayakan Mac yang disimpan daripada iPhone. Batalkan iPhone dalam tetapan jauh pemain Mac untuk mengalih keluar aksesnya pada Mac. Kedua-duanya ialah tindakan berasingan: melupakan Mac pada iPhone tidak membatalkan akses yang disimpan pada Mac. Anda boleh mengosongkan senarai fail terkini dalam pemain Mac. Anda boleh melumpuhkan akses Rangkaian Tempatan dalam tetapan sistem. Entri rantai kunci mungkin kekal semasa menyahpasang apl, jadi gunakan kawalan berpasangan sebelum menyahpasang jika anda ingin mengalih keluar bukti kelayakan yang disimpan.

Sokongan dan laman web ini

Jika anda memilih untuk menghubungi kami melalui GitHub Issues, maklumat yang anda serahkan dikendalikan oleh GitHub di bawah dasar privasinya dan mungkin terbuka. Jangan siarkan token gandingan, nama fail peribadi atau maklumat sensitif lain. Laman web ini dihoskan pada GitHub Pages; pembekal pengehosan boleh memproses maklumat permintaan seperti alamat IP di bawah Pernyataan Privasi GitHub. Kinrox tidak menambah skrip analitik atau kuki.

Kenalan dan perubahan

Untuk soalan privasi, hubungi penyelenggara melalui penjejak isu Kinrox. Kami akan mengemas kini halaman ini apabila pengendalian data apl berubah.
