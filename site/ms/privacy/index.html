Dasar Privasi

2026-11-01

Kinrox memainkan video setempat pada Mac dan menyediakan alat kawalan iPhone. Pembangun tidak menerima data peribadi, sejarah main balik atau analitik penggunaan.

Data pada peranti anda

Pemain Mac menyimpan penanda halaman dan keutamaan fail terbaharu pada Mac anda. Alat jauh iPhone menyimpan pengecam peranti rawak, Mac yang dipilih dan pilihan sambungan pada iPhone anda. Bukti kelayakan berpasangan disimpan dalam Rantai Kunci setiap peranti. Alat kawalan jauh menerima status main balik dan tajuk dan tempoh fail terkini daripada Mac anda. Laluan sistem fail penuh dan fail video tidak dihantar ke iPhone.

Komunikasi rangkaian tempatan

Dengan kebenaran anda, Kinrox menemui pemain menggunakan Bonjour dan bertukar-tukar arahan kawalan dan maklumat main balik melalui rangkaian tempatan anda. Sesi berpasangan menggunakan penyulitan. Nama peranti dan perkhidmatan kelihatan semasa penemuan rangkaian tempatan; penemuan itu sendiri bukan saluran yang disulitkan. Apl tidak menggunakan pelayan geganti yang dikendalikan oleh pembangun.

Semakan kemas kini Mac

Bermula dengan versi 0.3.0, pemain Mac menggunakan Sparkle untuk membaca suapan kemas kini awam pada GitHub Pages sekali sehari dan apabila anda memilih Semak Kemas Kini. Semakan tidak termasuk pengecam peranti unik, sejarah main balik atau profil sistem. Apabila anda memilih untuk memasang kemas kini, Sparkle memuat turun pemasang yang ditandatangani daripada GitHub Releases. GitHub boleh memproses maklumat permintaan seperti alamat IP di bawah dasar privasinya. Video setempat dan alat kawalan LAN berfungsi di luar talian. Kemas kini dan Spotify pilihan memerlukan internet.

Spotify

Spotify adalah pilihan dan hanya disambungkan pada Mac selepas log masuk menggunakan Client ID sendiri. Spotify Premium dan aplikasi rasmi Spotify pada Mac ini diperlukan. Kinrox menghantar permintaan pustaka, senarai main dan main balik terus kepada Spotify, yang memprosesnya menurut dasar privasinya. Bukti kelayakan pembaharuan kekal dalam Rantai Kunci Mac; metadata pustaka disimpan dalam memori. Kinrox mengurus satu senarai main peribadi Kinrox Queue. Memutuskan sambungan membuang bukti kelayakan setempat dan cache; senarai main kekal di Spotify sehingga anda membuangnya. iPhone menggunakan LAN untuk kawalan; mengetik Buka dalam Spotify boleh menggunakan internet. Tiada pelayan Kinrox atau analitik.

Akses Spotify: pustaka, main balik, kegemaran dan senarai main boleh sunting. Membuang kegemaran turut membuangnya daripada senarai main boleh sunting. Kelayakan disimpan dalam Rantai Kunci Mac. Memutuskan sambungan memadam data Spotify setempat dan mengekalkan senarai main Spotify. Tiada pelayan Kinrox atau analitik.

Syarat sambungan

Spotify · Dasar Privasi

Bahasa Melayu · 2026-11-01

Dasar privasi — sambungan Spotify

Versi 2026-11-01. Penyelenggara Kinrox, awaik, bertanggungjawab terhadap pemprosesan data Kinrox yang diterangkan di sini. Tambahan ini terpakai pada integrasi Spotify pilihan. Dasar privasi umum Kinrox tersedia di https://kinrox.app/privacy/. Hubungi: https://github.com/awaik/Kinrox/issues. Jangan siarkan token, kandungan pustaka peribadi atau maklumat peribadi lain dalam laporan isu awam.

Akses dan tujuan

Selepas anda menerima syarat dan memberikan kebenaran Spotify, Kinrox pada Mac membaca pengecam dan nama paparan akaun anda, lagu dan album tersimpan, artis yang diikuti, senarai main yang boleh diakses serta kandungannya, status main balik dan peranti tersedia. Maklumat ini digunakan untuk memaparkan pustaka anda dan mengawal Spotify. Apabila anda menggunakan kawalan berkenaan, ia boleh menyimpan dan mengalih keluar kegemaran, mengikuti artis, mencipta senarai main serta menyunting senarai main milik anda atau kolaboratif. Mengalih keluar kegemaran turut mengalih keluar kemunculannya daripada senarai main boleh sunting. Kinrox menyelenggara senarai main peribadi Kinrox Queue untuk main balik.

Penyimpanan dan penerima

Bukti kelayakan pembaharuan disimpan dalam Data Protection Keychain Mac. Token akses, butiran akaun dan metadata pustaka kekal dalam memori aplikasi. Client ID yang diberikan, kaitan senarai main pembantu dan versi dokumen yang diterima disimpan dalam keutamaan Mac. Kinrox tidak mempunyai pelayan, analitik atau telemetri dan penyelenggaranya tidak menerima sebarang data Spotify ini. Spotify menerima permintaan terus daripada Mac dan mengendalikannya mengikut dasar privasinya: https://www.spotify.com/legal/privacy-policy/. Spotify melihat maklumat rangkaian seperti alamat IP awam Mac.

iPhone dan pautan

iPhone yang dipasangkan menerima metadata lagu, album, artis dan senarai main, status baris gilir serta kawalan main balik melalui sambungan rangkaian setempat Kinrox yang disulitkan. Ia tidak pernah menerima bukti kelayakan Spotify atau memanggil Spotify Web API. Jika anda mengetik Buka dalam Spotify, iPhone atau Mac membuka item berkaitan dalam Spotify atau laman webnya. Penyerahan ini boleh menggunakan internet dan tertakluk pada dasar privasi Spotify. Metadata alat kawalan jauh disimpan dalam memori dan dipadam apabila sambungan terputus atau sumber atau akaun ditetapkan semula.

Pemutusan sambungan dan pengekalan

Dalam Kinrox pada Mac, buka Seting → Spotify → Putuskan Sambungan. Kinrox menyelesaikan kerja main balik tertunda, menghentikan permintaan, mengalih keluar bukti kelayakan pembaharuan dan kaitan setempat senarai main pembantu, serta mengosongkan status akaun dan pustaka daripada memori. Penyambungan semula automatik dihentikan. Versi penerimaan ialah keutamaan yang tidak terikat pada akaun. Perubahan yang telah dibuat dalam Spotify, termasuk senarai main dan kegemaran, kekal di sana. Memutuskan sambungan tidak membatalkan kebenaran di Spotify; alih keluar aplikasi di https://www.spotify.com/account/apps/ untuk membatalkannya. Anda boleh memadam senarai main pembantu yang dikekalkan terus dalam Spotify.

Kuki dan data umum Kinrox

Kinrox tidak menambahkan analitik atau kuki. Sesi API Spotify-nya tidak menggunakan kuki berterusan atau cache respons pada cakera. Log masuk pelayar dan laman web Spotify mungkin menggunakan kuki sendiri; uruskannya dalam pelayar dan seting privasi Spotify. Dasar umum Kinrox menerangkan penanda buku fail setempat, bukti kelayakan pemasangan, kemas kini Sparkle dan pengehosan GitHub. Spotify ialah benefisiari pihak ketiga bagi dasar ini dan syarat sambungan. Perubahan penting pada tambahan ini akan dipaparkan sebelum sambungan baharu diaktifkan.

Pengekalan dan pilihan anda

Bukti kelayakan berpasangan kekal sehingga anda mengalih keluarnya. Gunakan Lupakan dalam tetapan apl iPhone untuk mengalih keluar bukti kelayakan Mac yang disimpan daripada iPhone. Batalkan iPhone dalam tetapan jauh pemain Mac untuk mengalih keluar aksesnya pada Mac. Kedua-duanya ialah tindakan berasingan: melupakan Mac pada iPhone tidak membatalkan akses yang disimpan pada Mac. Anda boleh mengosongkan senarai fail terkini dalam pemain Mac. Anda boleh melumpuhkan akses Rangkaian Tempatan dalam tetapan sistem. Entri rantai kunci mungkin kekal semasa menyahpasang apl, jadi gunakan kawalan berpasangan sebelum menyahpasang jika anda ingin mengalih keluar bukti kelayakan yang disimpan.

Sokongan dan laman web ini

Jika anda memilih untuk menghubungi kami melalui GitHub Issues, maklumat yang anda serahkan dikendalikan oleh GitHub di bawah dasar privasinya dan mungkin terbuka. Jangan siarkan token gandingan, nama fail peribadi atau maklumat sensitif lain. Laman web ini dihoskan pada GitHub Pages; pembekal pengehosan boleh memproses maklumat permintaan seperti alamat IP di bawah Pernyataan Privasi GitHub. Kinrox tidak menambah skrip analitik atau kuki.

Kenalan dan perubahan

Untuk soalan privasi, hubungi penyelenggara melalui penjejak isu Kinrox. Kami akan mengemas kini halaman ini apabila pengendalian data apl berubah.
