连接条款

Spotify 访问权限：音乐库、播放、收藏和可编辑的播放列表。取消收藏也会从可编辑的播放列表中移除该曲目。 登录凭据保存在 Mac 钥匙串中。断开连接会清除本地 Spotify 数据，但保留 Spotify 播放列表。没有 Kinrox 服务器或使用分析。

Spotify 连接条款

在 Kinrox 中启用 Spotify 时，适用这些条款。Kinrox 由 awaik 维护（https://github.com/awaik/Kinrox）；支持和隐私问题请联系：https://github.com/awaik/Kinrox/issues。Kinrox 独立于 Spotify，未经 Spotify 背书。你在应用中接受后，这些条款即生效。

你的账户与选择

连接是可选的。请使用自己的 Spotify 开发者应用和获准使用的 Spotify Premium 账户。Spotify 控制 API 访问权限和配额；访问权限可能变化或终止。Spotify 自身的条款仍然适用。 音频通过 Spotify Soloist 播放。应您的请求，Soloist 会直接从 Spotify 下载到 Mac。每位用户须提供个人 Soloist API 密钥。首次配对使用 iPhone 上的 Spotify；之后，即使 Mac 和 iPhone 上的 Spotify 均已退出，也能播放。Soloist 负责解码并管理自身的音频缓存；Kinrox 不录制或导出音频。Soloist 构建版本会在 90 天后过期，届时需要更新。

资料库更改

你的操作可以保存或移除歌曲和专辑、关注或取消关注艺人、创建播放列表，以及更改你拥有或有权编辑的播放列表。从收藏中移除歌曲，也会从你可编辑的播放列表中移除该歌曲的所有出现项。选择专辑不会单独保存其中的歌曲。更改会应用到你的 Spotify 账户，并可能在其他 Spotify 客户端中显示。

播放队列

Kinrox 在本地保存播放队列，并为队列中的每一项启动一个 Soloist 进程。它不会创建用于播放的辅助播放列表。现有的 Kinrox Queue 播放列表会保留在 Spotify 中。其非机密标识符会保存在本地，以将这些列表排除在曲库修改之外；您可以自行在 Spotify 中删除这些列表。

Spotify 的权利

除非适用法律另有允许，你不得修改 Spotify 的平台、服务或内容，不得据此创作衍生作品，也不得对其进行反编译、反汇编、逆向工程，或将其转换为源代码或其他人类可读的形式。这些限制针对 Spotify 的材料，不限制 Kinrox 各组件许可证授予的代码使用权，包括 Mac 播放器的 GPL 许可证所授予的权利。

责任与保证

Kinrox 的维护者对 Kinrox 负责。在法律允许的范围内，Spotify 和其他第三方对 Kinrox 不承担任何责任。Kinrox 不代表 Spotify 作出承诺或保证。在法律允许的范围内，排除有关 Spotify 平台、服务及内容的所有默示保证，包括适销性、特定用途适用性和不侵权保证。消费者的法定强制性权利不受影响。

隐私与条款执行

数据收集和使用受与这些条款一同显示的隐私政策约束。Spotify 是这些条款及该隐私政策的第三方受益人，可以直接要求执行这些条款。要结束连接，请使用“设置 → Spotify → 断开连接”。你也可以在 Spotify 账户的应用页面撤销访问权限：https://www.spotify.com/account/apps/。

变更

Kinrox 重新连接前，必须接受这些连接条款的新版本。即使不接受 Spotify 连接条款，本地视频播放和局域网遥控仍然可用。

隐私政策 — Spotify 连接

版本 2026-11-10。Kinrox 的维护者 awaik 对此处所述的 Kinrox 数据处理负责。本补充政策适用于可选的 Spotify 集成。Kinrox 通用隐私政策见 https://kinrox.app/privacy/。联系方式：https://github.com/awaik/Kinrox/issues。请勿在公开问题报告中发布令牌、个人资料库内容或其他私人信息。

访问与目的

接受条款并授权 Spotify 后，Mac 上的 Kinrox 会读取你的账户标识符和显示名称、已保存的歌曲和专辑、已关注的艺人、可访问的播放列表及其内容、播放状态和可用设备。这些信息用于显示资料库和控制 Spotify。当你使用相应控件时，它可以保存或移除收藏、关注艺人、创建播放列表，以及编辑你拥有的或协作播放列表。移除收藏也会从可编辑的播放列表中移除其出现项。 通过 ListenBrainz / MusicBrainz（MetaBrainz Foundation）查找相似音乐的功能在连接 Spotify 后默认开启，可随时在 Mac 上的 Kinrox 中通过「设置 → Spotify」关闭。开启时，艺人姓名、曲目名称、ISRC 和 MBID 会发送给这些服务以查找相似音乐；不会发送用户标识或 Cookie。关闭时不会发送任何请求。

存储与接收方

用于刷新访问权限的凭据存储在 Mac 的 Data Protection Keychain 中。 访问令牌保留在内存中。资料库元数据缓存在 Mac 应用 Caches 文件夹中的本地 SQLite 数据库内。已验证的账户标识符和显示名称存储在 Mac 偏好设置中。 提供的 Client ID、辅助播放列表关联和已接受的文档版本存储在 Mac 偏好设置中。Kinrox 没有服务器、分析或遥测，维护者不会收到这些 Spotify 数据。Spotify 直接接收来自 Mac 的请求，并根据其隐私政策进行处理：https://www.spotify.com/legal/privacy-policy/。Spotify 会看到网络信息，例如 Mac 的公网 IP 地址。 个人 Soloist API 密钥保存在钥匙串中。Connect 会话保存在账户的私有文件夹中；Soloist 使用独立的音频缓存，上限为 200 MB。密钥通过启动参数传递给已签名的 Soloist 进程，同一用户账户下的其他进程可以读取这些参数。Soloist 的回环控制套接字没有身份验证或 Origin 检查；能够访问回环接口的本地程序或网页可以发送播放命令。 额外的本地 SQLite 缓存将发现结果保留 24 小时，相似性数据保留 7 天，MBID 映射保留 30 天。收听历史仅保存在 Mac 上，最多保留 180 天和 20,000 次播放记录，绝不会发送给外部服务或 iPhone。断开连接会删除这些缓存和历史记录。

iPhone 与链接

已配对的 iPhone 通过 Kinrox 的加密局域网连接接收歌曲、专辑、艺人和播放列表元数据、队列状态及播放控件。它绝不会收到 Spotify 凭据，也不会调用 Spotify Web API。点击“在 Spotify 中打开”后，iPhone 或 Mac 会在 Spotify 或其网站中打开对应项目。此跳转可能使用互联网，并受 Spotify 隐私政策约束。遥控端元数据保存在内存中，在断开连接或重置来源或账户时清除。

断开连接与保留

在 Mac 上的 Kinrox 中，打开“设置 → Spotify → 断开连接”。 Kinrox 会停止其 Soloist 进程和请求，删除刷新凭据、Soloist API 密钥以及自身的会话和音频缓存，并清除内存中的账户数据。旧队列播放列表的非机密标识符和已下载的引擎会保留。自动重新连接也会停止。接受的版本是一项不关联账户的偏好设置。已在 Spotify 中作出的更改，包括播放列表和收藏，仍会保留。断开连接不会撤销 Spotify 中的授权；要撤销，请在 https://www.spotify.com/account/apps/ 移除应用。你可以直接在 Spotify 中删除保留的辅助播放列表。 缓存的元数据如未重新验证，将在 7 天后过期。断开连接会自动删除 SQLite 缓存、其附属文件和已保存的账户关联。

Cookie 与 Kinrox 通用数据

Kinrox 不添加分析或 Cookie。其 Spotify API 会话不使用持久 Cookie 或磁盘响应缓存。浏览器登录和 Spotify 网站可能使用自己的 Cookie；请在浏览器和 Spotify 隐私设置中管理。Kinrox 通用政策说明了本地文件书签、配对凭据、Sparkle 更新和 GitHub 托管。Spotify 是本政策及连接条款的第三方受益人。本补充政策的重大变更会在启用新连接之前显示。
