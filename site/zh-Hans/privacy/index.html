隐私政策

2026-11-01

Kinrox 在 Mac 上播放本地视频，并提供 iPhone 遥控器。开发者不会收到个人数据、播放历史或使用分析。

您设备上的数据

Mac 播放器在 Mac 上存储最近的文件书签和首选项。 iPhone 遥控器会在您的 iPhone 上存储随机设备标识符、选定的 Mac 和连接首选项。配对凭据存储在每个设备的钥匙串中。遥控器从 Mac 接收播放状态以及最近文件的标题和持续时间。完整的文件系统路径和视频文件不会传输到 iPhone。

本地网络通讯

在您的许可下，Kinrox 会发现使用 Bonjour 的播放器，并通过您的本地网络交换控制命令和播放信息。配对会话使用加密。设备和服务名称在本地网络发现期间可见；发现本身并不是一个加密通道。这些应用程序不使用开发人员操作的中继服务器。

Mac更新检查

从版本 0.3.0 开始，Mac 播放器使用 Sparkle 每天一次以及当您选择“检查更新”时读取 GitHub Pages 上的公共更新源。检查不包括唯一的设备标识符、播放历史记录或系统配置文件。当您选择安装更新时，Sparkle 会从 GitHub Releases 下载签名的安装程序。 GitHub可能会根据其隐私政策处理IP地址等请求信息。 本地视频和局域网遥控可离线使用。更新和可选的 Spotify 功能需要互联网。

Spotify

连接是可选的。请使用自己的 Spotify 开发者应用和获准使用的 Spotify Premium 账户。Spotify 控制 API 访问权限和配额；访问权限可能变化或终止。Spotify 自身的条款仍然适用。 音频通过 Spotify Soloist 播放。应您的请求，Soloist 会直接从 Spotify 下载到 Mac。每位用户须提供个人 Soloist API 密钥。首次配对使用 iPhone 上的 Spotify；之后，即使 Mac 和 iPhone 上的 Spotify 均已退出，也能播放。Soloist 负责解码并管理自身的音频缓存；Kinrox 不录制或导出音频。Soloist 构建版本会在 90 天后过期，届时需要更新。

Spotify 访问权限：音乐库、播放、收藏和可编辑的播放列表。取消收藏也会从可编辑的播放列表中移除该曲目。 登录凭据保存在 Mac 钥匙串中。断开连接会清除本地 Spotify 数据，但保留 Spotify 播放列表。没有 Kinrox 服务器或使用分析。

隐私政策 — Spotify 连接

版本 2026-11-03。Kinrox 的维护者 awaik 对此处所述的 Kinrox 数据处理负责。本补充政策适用于可选的 Spotify 集成。Kinrox 通用隐私政策见 https://kinrox.app/privacy/。联系方式：https://github.com/awaik/Kinrox/issues。请勿在公开问题报告中发布令牌、个人资料库内容或其他私人信息。

访问与目的

接受条款并授权 Spotify 后，Mac 上的 Kinrox 会读取你的账户标识符和显示名称、已保存的歌曲和专辑、已关注的艺人、可访问的播放列表及其内容、播放状态和可用设备。这些信息用于显示资料库和控制 Spotify。当你使用相应控件时，它可以保存或移除收藏、关注艺人、创建播放列表，以及编辑你拥有的或协作播放列表。移除收藏也会从可编辑的播放列表中移除其出现项。

存储与接收方

用于刷新访问权限的凭据存储在 Mac 的 Data Protection Keychain 中。 访问令牌保留在内存中。资料库元数据缓存在 Mac 应用 Caches 文件夹中的本地 SQLite 数据库内。已验证的账户标识符和显示名称存储在 Mac 偏好设置中。 提供的 Client ID、辅助播放列表关联和已接受的文档版本存储在 Mac 偏好设置中。Kinrox 没有服务器、分析或遥测，维护者不会收到这些 Spotify 数据。Spotify 直接接收来自 Mac 的请求，并根据其隐私政策进行处理：https://www.spotify.com/legal/privacy-policy/。Spotify 会看到网络信息，例如 Mac 的公网 IP 地址。 个人 Soloist API 密钥保存在钥匙串中。Connect 会话保存在账户的私有文件夹中；Soloist 使用独立的音频缓存，上限为 200 MB。密钥通过启动参数传递给已签名的 Soloist 进程，同一用户账户下的其他进程可以读取这些参数。Soloist 的回环控制套接字没有身份验证或 Origin 检查；能够访问回环接口的本地程序或网页可以发送播放命令。

iPhone 与链接

已配对的 iPhone 通过 Kinrox 的加密局域网连接接收歌曲、专辑、艺人和播放列表元数据、队列状态及播放控件。它绝不会收到 Spotify 凭据，也不会调用 Spotify Web API。点击“在 Spotify 中打开”后，iPhone 或 Mac 会在 Spotify 或其网站中打开对应项目。此跳转可能使用互联网，并受 Spotify 隐私政策约束。遥控端元数据保存在内存中，在断开连接或重置来源或账户时清除。

断开连接与保留

在 Mac 上的 Kinrox 中，打开“设置 → Spotify → 断开连接”。 Kinrox 会停止其 Soloist 进程和请求，删除刷新凭据、Soloist API 密钥以及自身的会话和音频缓存，并清除内存中的账户数据。旧队列播放列表的非机密标识符和已下载的引擎会保留。自动重新连接也会停止。接受的版本是一项不关联账户的偏好设置。已在 Spotify 中作出的更改，包括播放列表和收藏，仍会保留。断开连接不会撤销 Spotify 中的授权；要撤销，请在 https://www.spotify.com/account/apps/ 移除应用。你可以直接在 Spotify 中删除保留的辅助播放列表。 缓存的元数据如未重新验证，将在 7 天后过期。断开连接会自动删除 SQLite 缓存、其附属文件和已保存的账户关联。

Cookie 与 Kinrox 通用数据

Kinrox 不添加分析或 Cookie。其 Spotify API 会话不使用持久 Cookie 或磁盘响应缓存。浏览器登录和 Spotify 网站可能使用自己的 Cookie；请在浏览器和 Spotify 隐私设置中管理。Kinrox 通用政策说明了本地文件书签、配对凭据、Sparkle 更新和 GitHub 托管。Spotify 是本政策及连接条款的第三方受益人。本补充政策的重大变更会在启用新连接之前显示。

保留和您的选择

配对凭据会一直保留，直到您将其删除为止。 使用 iPhone 应用程序设置中的“忘记”从 iPhone 中删除 Mac 保存的凭据。 在Mac播放器的远程设置中撤销iPhone，以删除其对Mac的访问权限。 这两个操作相互独立：在 iPhone 上忘记 Mac，不会撤销 Mac 上保存的授权。你可以在 Mac 播放器中清空最近文件列表。 您可以在系统设置中禁用本地网络访问。 钥匙串条目可能会在卸载应用程序后继续存在，因此如果您想删除保存的凭据，请在卸载之前使用配对控件。

支持和这个网站

如果您选择通过 GitHub Issues 联系我们，您提交的信息将由 GitHub 根据其隐私政策处理，并且可能是公开的。请勿发布配对令牌、私人文件名或其他敏感信息。本网站托管于GitHub Pages；托管提供商可以根据 GitHub 的隐私声明 处理请求信息，例如 IP 地址。 Kinrox 不添加分析脚本或 cookie。

联系方式及变更

对于隐私问题，请通过 Kinrox 问题跟踪器 联系维护人员。当应用程序的数据处理发生变化时，我们将更新此页面。
