隐私政策

此页面发布后生效。更新于 2026 年 10 月 30 日。

Kinrox 是 Mac 的本地视频播放器和 iPhone 的配套遥控器。这些应用程序不会向开发者发送个人数据、播放历史记录或使用情况分析。应用程序中没有帐户、广告 SDK 或云服务。

您设备上的数据

Mac 播放器在 Mac 上存储最近的文件书签和首选项。 iPhone 遥控器会在您的 iPhone 上存储随机设备标识符、选定的 Mac 和连接首选项。配对凭据存储在每个设备的钥匙串中。遥控器从 Mac 接收播放状态以及最近文件的标题和持续时间。完整的文件系统路径和视频文件不会传输到 iPhone。

本地网络通讯

在您的许可下，Kinrox 会发现使用 Bonjour 的播放器，并通过您的本地网络交换控制命令和播放信息。配对会话使用加密。设备和服务名称在本地网络发现期间可见；发现本身并不是一个加密通道。这些应用程序不使用开发人员操作的中继服务器。

Mac更新检查

从版本 0.3.0 开始，Mac 播放器使用 Sparkle 每天一次以及当您选择“检查更新”时读取 GitHub Pages 上的公共更新源。检查不包括唯一的设备标识符、播放历史记录或系统配置文件。当您选择安装更新时，Sparkle 会从 GitHub Releases 下载签名的安装程序。 GitHub可能会根据其隐私政策处理IP地址等请求信息。播放和 iPhone 远程控制不需要互联网连接。

保留和您的选择

配对凭据会一直保留，直到您将其删除为止。 使用 iPhone 应用程序设置中的“忘记”从 iPhone 中删除 Mac 保存的凭据。 在Mac播放器的远程设置中撤销iPhone，以删除其对Mac的访问权限。 这两个操作相互独立：在 iPhone 上忘记 Mac，不会撤销 Mac 上保存的授权。你可以在 Mac 播放器中清空最近文件列表。 您可以在系统设置中禁用本地网络访问。 钥匙串条目可能会在卸载应用程序后继续存在，因此如果您想删除保存的凭据，请在卸载之前使用配对控件。

支持和这个网站

如果您选择通过 GitHub Issues 联系我们，您提交的信息将由 GitHub 根据其隐私政策处理，并且可能是公开的。请勿发布配对令牌、私人文件名或其他敏感信息。本网站托管于GitHub Pages；托管提供商可以根据 GitHub 的隐私声明 处理请求信息，例如 IP 地址。 Kinrox 不添加分析脚本或 cookie。

联系方式及变更

对于隐私问题，请通过 Kinrox 问题跟踪器 联系维护人员。当应用程序的数据处理发生变化时，我们将更新此页面。
