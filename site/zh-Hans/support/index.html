Kinrox 支持

Kinrox Remote 控制 Mac 上的 Kinrox 视频播放器。它需要 iOS 17 或更高版本以及运行 Kinrox 的兼容 Mac。两个设备必须位于同一本地网络上。 iPhone 应用程序不播放或流式传输视频。

连接您的 iPhone

  1. 从官方发布页面下载 Mac 播放器并启动。
  2. 在Mac上启用Kinrox的远程控制，然后打开连接iPhone以显示配对码。
  3. 将 iPhone 连接到同一本地网络，并在出现提示时允许两个应用程序访问本地网络。
  4. 在Kinrox Remote中选择Mac，然后输入Mac上显示的六位代码。如果代码已过期，请使用新代码。
  5. 在 Mac 上打开本地视频。用 iPhone 暂停、跳转到其他时间点、调节音量，或打开仍可访问的最近文件。

Mac没有出现？

检查 Kinrox 是否正在运行且远程控制已启用。检查两台设备上的本地网络权限。访客 Wi-Fi、客户端隔离、VPN 和防火墙设置可以防止设备相互发现。尝试使用相同的普通家庭网络，并在配对时将两个应用程序保持在前台。

尝试没有 Mac 的控制

打开 Kinrox Remote 中的“设置”，然后选择“在没有 Mac 的情况下尝试演示”。该演示使用虚构媒体，不连接或控制真实的 Mac。当您准备好配对时，请在“设置”中退出演示。

连接或最近的文件问题

如果 Mac 上的配对已被撤销，请使用新代码再次配对。最近的文件必须在 Mac 上仍然可用；无法从远程打开移动或删除的文件。下一个和上一个跟随当前 Mac 文件夹中的视频文件。

联系方式

报告问题或寻求帮助。包括您的 iOS 和 macOS 版本、Kinrox 版本、您尝试过的操作以及错误消息。请勿包含配对令牌、私人文件名或其他敏感信息。 GitHub 问题是公开的。
