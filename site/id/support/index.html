Dukungan Kinrox

Kinrox Remote mengontrol pemutar video Kinrox di Mac. Ini memerlukan iOS 17 atau lebih baru dan Mac yang kompatibel yang menjalankan Kinrox. Kedua perangkat harus berada di jaringan lokal yang sama. Aplikasi iPhone tidak memutar atau melakukan streaming video.

Hubungkan iPhone Anda

  1. Unduh pemutar Mac dari rilis resmi, lalu jalankan.
  2. Aktifkan remote control di Kinrox pada Mac, lalu buka Hubungkan iPhone untuk menampilkan kode penyandingan.
  3. Hubungkan iPhone ke jaringan lokal yang sama dan izinkan akses Jaringan Lokal untuk kedua aplikasi saat diminta.
  4. Pilih Mac di Kinrox Remote dan masukkan kode enam digit yang ditunjukkan pada Mac. Gunakan kode baru jika sudah habis masa berlakunya.
  5. Buka video lokal di Mac. Gunakan iPhone untuk menjeda, berpindah ke waktu lain dalam video, mengatur volume, atau membuka file terbaru yang masih tersedia.

Mac tidak muncul?

Periksa apakah Kinrox berjalan dan kendali jarak jauh diaktifkan. Periksa izin Jaringan Lokal di kedua perangkat. Wi-Fi tamu, isolasi klien, VPN, dan pengaturan firewall dapat mencegah perangkat menemukan satu sama lain. Coba jaringan rumah normal yang sama dan pertahankan kedua aplikasi di latar depan saat memasangkan.

Coba kontrol tanpa Mac

Buka Pengaturan di Kinrox Remote dan pilih Coba Demo tanpa Mac. Demo ini menggunakan media fiksi dan tidak terhubung ke atau mengontrol Mac asli. Keluar dari demo di Pengaturan saat Anda siap memasangkan.

Masalah koneksi atau file terbaru

Jika pemasangan pada Mac telah dicabut, pasangkan kembali menggunakan kode baru. File terbaru harus masih tersedia di Mac; file yang dipindahkan atau dihapus tidak dapat dibuka dari jarak jauh. Berikutnya dan Sebelumnya ikuti file video di folder Mac saat ini.

Kontak

Laporkan masalah atau minta bantuan. Sertakan versi iOS dan macOS Anda, versi Kinrox, apa yang Anda coba dan pesan kesalahannya. Jangan sertakan token pemasangan, nama file pribadi, atau informasi sensitif lainnya. Masalah GitHub bersifat publik.
