Kebijakan Privasi

Efektif ketika halaman ini diterbitkan. Diperbarui 30 Oktober 2026.

Kinrox adalah pemutar video lokal untuk Mac dan remote pendamping untuk iPhone. Aplikasi tidak mengirimkan data pribadi, riwayat pemutaran, atau analisis penggunaan kepada pengembang. Tidak ada akun, SDK iklan, atau layanan cloud di aplikasi.

Data di perangkat Anda

Pemutar Mac menyimpan bookmark dan preferensi file terbaru di Mac Anda. Remote iPhone menyimpan pengidentifikasi perangkat acak, Mac yang dipilih, dan preferensi koneksi di iPhone Anda. Kredensial penyandingan disimpan di Rantai Kunci setiap perangkat. Remote menerima status pemutaran serta judul dan durasi file terbaru dari Mac Anda. Jalur sistem file lengkap dan file video tidak dikirimkan ke iPhone.

Komunikasi jaringan lokal

Dengan izin Anda, Kinrox menemukan pemain menggunakan Bonjour dan bertukar perintah kontrol dan informasi pemutaran melalui jaringan lokal Anda. Sesi berpasangan menggunakan enkripsi. Nama perangkat dan layanan terlihat selama penemuan jaringan lokal; penemuan itu sendiri bukanlah saluran terenkripsi. Aplikasi tidak menggunakan server relai yang dioperasikan pengembang.

Pemeriksaan pembaruan Mac

Dimulai dengan versi 0.3.0, pemain Mac menggunakan Sparkle untuk membaca feed pembaruan publik pada GitHub Pages sekali sehari dan ketika Anda memilih Periksa Pembaruan. Pemeriksaan tidak mencakup pengidentifikasi perangkat unik, riwayat pemutaran, atau profil sistem. Saat Anda memilih untuk memasang pembaruan, Sparkle unduh pemasang yang ditandatangani dari GitHub Releases. GitHub dapat memproses informasi permintaan seperti alamat IP berdasarkan kebijakan privasinya. Pemutaran dan kendali jarak jauh melalui iPhone tidak memerlukan akses internet.

Retensi dan pilihan Anda

Kredensial penyandingan tetap ada sampai Anda menghapusnya. Gunakan Lupakan di setelan aplikasi iPhone untuk menghapus kredensial tersimpan Mac tersebut dari iPhone. Cabut iPhone di setelan jarak jauh pemutar Mac untuk menghapus aksesnya di Mac. Keduanya adalah tindakan terpisah: melupakan Mac di iPhone tidak mencabut akses yang tersimpan di Mac. Anda dapat mengosongkan daftar file terbaru di pemutar Mac. Anda dapat menonaktifkan akses Jaringan Lokal di pengaturan sistem. Entri rantai kunci mungkin tetap bertahan saat mencopot pemasangan aplikasi, jadi gunakan kontrol penyandingan sebelum mencopot pemasangan jika Anda ingin menghapus kredensial yang disimpan.

Dukungan dan situs web ini

Jika Anda memilih untuk menghubungi kami melalui GitHub Issues, informasi yang Anda kirimkan akan ditangani oleh GitHub berdasarkan kebijakan privasinya dan mungkin bersifat publik. Jangan memposting token pasangan, nama file pribadi, atau informasi sensitif lainnya. Situs web ini dihosting pada GitHub Pages; penyedia hosting dapat memproses informasi permintaan seperti alamat IP berdasarkan GitHub Pernyataan Privasi. Kinrox tidak menambahkan skrip atau cookie analisis.

Kontak dan perubahan

Untuk pertanyaan privasi, hubungi pengelola melalui Kinrox pelacak masalah. Kami akan memperbarui halaman ini ketika penanganan data aplikasi berubah.
