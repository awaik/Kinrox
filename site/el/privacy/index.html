Πολιτική απορρήτου

Ισχύει όταν δημοσιεύεται αυτή η σελίδα. Ενημερώθηκε στις 30 Οκτωβρίου 2026.

Το Kinrox είναι ένα τοπικό πρόγραμμα αναπαραγωγής βίντεο για το Mac και ένα συνοδευτικό τηλεχειριστήριο για το iPhone. Οι εφαρμογές δεν στέλνουν προσωπικά δεδομένα, ιστορικό αναπαραγωγής ή αναλυτικά στοιχεία χρήσης στον προγραμματιστή. Δεν υπάρχουν λογαριασμοί, διαφημιστικά SDK ή υπηρεσίες cloud στις εφαρμογές.

Δεδομένα στις συσκευές σας

Το πρόγραμμα αναπαραγωγής Mac αποθηκεύει σελιδοδείκτες και προτιμήσεις πρόσφατων αρχείων στο Mac σας. Το τηλεχειριστήριο iPhone αποθηκεύει ένα τυχαίο αναγνωριστικό συσκευής, το επιλεγμένο Mac και τις προτιμήσεις σύνδεσης στο iPhone σας. Τα διαπιστευτήρια σύζευξης αποθηκεύονται στο Keychain κάθε συσκευής. Το τηλεχειριστήριο λαμβάνει την κατάσταση αναπαραγωγής και τους πρόσφατους τίτλους και τις διάρκειες αρχείων από το Mac σας. Οι πλήρεις διαδρομές συστήματος αρχείων και τα αρχεία βίντεο δεν μεταδίδονται στο iPhone.

Επικοινωνία τοπικού δικτύου

Με την άδειά σας, το Kinrox εντοπίζει προγράμματα αναπαραγωγής μέσω Bonjour και ανταλλάσσει εντολές ελέγχου και πληροφορίες αναπαραγωγής στο τοπικό σας δίκτυο. Οι συνεδρίες συζευγμένων συσκευών είναι κρυπτογραφημένες. Τα ονόματα συσκευών και υπηρεσιών είναι ορατά κατά τον εντοπισμό στο τοπικό δίκτυο· ο ίδιος ο εντοπισμός δεν είναι κρυπτογραφημένο κανάλι. Οι εφαρμογές δεν χρησιμοποιούν διακομιστή αναμετάδοσης του δημιουργού.

Mac έλεγχοι ενημέρωσης

Ξεκινώντας με την έκδοση 0.3.0, το πρόγραμμα αναπαραγωγής Mac χρησιμοποιεί το Sparkle για να διαβάζει τη δημόσια ροή ενημερώσεων στο GitHub Pages μία φορά την ημέρα και όταν επιλέγετε Έλεγχος για ενημερώσεις. Οι έλεγχοι δεν περιλαμβάνουν μοναδικά αναγνωριστικά συσκευής, ιστορικό αναπαραγωγής ή προφίλ συστήματος. Όταν επιλέγετε να εγκαταστήσετε μια ενημέρωση, Sparkle κατεβάζει το υπογεγραμμένο πρόγραμμα εγκατάστασης από το GitHub Releases. Το GitHub μπορεί να επεξεργάζεται πληροφορίες αιτήματος, όπως διευθύνσεις IP στο πλαίσιο της πολιτικής απορρήτου του. Η αναπαραγωγή και το τηλεχειριστήριο iPhone ​​δεν απαιτούν πρόσβαση στο διαδίκτυο.

Διατήρηση και οι επιλογές σας

Τα διαπιστευτήρια σύζευξης παραμένουν μέχρι να τα καταργήσετε. Χρησιμοποιήστε το Forget στις ρυθμίσεις της εφαρμογής iPhone για να καταργήσετε τα αποθηκευμένα διαπιστευτήρια αυτού του Mac από το iPhone. Ανακαλέστε το iPhone στις απομακρυσμένες ρυθμίσεις του προγράμματος αναπαραγωγής Mac για να καταργήσετε την πρόσβασή του στο Mac. Αυτές είναι ξεχωριστές ενέργειες: η διαγραφή του Mac από το iPhone δεν ανακαλεί την πρόσβαση που έχει αποθηκευτεί στο Mac. Μπορείτε να αδειάσετε τη λίστα πρόσφατων αρχείων στο πρόγραμμα αναπαραγωγής του Mac. Μπορείτε να απενεργοποιήσετε την πρόσβαση στο τοπικό δίκτυο στις ρυθμίσεις συστήματος. Οι καταχωρίσεις Keychain ενδέχεται να επιβιώσουν κατά την απεγκατάσταση μιας εφαρμογής, επομένως χρησιμοποιήστε τα στοιχεία ελέγχου σύζευξης πριν από την απεγκατάσταση, εάν θέλετε να καταργήσετε τα αποθηκευμένα διαπιστευτήρια.

Υποστήριξη και αυτόν τον ιστότοπο

Εάν επιλέξετε να επικοινωνήσετε μαζί μας μέσω του GitHub Issues, ο χειρισμός των πληροφοριών που υποβάλλετε γίνεται από το GitHub σύμφωνα με την πολιτική απορρήτου του και ενδέχεται να είναι δημόσιες. Μην δημοσιεύετε διακριτικά σύζευξης, προσωπικά ονόματα αρχείων ή άλλες ευαίσθητες πληροφορίες. Αυτός ο ιστότοπος φιλοξενείται στις GitHub Pages. ο πάροχος φιλοξενίας μπορεί να επεξεργαστεί πληροφορίες αιτήματος, όπως διευθύνσεις IP σύμφωνα με τη Δήλωση απορρήτου του GitHub. Το Kinrox δεν προσθέτει σενάρια αναλυτικών στοιχείων ή cookie.

Επαφές και αλλαγές

Για ερωτήσεις απορρήτου, επικοινωνήστε με τον συντηρητή μέσω της Kinrox παρακολούθησης προβλημάτων. Θα ενημερώσουμε αυτήν τη σελίδα όταν αλλάξει ο χειρισμός των δεδομένων των εφαρμογών.
