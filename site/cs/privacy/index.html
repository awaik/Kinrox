Zásady ochrany soukromí

Platné po zveřejnění této stránky. Aktualizováno 30. října 2026.

Kinrox je místní přehrávač videa pro Mac a doprovodný dálkový ovladač pro iPhone. Aplikace neposílají vývojáři osobní údaje, historii přehrávání ani analýzy využití. V aplikacích nejsou žádné účty, reklamní sady SDK ani cloudové služby.

Data na vašich zařízeních

Přehrávač Mac ukládá záložky a předvolby posledních souborů do vašeho Mac. Dálkové ovládání iPhone ukládá náhodný identifikátor zařízení, vybrané Mac a předvolby připojení na váš iPhone. Přihlašovací údaje pro párování jsou uloženy v Keychain každého zařízení. Dálkové ovládání přijímá stav přehrávání a poslední tituly a trvání souborů z vašeho Mac. Úplné cesty k souborovému systému a video soubory se do iPhone nepřenášejí.

Místní síťová komunikace

S vaším svolením Kinrox objeví přehrávače používající Bonjour a vymění si ovládací příkazy a informace o přehrávání přes vaši místní síť. Spárované relace používají šifrování. Názvy zařízení a služeb jsou viditelné během zjišťování místní sítě; samotný objev není šifrovaný kanál. Aplikace nepoužívají přenosový server provozovaný vývojářem.

Kontroly aktualizací Mac

Počínaje verzí 0.3.0 používá přehrávač Mac Sparkle ke čtení veřejného kanálu aktualizací na GitHub Pages jednou denně a když vyberete možnost Zkontrolovat aktualizace. Kontroly nezahrnují jedinečné identifikátory zařízení, historii přehrávání ani systémový profil. Když se rozhodnete nainstalovat aktualizaci, Sparkle stáhne podepsaný instalační program ze GitHub Releases. GitHub může zpracovávat informace o požadavku, jako jsou IP adresy, v rámci svých zásad ochrany osobních údajů. Přehrávání a dálkové ovládání iPhone nevyžadují přístup k internetu.

Udržení a vaše volby

Přihlašovací údaje pro párování zůstanou zachovány, dokud je neodstraníte. Pomocí možnosti Zapomenout v nastavení aplikace iPhone odstraňte uložené přihlašovací údaje Mac z iPhone. Zrušte iPhone ve vzdálených nastaveních přehrávače Mac, abyste odebrali jeho přístup k Mac. Jde o samostatné akce: zapomenutí Macu na iPhonu neodvolá přístup uložený na Macu. Seznam nedávných souborů můžete vymazat v přehrávači na Macu. Přístup k místní síti můžete zakázat v nastavení systému. Položky klíčenky mohou přežít i odinstalaci aplikace, takže pokud chcete odstranit uložené přihlašovací údaje, před odinstalací použijte ovládací prvky pro párování.

Podpora a tento web

Pokud nás kontaktujete přes GitHub Issues, poskytnuté informace zpracovává GitHub podle svých zásad ochrany osobních údajů a mohou být veřejné. Nezveřejňujte párovací tokeny, soukromé názvy souborů ani jiné citlivé údaje. Tento web je hostován na GitHub Pages. Poskytovatel hostingu může zpracovávat údaje o požadavcích, například IP adresy, podle zásad ochrany osobních údajů GitHub. Kinrox nepřidává analytické skripty ani soubory cookie.

Kontakt a změny

V případě otázek týkajících se ochrany osobních údajů kontaktujte správce prostřednictvím nástroje pro sledování problémů Kinrox. Tuto stránku aktualizujeme, když se změní zpracování dat aplikací.
