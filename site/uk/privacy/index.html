Політика конфіденційності

Набуває чинності з моменту публікації цієї сторінки. Оновлено 30 жовтня 2026 р.

Kinrox – це локальний відеопрогравач для Mac та супутній віддалений пристрій для iPhone. Програми не надсилають особисті дані, історію відтворення чи аналітику використання розробнику. У додатках немає облікових записів, рекламних SDK або хмарних служб.

Дані на ваших пристроях

Програвач Mac зберігає останні закладки файлів і параметри на вашому Mac. Пульт дистанційного керування iPhone зберігає випадковий ідентифікатор пристрою, вибрані Mac та параметри підключення на вашому iPhone. Облікові дані з’єднання зберігаються у в’язці ключів кожного пристрою. Пульт дистанційного керування отримує стан відтворення, назви та тривалість останніх файлів із вашого Mac. Повні шляхи файлової системи та відеофайли не передаються до iPhone.

Зв'язок по локальній мережі

З вашого дозволу Kinrox виявляє гравців, які використовують Bonjour, і обмінюється командами керування та інформацією про відтворення через вашу локальну мережу. Парні сеанси використовують шифрування. Назви пристроїв і служб видно під час виявлення локальної мережі; Discovery сам по собі не є зашифрованим каналом. Програми не використовують сервер ретрансляції, яким керує розробник.

Mac перевірки оновлень

Починаючи з версії 0.3.0, програвач Mac використовує Sparkle для читання загальнодоступної стрічки оновлень GitHub Pages раз на день і коли ви вибираєте «Перевірити наявність оновлень». Перевірки не включають унікальні ідентифікатори пристроїв, історію відтворення чи профіль системи. Коли ви вирішуєте встановити оновлення, Sparkle завантажує підписану програму встановлення з GitHub Releases. GitHub може обробляти запитувану інформацію, як-от IP-адреси, відповідно до своєї політики конфіденційності. Для відтворення та iPhone ​​дистанційного керування не потрібен доступ до Інтернету.

Утримання та ваш вибір

Облікові дані для створення пари зберігаються, доки ви їх не видалите. Використовуйте Забути в налаштуваннях програми iPhone, щоб видалити збережені облікові дані Mac з iPhone. Скасуйте iPhone у віддалених налаштуваннях програвача Mac, щоб скасувати його доступ до Mac. Це окремі дії: якщо забути Mac на iPhone, збережений на Mac дозвіл не буде відкликано. Список недавніх файлів можна очистити в програвачі на Mac. Ви можете вимкнути доступ до локальної мережі в налаштуваннях системи. Записи в брелоках можуть зберегтися після видалення програми, тому скористайтеся елементами керування підключенням перед видаленням, якщо ви хочете видалити збережені облікові дані.

Підтримка і цей сайт

Якщо ви вирішите зв’язатися з нами через GitHub Issues, надана вами інформація обробляється GitHub відповідно до його політики конфіденційності та може бути загальнодоступною. Не публікуйте маркери сполучення, приватні імена файлів чи іншу конфіденційну інформацію. Цей веб-сайт розміщено на GitHub Pages; хостинг-провайдер може обробляти запитувану інформацію, як-от IP-адреси, відповідно до Заяви про конфіденційність GitHub. Kinrox не додає сценарії аналітики чи файли cookie.

Контакт і зміни

Із запитаннями щодо конфіденційності зв’яжіться з розробником через Kinrox засіб відстеження проблем. Ми оновимо цю сторінку, коли зміниться обробка даних програм.
