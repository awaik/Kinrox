Kinrox support

Kinrox Remote controls the Kinrox video player on a Mac. It requires iOS 17 or later and a compatible Mac running Kinrox. Both devices must be on the same local network. The iPhone app does not play or stream videos.

Connect your iPhone

  1. Get the Mac player from the official releases and launch it.
  2. Enable remote control in Kinrox on the Mac, then open Connect iPhone to display a pairing code.
  3. Connect the iPhone to the same local network and allow Local Network access for both apps when prompted.
  4. Select the Mac in Kinrox Remote and enter the six-digit code shown on the Mac. Use a fresh code if it has expired.
  5. Open a local video on the Mac. Use your iPhone to pause, seek, adjust volume or open available recent files.

Mac not appearing?

Check that Kinrox is running and remote control is enabled. Check Local Network permissions on both devices. Guest Wi-Fi, client isolation, VPNs and firewall settings can prevent devices from discovering each other. Try the same normal home network and keep both apps in the foreground while pairing.

Try the controls without a Mac

Open Settings in Kinrox Remote and choose Try Demo without Mac. The demo uses fictional media and does not connect to or control a real Mac. Exit the demo in Settings when you are ready to pair.

Connection or recent-file issues

If pairing has been revoked on the Mac, pair again using a fresh code. A recent file must still be available on the Mac; moved or deleted files cannot be opened from the remote. Next and Previous follow video files in the current Mac folder.

Contact

Report an issue or ask for help. Include your iOS and macOS versions, Kinrox versions, what you tried and the error message. Do not include pairing tokens, private filenames or other sensitive information. GitHub issues are public.
