Kinrox サポート

Kinrox Remote は、Mac の Kinrox 動画プレーヤーを制御します。これには、iOS 17 以降と、互換性のある Mac 実行中の Kinrox が必要です。両方のデバイスが同じローカル ネットワーク上に存在する必要があります。 iPhone アプリは動画の再生やストリーミングを行いません。

iPhone を接続します

  1. 公式リリースからMac用プレーヤーをダウンロードして起動します。
  2. Mac の Kinrox でリモート コントロールを有効にし、接続 iPhone を開いてペアリング コードを表示します。
  3. iPhone を同じローカル ネットワークに接続し、プロンプトが表示されたら両方のアプリのローカル ネットワーク アクセスを許可します。
  4. Kinrox Remote で Mac を選択し、Mac に表示されている 6 桁のコードを入力します。有効期限が切れている場合は、新しいコードを使用してください。
  5. Macでローカル動画を開きます。iPhoneで一時停止、再生位置の移動、音量調整をしたり、Mac上に残っている最近使ったファイルを開いたりできます。

Mac が表示されない場合は、

Kinrox が実行中であり、リモート コントロールが有効になっていることを確認してください。両方のデバイスのローカル ネットワークのアクセス許可を確認します。ゲスト Wi-Fi、クライアント分離、VPN、ファイアウォール設定により、デバイスが相互に検出できなくなる場合があります。同じ通常のホーム ネットワークを試し、ペアリング中は両方のアプリをフォアグラウンドに保ちます。

Mac なしでコントロールを試してください

Kinrox Remote で [設定] を開き、[Mac なしでデモを試す] を選択します。デモでは架空のメディアを使用しており、実際の Mac に接続したり制御したりすることはありません。ペアリングの準備ができたら、[設定] でデモを終了します。

接続または最近のファイルの問題

Mac でペアリングが取り消されている場合は、新しいコードを使用して再度ペアリングします。最近のファイルは引き続き Mac で利用できる必要があります。移動または削除されたファイルをリモートから開くことはできません。 [次へ] と [前へ] は、現在の Mac フォルダ内の動画ファイルに従います。

お問い合わせ

問題を報告するか、助けを求めてください。 iOS と macOS のバージョン、Kinrox のバージョン、試したこと、エラー メッセージを含めます。ペアリング トークン、プライベート ファイル名、その他の機密情報は含めないでください。 GitHub 問題は公開されています。
