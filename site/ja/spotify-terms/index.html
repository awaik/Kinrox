接続規約

Spotifyへのアクセス：ライブラリ、再生、お気に入り、編集可能なプレイリスト。お気に入りから削除すると、編集可能なプレイリストからも削除されます。 認証情報はMacのキーチェーンに保存されます。接続解除でSpotifyのローカルデータは消去されますが、プレイリストは残ります。Kinroxのサーバーや利用分析はありません。

Spotify 接続条件

この条件は、Kinrox で Spotify を有効にすると適用されます。Kinrox の管理者は awaik（https://github.com/awaik/Kinrox）です。サポートやプライバシーに関するお問い合わせ先：https://github.com/awaik/Kinrox/issues。Kinrox は Spotify から独立しており、Spotify の承認を受けたものではありません。この条件はアプリ内で同意した時点から適用されます。

アカウントと選択

接続は任意です。ご自身の Spotify 開発者アプリと、利用を許可された Spotify Premium アカウントを使用してください。API アクセスと割り当て上限は Spotify が管理し、アクセスが変更または停止される場合があります。Spotify 自身の規約も引き続き適用されます。 音声は、お客様の操作によりSpotifyからMacへ直接ダウンロードされるSpotify Soloistで再生されます。各ユーザーが個人用Soloist APIキーを用意します。初回のみiPhoneのSpotifyでペアリングし、その後はMacとiPhoneのSpotifyを終了した状態でも再生できます。デコードと音声キャッシュはSoloistが管理し、Kinroxは音声を録音・書き出ししません。Soloistのビルドは90日で期限切れとなり、更新が必要です。

ライブラリの変更

操作によって、曲やアルバムの保存・削除、アーティストのフォロー・解除、プレイリストの作成、および所有または編集権限のあるプレイリストの変更が行われます。曲をお気に入りから削除すると、編集可能なプレイリストにあるその曲のすべての登録も削除されます。アルバムを選択しても、各曲が個別に保存されるわけではありません。変更は Spotify アカウントに反映され、他の Spotify クライアントでも表示される場合があります。

再生キュー

Kinroxは再生キューをローカルに保存し、キュー内の各項目ごとにSoloistプロセスを起動します。再生用の補助プレイリストは作成しません。既存のKinrox QueueプレイリストはSpotifyに残ります。これらをライブラリ変更の対象から除外するため、秘密情報ではない識別子をローカルに保持します。プレイリストはSpotifyでご自身で削除できます。

Spotify の権利

適用法で認められる場合を除き、Spotify のプラットフォーム、サービス、コンテンツの改変や二次的著作物の作成、逆コンパイル、逆アセンブル、リバースエンジニアリング、ソースコードまたは他の人が読める形式への変換は禁止されます。これらの制限は Spotify の素材に関するもので、Mac プレイヤーの GPL ライセンスを含む各コンポーネントのライセンスが Kinrox コードに与える権利を制限しません。

責任と保証

Kinrox については Kinrox の管理者が責任を負います。法律で認められる範囲で、Spotify およびその他の第三者は Kinrox に関する責任を負いません。Kinrox は Spotify のために約束や保証を行いません。法律で認められる範囲で、Spotify のプラットフォーム、サービス、コンテンツについて、商品性、特定目的への適合性、権利非侵害を含むすべての黙示の保証を除外します。強行法規による消費者の権利は影響を受けません。

プライバシーと条件の履行

データの収集・使用には、この条件とともに表示されるプライバシーポリシーが適用されます。Spotify はこの条件および同ポリシーの第三者受益者であり、この条件の履行を直接求めることができます。接続を終了するには「設定 → Spotify → 接続解除」を使用してください。Spotify アカウントのアプリページでもアクセスを取り消せます：https://www.spotify.com/account/apps/。

変更

この接続条件の新しいバージョンには、Kinrox が再接続する前に同意する必要があります。Spotify 接続条件に同意しなくても、ローカル動画の再生と LAN 経由のリモート操作は利用できます。

プライバシーポリシー — Spotify 接続

バージョン 2026-11-03。Kinrox の管理者 awaik は、ここに記載する Kinrox のデータ処理に責任を負います。この補足は任意の Spotify 連携に適用されます。Kinrox の一般プライバシーポリシー：https://kinrox.app/privacy/。お問い合わせ：https://github.com/awaik/Kinrox/issues。公開の Issue にトークン、個人のライブラリ内容、その他の非公開情報を投稿しないでください。

アクセスと目的

条件に同意し Spotify を認可すると、Mac 上の Kinrox はアカウント識別子と表示名、保存済みの曲とアルバム、フォロー中のアーティスト、アクセス可能なプレイリストとその内容、再生状態、利用可能なデバイスを読み取ります。これらの情報はライブラリの表示と Spotify の操作に使用します。該当する操作を行うと、お気に入りの保存・削除、アーティストのフォロー、プレイリストの作成、所有または共同編集のプレイリストの編集ができます。お気に入りを削除すると、編集可能なプレイリスト内の該当項目も削除されます。

保存と受領者

更新用の認証情報は Mac の Data Protection Keychain に保存します。 アクセストークンはメモリ内に保持します。ライブラリのメタデータは、Mac アプリの Caches フォルダにあるローカルの SQLite データベースにキャッシュします。確認済みのアカウント ID と表示名は Mac の設定に保存します。 入力した Client ID、補助プレイリストの関連付け、同意した文書のバージョンは Mac の設定に保存します。Kinrox にはサーバー、利用分析、テレメトリがなく、管理者はこれらの Spotify データを一切受け取りません。Spotify は Mac から直接リクエストを受け取り、自社のプライバシーポリシーに従って処理します：https://www.spotify.com/legal/privacy-policy/。Spotify には Mac の公開 IP アドレスなどのネットワーク情報が見えます。 個人用Soloist APIキーはキーチェーンに保存されます。Connectセッションはアカウント専用の非公開フォルダに保存され、Soloistは上限200 MBの独立した音声キャッシュを使用します。キーは署名済みSoloistプロセスの起動引数として渡され、同じユーザーアカウントの他のプロセスから読み取ることができます。Soloistのループバック制御ソケットには認証やOriginの検査がありません。ループバックにアクセスできるローカルプログラムやウェブページは再生コマンドを送信できます。

iPhone とリンク

ペアリングした iPhone は、Kinrox の暗号化されたローカルネットワーク接続を通じて、曲、アルバム、アーティスト、プレイリストのメタデータ、キューの状態、再生操作情報を受け取ります。Spotify の認証情報を受け取ることも、Spotify Web API を呼び出すこともありません。「Spotify で開く」をタップすると、iPhone または Mac は該当項目を Spotify またはそのウェブサイトで開きます。この引き渡しにはインターネットが使われる場合があり、Spotify のプライバシーポリシーが適用されます。リモコンのメタデータはメモリに保持し、接続解除時またはソース・アカウントのリセット時に消去します。

接続解除と保持

Mac の Kinrox で「設定 → Spotify → 接続解除」を開いてください。 Kinroxは自身のSoloistプロセスとリクエストを停止し、更新用認証情報、Soloist APIキー、自身のセッションと音声キャッシュを削除して、メモリ内のアカウントデータを消去します。過去のキュープレイリストの秘密情報ではない識別子と、ダウンロード済みのエンジンは残ります。自動再接続も停止します。同意したバージョンはアカウントに紐付かない設定です。プレイリストやお気に入りを含め、Spotify ですでに行った変更は残ります。接続解除は Spotify 側の認可を取り消しません。取り消すには https://www.spotify.com/account/apps/ でアプリを削除してください。残った補助プレイリストは Spotify で直接削除できます。 キャッシュしたメタデータは、再検証されないまま 7 日経過すると期限切れになります。接続を解除すると、SQLite キャッシュ、その付随ファイル、保存したアカウントの関連付けを自動的に削除します。

Cookie と Kinrox の一般データ

Kinrox は利用分析や Cookie を追加しません。Spotify API セッションでは永続 Cookie やディスク上のレスポンスキャッシュを使用しません。ブラウザでのログインや Spotify のウェブサイトは独自の Cookie を使用する場合があるため、ブラウザと Spotify のプライバシー設定で管理してください。Kinrox の一般ポリシーでは、ローカルファイルのブックマーク、ペアリング認証情報、Sparkle 更新、GitHub ホスティングを説明しています。Spotify はこのポリシーと接続条件の第三者受益者です。この補足の重要な変更は、新しい接続を有効にする前に表示します。
