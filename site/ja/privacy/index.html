プライバシーポリシー

このページが公開された時点で有効になります。 2026 年 10 月 30 日に更新されました。

Kinrox は、Mac のローカル動画プレーヤーであり、iPhone のコンパニオン リモコンです。アプリは個人データ、再生履歴、使用状況分析を開発者に送信しません。アプリにはアカウント、広告 SDK、またはクラウド サービスはありません。

デバイス上のデータ

Mac プレーヤーは、最近のファイルのブックマークと設定を Mac に保存します。 iPhone リモコンは、ランダムなデバイス識別子、選択された Mac、接続設定を iPhone に保存します。ペアリング認証情報は各デバイスのキーチェーンに保存されます。リモコンは、再生状態、最近のファイルのタイトルと再生時間を Mac から受信します。完全なファイル システム パスと動画ファイルは、iPhone に送信されません。

ローカルネットワーク通信

許可をいただいたうえで、KinroxはBonjourを使ってプレーヤーを検出し、ローカルネットワーク経由で操作コマンドと再生情報をやり取りします。ペアリング済みのセッションは暗号化されます。ローカルネットワークでの検出時には、デバイス名とサービス名が公開されます。検出そのものは暗号化された通信ではありません。アプリは開発者が運営する中継サーバーを使用しません。

Mac 更新チェック

バージョン 0.3.0 以降、Mac プレーヤーは、1 日に 1 回、[アップデートの確認] を選択したときに、Sparkle を使用して GitHub Pages の公開アップデート フィードを読み取ります。チェックには、一意のデバイス識別子、再生履歴、システム プロファイルは含まれません。アップデートのインストールを選択すると、Sparkle は署名付きインストーラを GitHub Releases からダウンロードします。 GitHub は、プライバシー ポリシーに基づいて IP アドレスなどのリクエスト情報を処理する場合があります。再生とiPhoneリモコンにはインターネット アクセスは必要ありません。

保持とあなたの選択

ペアリングの認証情報は、削除するまで残ります。 iPhone アプリの設定で [削除] を使用して、Mac の保存された認証情報を iPhone から削除します。 Mac プレーヤーのリモート設定で iPhone を取り消して、Mac へのアクセスを削除します。 これらは別々の操作です。iPhoneでMacの登録を解除しても、Mac側のアクセス許可は取り消されません。Macプレーヤーでは、最近使ったファイルのリストを消去できます。 システム設定でローカル ネットワーク アクセスを無効にすることができます。 キーチェーンのエントリはアプリをアンインストールしても残る場合があるため、保存された認証情報を削除したい場合は、アンインストールする前にペアリング コントロールを使用してください。

サポートとこのウェブサイト

GitHub Issues を通じてお問い合わせいただくことを選択した場合、送信された情報は GitHub のプライバシー ポリシーに基づいて処理され、公開される場合があります。ペアリング トークン、プライベート ファイル名、その他の機密情報を投稿しないでください。このウェブサイトは GitHub Pages でホストされています。ホスティング プロバイダは、GitHub のプライバシーに関する声明に基づいて、IP アドレスなどのリクエスト情報を処理する場合があります。 Kinrox 分析スクリプトや Cookie は追加されません。

連絡先と変更点

プライバシーについてのご質問は、Kinroxの課題トラッカーから開発者にお問い合わせください。アプリのデータの取り扱いが変わった場合は、このページを更新します。
