Integritetspolicy

Gäller när denna sida publiceras. Uppdaterad 30 oktober 2026.

Kinrox är en lokal videospelare för Mac och en medföljande fjärrkontroll för iPhone. Apparna skickar inte personlig data, uppspelningshistorik eller användningsanalys till utvecklaren. Det finns inga konton, reklam-SDK:er eller molntjänster i apparna.

Data på dina enheter

Mac-spelaren lagrar de senaste filernas bokmärken och inställningar på din Mac. Fjärrkontrollen iPhone lagrar en slumpmässig enhetsidentifierare, den valda Mac och anslutningsinställningar på din iPhone. Parningsuppgifterna lagras i varje enhets nyckelring. Fjärrkontrollen tar emot uppspelningsstatus och senaste filtitlar och varaktigheter från din Mac. Fullständiga filsystemsökvägar och videofiler överförs inte till iPhone.

Lokal nätverkskommunikation

Med din tillåtelse upptäcker Kinrox spelare som använder Bonjour och utbyter kontrollkommandon och uppspelningsinformation över ditt lokala nätverk. Ihopkopplade sessioner använder kryptering. Enhets- och tjänstnamn är synliga under upptäckt av lokalt nätverk; upptäckten i sig är inte en krypterad kanal. Apparna använder inte en utvecklarstyrd reläserver.

Mac uppdateringskontroller

Från och med version 0.3.0 använder Mac-spelaren Sparkle för att läsa det offentliga uppdateringsflödet på GitHub Pages en gång om dagen och när du väljer Sök efter uppdateringar. Kontroller inkluderar inte unika enhetsidentifierare, uppspelningshistorik eller en systemprofil. När du väljer att installera en uppdatering, laddar Sparkle ned det signerade installationsprogrammet från GitHub Releases. GitHub kan behandla begäranden information såsom IP-adresser enligt sin integritetspolicy. Uppspelning och iPhone fjärrkontroll kräver inte internetåtkomst.

Retention och dina val

Parningsuppgifterna finns kvar tills du tar bort dem. Använd Glöm i iPhone-appens inställningar för att ta bort Mac:s sparade referenser från iPhone. Återkalla iPhone i Mac-spelarens fjärrinställningar för att ta bort dess åtkomst på Mac. Det här är separata åtgärder: att glömma Mac-datorn på iPhone återkallar inte den sparade åtkomsten på Mac-datorn. Du kan tömma listan över senaste filer i Mac-spelaren. Du kan inaktivera åtkomst till lokalt nätverk i systeminställningarna. Nyckelringsposter kan överleva när en app avinstalleras, så använd parningskontrollerna innan du avinstallerar om du vill ta bort sparade autentiseringsuppgifter.

Support och denna webbplats

Om du väljer att kontakta oss via GitHub Issues, hanteras informationen du skickar av GitHub enligt dess integritetspolicy och kan vara offentlig. Lägg inte upp parningstokens, privata filnamn eller annan känslig information. Denna webbplats finns på GitHub Pages; värdleverantören kan behandla begäran om information såsom IP-adresser under GitHub:s sekretesspolicy. Kinrox lägger till inga analytiska skript eller cookies.

Kontakt och ändringar

För sekretessfrågor, kontakta underhållaren via Kinrox issue tracker. Vi kommer att uppdatera den här sidan när apparnas datahantering ändras.
