תמיכה ב-Kinrox

Kinrox Remote שולט בנגן הווידאו Kinrox ב-Mac. זה דורש iOS 17 ומעלה ו-Mac תואם עם Kinrox. שני המכשירים חייבים להיות באותה רשת מקומית. האפליקציה iPhone אינה מנגנת או מזרימה סרטונים.

חבר את ה-iPhone שלך

  1. הורידו את הנגן ל-Mac מהגרסאות הרשמיות והפעילו אותו.
  2. אפשר שלט רחוק ב-Kinrox ב-Mac, ואז פתח את חבר iPhone כדי להציג קוד התאמה.
  3. חבר את ה-iPhone לאותה רשת מקומית ואפשר גישה לרשת מקומית עבור שתי האפליקציות כאשר תתבקש.
  4. בחר את ה-Mac ב-Kinrox Remote והזן את הקוד בן שש הספרות המוצג ב-Mac. השתמש בקוד חדש אם פג תוקפו.
  5. פתחו סרטון מקומי ב-Mac. השתמשו ב-iPhone כדי להשהות, לעבור לנקודה אחרת בסרטון, לשנות את עוצמת הקול או לפתוח קבצים אחרונים שעדיין זמינים.

Mac לא מופיע?

בדוק ש-Kinrox פועל והשליטה מרחוק מופעלת. בדוק את הרשאות הרשת המקומית בשני המכשירים. Wi-Fi לאורחים, בידוד לקוח, VPNs והגדרות חומת אש יכולים למנוע ממכשירים לגלות זה את זה. נסה את אותה רשת ביתית רגילה והשאר את שתי האפליקציות בחזית בזמן ההתאמה.

נסה את הפקדים ללא Mac

פתח את ההגדרות ב-Kinrox Remote ובחר נסה הדגמה ללא Mac. ההדגמה משתמשת במדיה בדיונית ואינה מתחברת או שולטת ב-Mac אמיתי. צא מההדגמה בהגדרות כשתהיה מוכן להתאמה.

בעיות חיבור או קבצים אחרונים

אם הצימוד בוטל ב-Mac, התאם שוב באמצעות קוד חדש. קובץ עדכני עדיין חייב להיות זמין ב-Mac; לא ניתן לפתוח קבצים שהועברו או שנמחקו מהשלט. הבא והקודם עקוב אחר קובצי הווידאו בתיקיית Mac הנוכחית.

צור קשר

דווח על בעיה או בקש עזרה. כלול את גרסאות iOS ו-macOS שלך, גרסאות Kinrox, מה שניסית והודעת השגיאה. אל תכלול אסימוני התאמה, שמות קבצים פרטיים או מידע רגיש אחר. בעיות GitHub הן ציבוריות.
