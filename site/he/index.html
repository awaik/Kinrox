Spotify

Spotify בלי אפליקציית שולחן העבודה הכבדה.

נגן Spotify טבעי ב-SwiftUI עם גילוי מוזיקה משלו. הוא מנגן כש-Spotify.app סגור לגמרי וצורך עד 200 MB זיכרון — פי 2 עד 10 פחות מלקוח Spotify לשולחן העבודה, שעלול לתפוס עד 2 GB.

מדידה מ־2026-11-09 אחרי 12 שעות ניגון: כ־193 MB בסך הכול — 161 MB עבור Kinrox ו־32 MB עבור Soloist ותהליכי העזר. זיכרון פיזי לפי macOS footprint; מדידה נקודתית, לא תקרה.

נדרשים Spotify Premium, Client ID משלכם למפתחי Spotify ומפתח Soloist אישי. Kinrox ידריך אתכם בהגדרה.

רצועות דומות שממשיכות להתנגן

התחילו מרצועה, אמן, אלבום או פלייליסט. Kinrox מראה למה כל הצעה מתאימה — הושמעו יחד, שיתופי פעולה, הספרייה שלכם, ז׳אנר — ו“להאזין לדומים” ממשיך להוסיף לתור מוזיקה מתאימה. “לא מעניין אותי” מסתיר את מה שאתם לא רוצים.

עד 200 MB במקום 2 GB

ללא דפדפן מוטמע: תצוגות SwiftUI טבעיות ומנוע שמע קל צורכים שבריר מהזיכרון של לקוח Spotify לשולחן העבודה.

בנה מהמקור
# Xcode 26.5, XcodeGen and mpv from Homebrew
brew install xcodegen mpv pkg-config
git clone https://github.com/awaik/Kinrox.git
cd Kinrox
cp -n Config/Signing.local.xcconfig.example \
  Config/Signing.local.xcconfig
# Set your team: docs/runbooks/RUNBOOK-BUILD-AND-SIGNING.md
./Scripts/check-env.sh
./Scripts/generate.sh

xcodebuild -workspace Kinrox.xcworkspace \
  -scheme PlayerMac -configuration Debug \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath DerivedData build
open DerivedData/Build/Products/Debug/Kinrox.app
שאלות נפוצות

שאלות

זה צריך אינטרנט?

וידאו מקומי ושלט ברשת המקומית פועלים ללא אינטרנט. עדכונים ו-Spotify האופציונלי דורשים אינטרנט.

זה עובד עם טלוויזיה, לא מקרן?

כן. Kinrox מנגן בכל מה שה-Mac שלך מציג - מקרן, טלוויזיה דרך HDMI או צג המחובר ל-AirPlay.

אילו Macs ו-iPhones נתמכים?

Macs עם Apple silicon ב-macOS 14 Sonoma ואילך, ו-iPhones ב-iOS 17 ומעלה. Intel Macs אינם נתמכים עדיין.

האם יותר מ-iPhone אחד יכול לשלוט באותו Mac?

כן. כל iPhone מתחבר פעם אחת עם קוד משלו; ניתן לחבר עד ארבעה שלטים בו-זמנית. אתה יכול לבטל כל אחד מהם בהגדרות הנגן.

האם אני יכול לבחור רצועות שמע וכתוביות?

כן. ב-Mac, השתמש בלחצן אודיו וכתוביות או בתפריטי אודיו וכתוביות. בחר רצועות מוטמעות, מצא קבצים חיצוניים בתיקיות מקוננות או כבה כתוביות. Kinrox יכול לזכור את הבחירה שלך לפרק הבא.

כמה זה עולה?

Kinrox ל-Mac הוא תוכנת קוד פתוח ברישיון GNU GPL v3. Kinrox Remote זמין בחינם לשימוש אישי ולא מסחרי. שימוש עסקי, מכירה ומינויים בתשלום אסורים. גרסאות GPL קודמות שומרות על הרישיון המקורי שלהן.
