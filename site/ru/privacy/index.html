Политика конфиденциальности

2026-11-01

Kinrox воспроизводит локальные видео на Mac и предоставляет пульт для iPhone. Разработчик не получает персональные данные, историю воспроизведения или аналитику использования.

Данные на ваших устройствах

Mac хранит закладки недавних файлов и настройки. iPhone хранит случайный идентификатор устройства, выбранный Mac и настройки соединения. Данные сопряжения хранятся в Связке ключей каждого устройства. Пульт получает с Mac состояние воспроизведения, названия и длительность недавних файлов. Полные пути к файлам и сами видео на iPhone не передаются.

Локальная сеть

С вашего разрешения Kinrox находит плееры через Bonjour и передаёт команды и сведения о воспроизведении по локальной сети. Сеансы сопряжённых устройств защищены шифрованием. Имена устройств и сервисов видны при обнаружении в сети; само обнаружение не зашифровано. Сервер-посредник разработчика не используется.

Проверка обновлений на Mac

Начиная с версии 0.3.0, Mac-плеер использует Sparkle для чтения публичной ленты обновлений на GitHub Pages раз в день и по команде «Проверить обновления». Проверки не содержат уникальных идентификаторов устройств, истории воспроизведения или сведений о системе. Когда вы выбираете установку, Sparkle скачивает подписанный установщик с GitHub Releases. GitHub может обрабатывать IP-адреса и другие сведения о запросах согласно своей политике конфиденциальности. Локальное видео и пульт по локальной сети работают без интернета. Обновления и дополнительное подключение Spotify требуют интернета.

Spotify

Spotify подключается по желанию, только на Mac после входа с собственным Client ID. Нужны Spotify Premium и официальное приложение Spotify на этом Mac. Kinrox отправляет запросы к библиотеке, плейлистам и воспроизведению напрямую в Spotify, который обрабатывает их по своей политике конфиденциальности. Данные для обновления доступа хранятся в Связке ключей Mac, метаданные библиотеки — в памяти. Kinrox управляет одним приватным плейлистом Kinrox Queue. Отключение удаляет локальные данные доступа и кеш библиотеки; плейлист остаётся в Spotify, пока вы его не удалите. iPhone управляет воспроизведением по локальной сети; нажатие «Открыть в Spotify» может использовать интернет. Сервера Kinrox и аналитики нет.

Доступ Spotify: библиотека, воспроизведение, избранное и редактируемые плейлисты. Снятие отметки избранного также удаляет трек из редактируемых плейлистов. Данные входа хранятся в Связке ключей Mac. Отключение удаляет локальные данные Spotify, сохраняя плейлисты Spotify. Серверов Kinrox и аналитики нет.

Политика конфиденциальности — подключение Spotify

Версия 2026-11-01. Разработчик Kinrox, awaik, отвечает за описанную здесь обработку данных в Kinrox. Это дополнение относится к необязательной интеграции Spotify. Общая политика конфиденциальности Kinrox доступна по адресу https://kinrox.app/privacy/. Контакт: https://github.com/awaik/Kinrox/issues. Не публикуйте токены, содержимое личной медиатеки и другую конфиденциальную информацию в публичных обращениях.

Доступ и цели

После принятия условий и авторизации Spotify Kinrox на Mac читает идентификатор и отображаемое имя вашего аккаунта, сохранённые треки и альбомы, исполнителей, на которых вы подписаны, доступные плейлисты и их содержимое, состояние воспроизведения и доступные устройства. Эти сведения используются для отображения медиатеки и управления Spotify. При использовании соответствующих элементов управления Kinrox может добавлять и удалять избранное, подписываться на исполнителей, создавать плейлисты и редактировать ваши собственные или совместные плейлисты. Удаление избранного также удаляет его вхождения из редактируемых плейлистов. Для воспроизведения Kinrox поддерживает приватный плейлист Kinrox Queue.

Хранение и получатели

Учётные данные для обновления доступа хранятся в Data Protection Keychain на Mac. Токены доступа, сведения об аккаунте и метаданные медиатеки остаются в памяти приложения. Указанный Client ID, привязка служебного плейлиста и версия принятых документов хранятся в настройках Mac. У Kinrox нет сервера, аналитики или телеметрии, а разработчик не получает эти данные Spotify. Spotify получает запросы напрямую с Mac и обрабатывает их по своей политике конфиденциальности: https://www.spotify.com/legal/privacy-policy/. Spotify видит сетевые сведения, например публичный IP-адрес Mac.

iPhone и ссылки

Сопряжённый iPhone получает метаданные треков, альбомов, исполнителей и плейлистов, состояние очереди и элементы управления воспроизведением через зашифрованное соединение Kinrox по локальной сети. Он никогда не получает учётные данные Spotify и не обращается к Spotify Web API. При нажатии «Открыть в Spotify» iPhone или Mac открывает соответствующий объект в Spotify или на его сайте. Такой переход может использовать интернет и регулируется политикой конфиденциальности Spotify. Метаданные пульта хранятся в памяти и очищаются при отключении или сбросе источника либо аккаунта.

Отключение и сроки хранения

В Kinrox на Mac выберите «Настройки → Spotify → Отключить». Kinrox завершает ожидающие операции воспроизведения, прекращает запросы, удаляет учётные данные для обновления доступа и локальные привязки служебных плейлистов, очищает сведения об аккаунте и медиатеке из памяти. Автоматическое переподключение прекращается. Версия принятого документа — настройка, не связанная с аккаунтом. Уже внесённые в Spotify изменения, включая плейлисты и избранное, сохраняются. Отключение не отзывает авторизацию в Spotify; для её отзыва удалите приложение на странице https://www.spotify.com/account/apps/. Сохранённые служебные плейлисты можно удалить непосредственно в Spotify.

Файлы cookie и общие данные Kinrox

Kinrox не добавляет аналитику или файлы cookie. Его сеансы Spotify API не используют постоянные cookie или дисковый кэш ответов. Вход через браузер и сайты Spotify могут использовать собственные cookie; управляйте ими в браузере и настройках конфиденциальности Spotify. Общая политика Kinrox описывает закладки локальных файлов, данные сопряжения, обновления Sparkle и хостинг GitHub. Spotify является сторонним выгодоприобретателем по этой политике и условиям подключения. Существенные изменения этого дополнения будут показаны до включения нового подключения.

Хранение и удаление

Данные сопряжения сохраняются до удаления. В настройках пульта выберите «Забыть», чтобы удалить сохранённые данные Mac с iPhone. В настройках пульта на Mac отзовите доступ iPhone, чтобы удалить его запись на Mac. Это разные действия: удаление на iPhone не отзывает запись на Mac. Список недавних файлов очищается в плеере на Mac. Доступ к локальной сети можно отключить в системных настройках. Записи Связки ключей могут сохраняться после удаления приложения, поэтому при необходимости удалите сопряжение заранее.

Поддержка и сайт

Если вы обратитесь через GitHub Issues, предоставленные сведения будут обрабатываться GitHub согласно его политике конфиденциальности и могут быть публичными. Не публикуйте токены сопряжения, личные имена файлов и другие конфиденциальные данные. Сайт размещён на GitHub Pages; провайдер может обрабатывать IP-адреса и другие сведения о запросах согласно политике конфиденциальности GitHub. Kinrox не добавляет скрипты аналитики или cookies.

Контакты и изменения

Вопросы о конфиденциальности можно задать разработчику в трекере Kinrox. При изменении обработки данных мы обновим эту страницу.
