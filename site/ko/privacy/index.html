개인정보 처리방침

이 페이지가 게시되면 유효합니다. 2026년 10월 30일에 업데이트되었습니다.

Kinrox는 Mac용 로컬 비디오 플레이어이자 iPhone용 보조 리모컨입니다. 앱은 개인 데이터, 재생 기록 또는 사용 분석을 개발자에게 보내지 않습니다. 앱에는 계정, 광고 SDK 또는 클라우드 서비스가 없습니다.

기기의 데이터

Mac 플레이어는 최근 파일 북마크와 기본 설정을 Mac에 저장합니다. iPhone 리모컨은 임의의 장치 식별자, 선택한 Mac 및 연결 기본 설정을 iPhone에 저장합니다. 페어링 자격 증명은 각 장치의 키체인에 저장됩니다. 리모컨은 Mac로부터 재생 상태와 최근 파일 제목 및 재생 시간을 수신합니다. 전체 파일 시스템 경로와 비디오 파일은 iPhone로 전송되지 않습니다.

로컬 네트워크 통신

귀하의 허가를 받아 Kinrox는 Bonjour를 사용하는 플레이어를 검색하고 로컬 네트워크를 통해 제어 명령 및 재생 정보를 교환합니다. 페어링된 세션은 암호화를 사용합니다. 로컬 네트워크 검색 중에 장치 및 서비스 이름이 표시됩니다. 검색 자체는 암호화된 채널이 아닙니다. 해당 앱은 개발자가 운영하는 중계 서버를 사용하지 않습니다.

Mac 업데이트 확인

0.3.0 버전부터 Mac 플레이어는 Sparkle를 사용하여 하루에 한 번, 업데이트 확인을 선택할 때 GitHub Pages의 공개 업데이트 피드를 읽습니다. 검사에는 고유한 장치 식별자, 재생 기록 또는 시스템 프로필이 포함되지 않습니다. 업데이트 설치를 선택하면 Sparkle는 GitHub Releases에서 서명된 설치 프로그램을 다운로드합니다. GitHub는 개인정보 보호정책에 따라 IP 주소와 같은 요청 정보를 처리할 수 있습니다. 재생 및 iPhone 원격 제어에는 인터넷 접속이 필요하지 않습니다.

보존 및 귀하의 선택

페어링 자격 증명은 제거할 때까지 유지됩니다. iPhone 앱 설정에서 잊어버리기를 사용하여 iPhone에서 Mac의 저장된 자격 증명을 제거합니다. Mac에 대한 액세스를 제거하려면 Mac 플레이어의 원격 설정에서 iPhone를 취소하십시오. 두 작업은 별개입니다. iPhone에서 Mac 등록을 지워도 Mac에 저장된 접근 권한은 취소되지 않습니다. 최근 파일 목록은 Mac 플레이어에서 지울 수 있습니다. 시스템 설정에서 로컬 네트워크 액세스를 비활성화할 수 있습니다. 키체인 항목은 앱을 제거해도 남아 있을 수 있으므로 저장된 자격 증명을 제거하려면 제거하기 전에 페어링 컨트롤을 사용하세요.

지원 및 이 웹사이트

GitHub Issues를 통해 당사에 연락하기로 선택한 경우 귀하가 제출한 정보는 GitHub의 개인정보 보호정책에 따라 처리되며 공개될 수 있습니다. 페어링 토큰, 개인 파일 이름 또는 기타 민감한 정보를 게시하지 마십시오. 이 웹사이트는 GitHub Pages에서 호스팅됩니다. 호스팅 제공업체는 GitHub의 개인정보 보호정책에 따라 IP 주소와 같은 요청 정보를 처리할 수 있습니다. Kinrox는 분석 스크립트나 쿠키를 추가하지 않습니다.

문의 및 변경

개인 정보 보호 관련 질문이 있는 경우 Kinrox 문제 추적기를 통해 관리자에게 문의하세요. 앱의 데이터 처리가 변경되면 이 페이지를 업데이트할 예정입니다.
