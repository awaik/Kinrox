개인정보 처리방침

2026-11-01

Kinrox는 Mac에서 로컬 동영상을 재생하고 iPhone 리모컨을 제공합니다. 개발자는 개인 정보, 재생 기록 또는 사용 분석 데이터를 받지 않습니다.

기기의 데이터

Mac 플레이어는 최근 파일 북마크와 기본 설정을 Mac에 저장합니다. iPhone 리모컨은 임의의 장치 식별자, 선택한 Mac 및 연결 기본 설정을 iPhone에 저장합니다. 페어링 자격 증명은 각 장치의 키체인에 저장됩니다. 리모컨은 Mac로부터 재생 상태와 최근 파일 제목 및 재생 시간을 수신합니다. 전체 파일 시스템 경로와 비디오 파일은 iPhone로 전송되지 않습니다.

로컬 네트워크 통신

귀하의 허가를 받아 Kinrox는 Bonjour를 사용하는 플레이어를 검색하고 로컬 네트워크를 통해 제어 명령 및 재생 정보를 교환합니다. 페어링된 세션은 암호화를 사용합니다. 로컬 네트워크 검색 중에 장치 및 서비스 이름이 표시됩니다. 검색 자체는 암호화된 채널이 아닙니다. 해당 앱은 개발자가 운영하는 중계 서버를 사용하지 않습니다.

Mac 업데이트 확인

0.3.0 버전부터 Mac 플레이어는 Sparkle를 사용하여 하루에 한 번, 업데이트 확인을 선택할 때 GitHub Pages의 공개 업데이트 피드를 읽습니다. 검사에는 고유한 장치 식별자, 재생 기록 또는 시스템 프로필이 포함되지 않습니다. 업데이트 설치를 선택하면 Sparkle는 GitHub Releases에서 서명된 설치 프로그램을 다운로드합니다. GitHub는 개인정보 보호정책에 따라 IP 주소와 같은 요청 정보를 처리할 수 있습니다. 로컬 동영상과 LAN 리모컨은 오프라인으로 작동합니다. 업데이트와 선택적 Spotify 기능에는 인터넷이 필요합니다.

Spotify

연결은 선택 사항입니다. 본인의 Spotify 개발자 앱과 사용이 허가된 Spotify Premium 계정을 사용하세요. Spotify가 API 접근과 할당량을 관리하며, 접근 권한은 변경되거나 중단될 수 있습니다. Spotify 자체 약관도 계속 적용됩니다. 오디오는 사용자의 요청에 따라 Spotify에서 Mac으로 직접 다운로드한 Spotify Soloist로 재생됩니다. 각 사용자는 개인 Soloist API 키를 제공합니다. 최초 한 번 iPhone의 Spotify로 페어링하면 이후 Mac과 iPhone에서 Spotify를 종료한 상태로도 재생할 수 있습니다. Soloist가 디코딩과 자체 오디오 캐시를 관리하며, Kinrox는 오디오를 녹음하거나 내보내지 않습니다. Soloist 빌드는 90일 후 만료되며 업데이트가 필요합니다.

Spotify 접근: 라이브러리, 재생, 즐겨찾기 및 편집 가능한 플레이리스트. 즐겨찾기에서 삭제하면 편집 가능한 플레이리스트에서도 삭제됩니다. 인증 정보는 Mac 키체인에 저장됩니다. 연결 해제 시 로컬 Spotify 데이터는 지워지지만 플레이리스트는 유지됩니다. Kinrox 서버나 사용 분석은 없습니다.

개인정보 처리방침 — Spotify 연결

버전 2026-11-03. Kinrox 유지 관리자 awaik은 여기에 설명된 Kinrox의 데이터 처리에 책임을 집니다. 이 부록은 선택적 Spotify 연동에 적용됩니다. Kinrox 일반 개인정보 처리방침: https://kinrox.app/privacy/. 문의: https://github.com/awaik/Kinrox/issues. 공개 이슈에 토큰, 개인 라이브러리 내용 또는 기타 비공개 정보를 게시하지 마세요.

접근과 목적

약관에 동의하고 Spotify를 승인하면 Mac의 Kinrox는 계정 식별자와 표시 이름, 저장된 곡과 앨범, 팔로우한 아티스트, 접근 가능한 플레이리스트와 그 내용, 재생 상태 및 사용 가능한 기기를 읽습니다. 이 정보는 라이브러리 표시와 Spotify 제어에 사용됩니다. 해당 제어 기능을 사용하면 즐겨찾기를 저장하거나 제거하고, 아티스트를 팔로우하고, 플레이리스트를 만들며, 소유하거나 공동 편집하는 플레이리스트를 편집할 수 있습니다. 즐겨찾기를 제거하면 편집 가능한 플레이리스트의 해당 항목도 제거됩니다.

저장과 수신자

갱신 자격 증명은 Mac의 Data Protection Keychain에 저장됩니다. 접근 토큰은 메모리에 남습니다. 라이브러리 메타데이터는 Mac 앱의 Caches 폴더에 있는 로컬 SQLite 데이터베이스에 캐시됩니다. 확인된 계정 식별자와 표시 이름은 Mac 환경설정에 저장됩니다. 입력한 Client ID, 보조 플레이리스트 연결 정보 및 동의한 문서 버전은 Mac 환경설정에 저장됩니다. Kinrox에는 서버, 분석 또는 원격 측정이 없으며 유지 관리자는 이 Spotify 데이터를 받지 않습니다. Spotify는 Mac에서 직접 요청을 받고 자체 개인정보 처리방침에 따라 처리합니다: https://www.spotify.com/legal/privacy-policy/. Spotify는 Mac의 공인 IP 주소와 같은 네트워크 정보를 볼 수 있습니다. 개인 Soloist API 키는 키체인에 저장됩니다. Connect 세션은 계정 전용 비공개 폴더에 저장되며, Soloist는 최대 200 MB의 별도 오디오 캐시를 사용합니다. 키는 서명된 Soloist 프로세스의 실행 인수로 전달되며 같은 사용자 계정의 다른 프로세스가 읽을 수 있습니다. Soloist의 루프백 제어 소켓에는 인증이나 Origin 검사가 없습니다. 루프백에 접근할 수 있는 로컬 프로그램이나 웹 페이지는 재생 명령을 보낼 수 있습니다.

iPhone과 링크

페어링된 iPhone은 Kinrox의 암호화된 로컬 네트워크 연결을 통해 곡, 앨범, 아티스트 및 플레이리스트 메타데이터, 대기열 상태와 재생 제어 정보를 받습니다. Spotify 자격 증명을 받거나 Spotify Web API를 호출하지 않습니다. Spotify에서 열기를 탭하면 iPhone 또는 Mac이 해당 항목을 Spotify 또는 그 웹사이트에서 엽니다. 이 전달은 인터넷을 사용할 수 있으며 Spotify 개인정보 처리방침이 적용됩니다. 리모컨 메타데이터는 메모리에 보관되며 연결 해제 또는 소스나 계정 초기화 시 삭제됩니다.

연결 해제와 보관

Mac의 Kinrox에서 설정 → Spotify → 연결 해제를 여세요. Kinrox는 자체 Soloist 프로세스와 요청을 중지하고 갱신 자격 증명, Soloist API 키, 자체 세션과 오디오 캐시를 삭제하며 메모리에서 계정 데이터를 지웁니다. 비밀 정보가 아닌 이전 대기열 플레이리스트 식별자와 다운로드한 엔진은 남습니다. 자동 재연결도 중단합니다. 동의한 버전은 계정과 연결되지 않은 환경설정입니다. 플레이리스트와 즐겨찾기 등 Spotify에서 이미 이루어진 변경 사항은 그대로 남습니다. 연결 해제는 Spotify의 승인을 철회하지 않습니다. 철회하려면 https://www.spotify.com/account/apps/ 에서 앱을 제거하세요. 남아 있는 보조 플레이리스트는 Spotify에서 직접 삭제할 수 있습니다. 캐시된 메타데이터는 재검증 없이 7일이 지나면 만료됩니다. 연결을 끊으면 SQLite 캐시, 관련 보조 파일 및 저장된 계정 연결 정보가 자동으로 삭제됩니다.

쿠키와 Kinrox 일반 데이터

Kinrox는 분석이나 쿠키를 추가하지 않습니다. Spotify API 세션은 영구 쿠키나 디스크 응답 캐시를 사용하지 않습니다. 브라우저 로그인과 Spotify 웹사이트는 자체 쿠키를 사용할 수 있으므로 브라우저와 Spotify 개인정보 설정에서 관리하세요. Kinrox 일반 방침은 로컬 파일 책갈피, 페어링 자격 증명, Sparkle 업데이트 및 GitHub 호스팅을 설명합니다. Spotify는 이 방침과 연결 약관의 제3자 수익자입니다. 이 부록의 중요한 변경 사항은 새 연결을 활성화하기 전에 표시됩니다.

보존 및 귀하의 선택

페어링 자격 증명은 제거할 때까지 유지됩니다. iPhone 앱 설정에서 잊어버리기를 사용하여 iPhone에서 Mac의 저장된 자격 증명을 제거합니다. Mac에 대한 액세스를 제거하려면 Mac 플레이어의 원격 설정에서 iPhone를 취소하십시오. 두 작업은 별개입니다. iPhone에서 Mac 등록을 지워도 Mac에 저장된 접근 권한은 취소되지 않습니다. 최근 파일 목록은 Mac 플레이어에서 지울 수 있습니다. 시스템 설정에서 로컬 네트워크 액세스를 비활성화할 수 있습니다. 키체인 항목은 앱을 제거해도 남아 있을 수 있으므로 저장된 자격 증명을 제거하려면 제거하기 전에 페어링 컨트롤을 사용하세요.

지원 및 이 웹사이트

GitHub Issues를 통해 당사에 연락하기로 선택한 경우 귀하가 제출한 정보는 GitHub의 개인정보 보호정책에 따라 처리되며 공개될 수 있습니다. 페어링 토큰, 개인 파일 이름 또는 기타 민감한 정보를 게시하지 마십시오. 이 웹사이트는 GitHub Pages에서 호스팅됩니다. 호스팅 제공업체는 GitHub의 개인정보 보호정책에 따라 IP 주소와 같은 요청 정보를 처리할 수 있습니다. Kinrox는 분석 스크립트나 쿠키를 추가하지 않습니다.

문의 및 변경

개인 정보 보호 관련 질문이 있는 경우 Kinrox 문제 추적기를 통해 관리자에게 문의하세요. 앱의 데이터 처리가 변경되면 이 페이지를 업데이트할 예정입니다.
