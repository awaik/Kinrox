سیاست حفظ حریم خصوصی

زمانی موثر است که این صفحه منتشر شود. به روز شده در 30 اکتبر 2026.

Kinrox یک پخش کننده ویدیوی محلی برای Mac و یک کنترل از راه دور همراه برای iPhone است. این برنامه ها اطلاعات شخصی، سابقه پخش یا تجزیه و تحلیل استفاده را برای توسعه دهنده ارسال نمی کنند. هیچ حساب کاربری، SDK های تبلیغاتی یا خدمات ابری در برنامه ها وجود ندارد.

داده های دستگاه های شما

پخش کننده Mac نشانک ها و تنظیمات برگزیده فایل اخیر را در Mac شما ذخیره می کند. کنترل از راه دور iPhone یک شناسه تصادفی دستگاه، Mac انتخاب شده و تنظیمات برگزیده اتصال را در iPhone شما ذخیره می کند. اعتبار جفت شدن در Keychain هر دستگاه ذخیره می شود. کنترل از راه دور وضعیت پخش و عناوین و مدت زمان فایل اخیر را از Mac شما دریافت می کند. مسیرهای کامل سیستم فایل و فایل های ویدئویی به iPhone منتقل نمی شوند.

ارتباطات شبکه محلی

با اجازه شما، Kinrox پخش‌کننده‌های را که از Bonjour استفاده می کنند کشف می کند و دستورات کنترلی و اطلاعات پخش را در شبکه محلی شما مبادله می کند. جلسات جفت شده از رمزگذاری استفاده می کنند. نام دستگاه و سرویس در هنگام کشف شبکه محلی قابل مشاهده است. کشف خود یک کانال رمزگذاری شده نیست. برنامه‌ها از سرور رله توسعه‌دهنده استفاده نمی‌کنند.

Mac به روز رسانی را بررسی می کند

با شروع نسخه 0.3.0، پخش کننده Mac از Sparkle برای خواندن فید به روز رسانی عمومی در GitHub Pages یک بار در روز و هنگامی که بررسی برای به روز رسانی را انتخاب می کنید، استفاده می کند. بررسی‌ها شامل شناسه‌های منحصربه‌فرد دستگاه، سابقه پخش یا نمایه سیستم نمی‌شوند. وقتی نصب به‌روزرسانی را انتخاب می‌کنید، Sparkle نصب‌کننده امضاشده را از GitHub Releases دانلود می‌کند. GitHub ممکن است اطلاعات درخواستی مانند آدرس های IP را تحت خط مشی رازداری خود پردازش کند. پخش و کنترل از راه دور iPhone نیازی به دسترسی به اینترنت ندارند.

حفظ و انتخاب های شما

اعتبار جفت شدن تا زمانی که آنها را حذف نکنید باقی می ماند. از Forget در تنظیمات برنامه iPhone برای حذف اطلاعات کاربری ذخیره شده Mac از iPhone استفاده کنید. iPhone را در تنظیمات راه دور پخش کننده Mac لغو کنید تا دسترسی آن به Mac حذف شود. این دو کار مستقل هستند: فراموش کردن Mac در iPhone، مجوز دسترسی ذخیره‌شده در Mac را لغو نمی‌کند. می‌توانید فهرست فایل‌های اخیر را در پخش‌کنندهٔ Mac پاک کنید. می توانید دسترسی به شبکه محلی را در تنظیمات سیستم غیرفعال کنید. ورودی‌های Keychain ممکن است از حذف نصب یک برنامه زنده بمانند، بنابراین اگر می‌خواهید اطلاعات کاربری ذخیره شده را حذف کنید، قبل از حذف از کنترل‌های جفت‌سازی استفاده کنید.

پشتیبانی و این وب سایت

اگر تصمیم دارید از طریق GitHub Issues با ما تماس بگیرید، اطلاعاتی که ارسال می کنید توسط GitHub تحت خط مشی رازداری آن اداره می شود و ممکن است عمومی باشد. از ارسال نشانه های جفت، نام فایل های خصوصی یا سایر اطلاعات حساس خودداری کنید. این وب سایت در GitHub Pages میزبانی می شود. ارائه‌دهنده میزبانی ممکن است اطلاعات درخواستی مانند آدرس‌های IP را تحت بیانیه حریم خصوصی GitHub پردازش کند. Kinrox هیچ اسکریپت تحلیلی یا کوکی اضافه نمی کند.

تماس و تغییرات

برای سوالات حریم خصوصی، از طریق ردیاب Kinrox با نگهدار تماس بگیرید. زمانی که مدیریت داده‌های برنامه‌ها تغییر کند، این صفحه را به‌روزرسانی خواهیم کرد.
