Kostenlos und Open Source · Mac + iPhone

Bleib sitzen. Pausiere den Film.

Kinrox spielt Videos auf deinem Mac ab und macht dein iPhone zur Fernbedienung. Das MacBook steht am Beamer, du liegst auf dem Sofa: pausieren, zehn Sekunden zurückspringen, leiser stellen oder die nächste Folge starten, ohne die Decke zu verlassen.

Kopplung

In zehn Sekunden verbunden. Einmal.

Keine IP-Adressen, keine Passwörter, kein Konto. Nach dem ersten Code verbindet sich Ihr iPhone von selbst wieder.

  1. Öffnen Sie ein Video auf Ihrem Mac

    Ziehen Sie eine Datei in Kinrox oder drücken Sie ⌘ O. Der Remote-Server ist standardmäßig aktiviert.

  2. Wählen Sie Ihren Mac auf dem iPhone

    Kinrox wird von selbst angezeigt, wenn beide Geräte mit demselben WLAN verbunden sind.

  3. Geben Sie den 6-stelligen Code ein

    Der Mac zeigt einen Code an, der zwei Minuten lang aktiv ist. Drei falsche Versuche und es ist weg.

Privatsphäre

Was in Ihrem Wohnzimmer passiert, bleibt dort.

Ihr Mac und iPhone tauschen Wiedergabebefehle direkt über Ihr lokales Netzwerk aus. Ihre Videos bleiben auf dem Mac.

Nur lokales Netzwerk

Erkennung über Bonjour, Verbindungen nur aus Ihrem eigenen Subnetz. Öffentliche Adressen und Mobilfunkadressen werden abgelehnt.

Verschlüsselt und gekoppelt

Jeder Befehl wird in einem verschlüsselten Kanal übertragen. Pairing-Tokens befinden sich auf beiden Geräten im Schlüsselbund.

X25519HKDF-SHA256ChaCha20-Poly1305

Keine Konten, keine Telemetrie

Keine Konten oder Nutzungsanalysen. Der Mac überprüft täglich einen öffentlichen Update-Feed ohne eindeutige Kennungen oder Systemprofilierung. Diese Website verfügt über keine Analysen oder Cookies.

Ihre Dateien bleiben auf dem Mac

Die Fernbedienung erhält Titel und Dauer, aber keine Dateipfade. Zuletzt geöffnete Dateien werden direkt auf dem Mac aufgerufen.

brew install xcodegen mpv pkg-config
git clone https://github.com/awaik/Kinrox.git
cd Kinrox
cp -n Config/Signing.local.xcconfig.example \
  Config/Signing.local.xcconfig
# Set your team: docs/runbooks/RUNBOOK-BUILD-AND-SIGNING.md
./Scripts/check-env.sh
./Scripts/generate.sh

xcodebuild -workspace Kinrox.xcworkspace \
  -scheme PlayerMac -configuration Debug \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath DerivedData build
open DerivedData/Build/Products/Debug/Kinrox.app
FAQ

Fragen

Braucht es das Internet?

Wiedergabe und Fernbedienung funktionieren ohne Internetzugang, wenn Mac und iPhone ein Wi-Fi-Netzwerk teilen. Der Mac verwendet HTTPS für tägliche Update-Prüfungen und lädt ein Update herunter, wenn Sie es installieren möchten.

Funktioniert es mit einem Fernseher, nicht mit einem Projektor?

Ja. Der Kinrox spielt auf allem ab, was Ihr Mac zeigt – einem Projektor, einem Fernseher über HDMI oder einem mit dem AirPlay verbundenen Display.

Welche Macs und iPhones werden unterstützt?

Macs mit Apple silicon auf macOS 14, Sonoma oder höher und iPhones auf iOS 17 oder höher. Intel Macs werden noch nicht unterstützt.

Kann mehr als ein iPhone denselben Mac steuern?

Ja. Jeder iPhone paart sich einmal mit seinem eigenen Code; Bis zu vier Fernbedienungen können gleichzeitig angeschlossen werden. Sie können jede davon in den Player-Einstellungen widerrufen.

Kann ich Audio- und Untertitelspuren auswählen?

Ja. Verwenden Sie beim Mac die Schaltfläche „Audio & Untertitel“ oder die Menüs „Audio und Untertitel“. Wählen Sie eingebettete Titel, suchen Sie externe Dateien in verschachtelten Ordnern oder schalten Sie Untertitel aus. Kinrox kann sich Ihre Wahl für die nächste Folge merken.

Wie viel kostet es?

Nichts. Kinrox ist kostenlos und Open Source unter der Bezeichnung GNU GPL v3.
