Kinrox-Unterstützung

Kinrox Remote steuert den Kinrox-Videoplayer auf einem Mac. Es erfordert iOS 17 oder höher und einen kompatiblen Mac mit Kinrox. Beide Geräte müssen sich im selben lokalen Netzwerk befinden. Die iPhone-App spielt oder streamt keine Videos.

Schließen Sie Ihren iPhone an

  1. Lade den Mac-Player aus den offiziellen Releases herunter und starte ihn.
  2. Aktivieren Sie die Fernbedienung in Kinrox auf dem Mac und öffnen Sie dann iPhone verbinden, um einen Kopplungscode anzuzeigen.
  3. Verbinden Sie den iPhone mit demselben lokalen Netzwerk und erlauben Sie beiden Apps den Zugriff auf das lokale Netzwerk, wenn Sie dazu aufgefordert werden.
  4. Wählen Sie Mac in Kinrox Remote aus und geben Sie den sechsstelligen Code ein, der auf dem Mac angezeigt wird. Verwenden Sie einen neuen Code, wenn dieser abgelaufen ist.
  5. Öffnen Sie ein lokales Video auf dem Mac. Verwenden Sie Ihren iPhone zum Anhalten, Suchen, Anpassen der Lautstärke oder Öffnen verfügbarer aktueller Dateien.

Mac erscheint nicht?

Überprüfen Sie, ob Kinrox ausgeführt wird und die Fernsteuerung aktiviert ist. Überprüfen Sie die lokalen Netzwerkberechtigungen auf beiden Geräten. Gast-WLAN, Client-Isolation, VPNs und Firewall-Einstellungen können verhindern, dass Geräte sich gegenseitig erkennen. Probieren Sie dasselbe normale Heimnetzwerk aus und lassen Sie beide Apps beim Koppeln im Vordergrund.

Probieren Sie die Steuerung ohne Mac aus

Öffnen Sie die Einstellungen in Kinrox Remote und wählen Sie Demo ohne Mac testen. Die Demo verwendet fiktive Medien und stellt keine Verbindung zu einem echten Mac her und steuert diesen nicht. Beenden Sie die Demo in den Einstellungen, wenn Sie zum Koppeln bereit sind.

Verbindungs- oder aktuelle Dateiprobleme

Wenn die Kopplung am Mac widerrufen wurde, koppeln Sie sie erneut mit einem neuen Code. Auf dem Mac muss noch eine aktuelle Datei verfügbar sein; Verschobene oder gelöschte Dateien können nicht von der Fernbedienung aus geöffnet werden. „Nächste“ und „Vorherige“ folgen den Videodateien im aktuellen Mac-Ordner.

Kontakt

Melden Sie ein Problem oder bitten Sie um Hilfe. Geben Sie Ihre iOS- und macOS-Versionen, Kinrox-Versionen, Ihre Versuche und die Fehlermeldung an. Fügen Sie keine Pairing-Tokens, privaten Dateinamen oder andere vertrauliche Informationen hinzu. GitHub-Probleme sind öffentlich.
