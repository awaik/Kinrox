Kinrox assistance

Kinrox Remote contrôle le lecteur vidéo Kinrox sur un Mac. Il nécessite iOS 17 ou version ultérieure et un Mac compatible exécutant Kinrox. Les deux appareils doivent être sur le même réseau local. L'application iPhone ne lit ni ne diffuse de vidéos.

Connectez votre iPhone

  1. Téléchargez le lecteur Mac depuis les versions officielles, puis lancez-le.
  2. Activez le contrôle à distance dans Kinrox sur le Mac, puis ouvrez Connecter l’iPhone pour afficher un code d'association.
  3. Connectez le iPhone au même réseau local et autorisez l'accès au réseau local pour les deux applications lorsque vous y êtes invité.
  4. Sélectionnez le Mac dans Kinrox Remote et entrez le code à six chiffres affiché sur le Mac. Utilisez un nouveau code s’il a expiré.
  5. Ouvrez une vidéo locale sur le Mac. Utilisez votre iPhone pour mettre en pause, rechercher, régler le volume ou ouvrir les fichiers récents disponibles.

Mac n'apparaît pas ?

Vérifiez que Kinrox est en cours d'exécution et que le contrôle à distance est activé. Vérifiez les autorisations du réseau local sur les deux appareils. Le Wi-Fi invité, l’isolation des clients, les VPN et les paramètres de pare-feu peuvent empêcher les appareils de se découvrir. Essayez le même réseau domestique normal et gardez les deux applications au premier plan lors du couplage.

Essayez les commandes sans Mac

Ouvrez les paramètres dans Kinrox Remote et choisissez Essayer la démo sans Mac. La démo utilise des médias fictifs et ne se connecte ni ne contrôle un véritable Mac. Quittez la démo dans Paramètres lorsque vous êtes prêt à effectuer le couplage.

Problèmes de connexion ou de fichiers récents

Si l'appairage a été révoqué sur le Mac, associez-le à nouveau en utilisant un nouveau code. Un fichier récent doit toujours être disponible sur le Mac ; les fichiers déplacés ou supprimés ne peuvent pas être ouverts à partir de la télécommande. Suivant et Précédent suivent les fichiers vidéo dans le dossier Mac ​​actuel.

Contacter

Signaler un problème ou demander de l'aide. Incluez vos versions iOS et macOS, vos versions Kinrox, ce que vous avez essayé et le message d'erreur. N'incluez pas de jetons de couplage, de noms de fichiers privés ou d'autres informations sensibles. Les problèmes GitHub sont publics.
