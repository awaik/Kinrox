Politique de confidentialité

2026-11-01

Kinrox lit les vidéos locales sur Mac et propose une télécommande pour iPhone. Le développeur ne reçoit ni données personnelles, ni historique de lecture, ni statistiques d’utilisation.

Données sur vos appareils

Le lecteur Mac stocke les favoris et les préférences des fichiers récents sur votre Mac. La télécommande iPhone stocke un identifiant d'appareil aléatoire, le Mac sélectionné et les préférences de connexion sur votre iPhone. Les informations d’identification de couplage sont stockées dans le trousseau de chaque appareil. La télécommande reçoit l'état de lecture ainsi que les titres et durées des fichiers récents de votre Mac. Les chemins complets du système de fichiers et les fichiers vidéo ne sont pas transmis au iPhone.

Communication sur réseau local

Avec votre autorisation, Kinrox découvre les lecteurs utilisant Bonjour et échange des commandes de contrôle et des informations de lecture sur votre réseau local. Les sessions couplées utilisent le cryptage. Les noms de périphériques et de services sont visibles lors de la découverte du réseau local ; La découverte elle-même n’est pas une chaîne cryptée. Les applications n'utilisent pas de serveur relais exploité par le développeur.

Mac vérifications de mise à jour

À partir de la version 0.3.0, le lecteur Mac utilise Sparkle pour lire le flux de mise à jour public sur GitHub Pages une fois par jour et lorsque vous choisissez Rechercher les mises à jour. Les vérifications n'incluent pas les identifiants uniques de l'appareil, l'historique de lecture ou un profil système. Lorsque vous choisissez d'installer une mise à jour, Sparkle télécharge le programme d'installation signé à partir de GitHub Releases. GitHub peut traiter les informations demandées telles que les adresses IP dans le cadre de sa politique de confidentialité. La vidéo locale et la télécommande LAN fonctionnent hors ligne. Les mises à jour et Spotify facultatif nécessitent internet.

Spotify

La connexion est facultative. Utilisez votre propre application développeur Spotify et un compte Spotify Premium autorisé. Spotify contrôle l’accès à l’API et les quotas ; cet accès peut changer ou cesser. Les conditions de Spotify restent applicables. Le son est lu par Spotify Soloist, téléchargé directement depuis Spotify sur votre Mac à votre demande. Chaque utilisateur fournit une clé API personnelle Soloist. L’association initiale utilise Spotify sur iPhone ; la lecture fonctionne ensuite avec Spotify fermé sur Mac et iPhone. Soloist gère le décodage et son cache audio ; Kinrox n’enregistre ni n’exporte le son. Les versions de Soloist expirent après 90 jours et nécessitent une mise à jour.

Accès Spotify : bibliothèque, lecture, favoris et playlists modifiables. Retirer un favori le supprime aussi des playlists modifiables. Les identifiants restent dans le trousseau du Mac. La déconnexion efface les données locales Spotify et conserve ses playlists. Aucun serveur Kinrox ni analyse d’utilisation.

Politique de confidentialité — connexion à Spotify

Version 2026-11-03. Le mainteneur de Kinrox, awaik, est responsable des traitements de Kinrox décrits ici. Ce complément concerne l’intégration facultative de Spotify. La politique générale de confidentialité de Kinrox est disponible à l’adresse https://kinrox.app/privacy/. Contact : https://github.com/awaik/Kinrox/issues. Ne publiez pas de jetons, de contenus de votre bibliothèque personnelle ni d’autres informations privées dans les tickets publics.

Accès et finalités

Après acceptation des conditions et autorisation de Spotify, Kinrox sur Mac lit l’identifiant et le nom d’affichage de votre compte, les titres et albums enregistrés, les artistes suivis, les playlists accessibles et leur contenu, l’état de lecture et les appareils disponibles. Ces informations servent à afficher votre bibliothèque et à contrôler Spotify. Lorsque vous utilisez les commandes correspondantes, il peut ajouter et supprimer des favoris, suivre des artistes, créer des playlists et modifier les playlists dont vous êtes propriétaire ou collaborateur. Supprimer un favori supprime aussi ses occurrences dans les playlists modifiables.

Stockage et destinataires

Les identifiants de renouvellement sont stockés dans le Data Protection Keychain du Mac. Les jetons d’accès restent en mémoire. Les métadonnées de la bibliothèque sont mises en cache dans une base SQLite locale, dans le dossier Caches de l’app sur Mac. L’identifiant de compte vérifié et le nom affiché sont enregistrés dans les préférences du Mac. Le Client ID fourni, l’association de la playlist auxiliaire et la version acceptée des documents sont stockés dans les préférences du Mac. Kinrox n’a ni serveur, ni analyse d’utilisation, ni télémétrie, et son mainteneur ne reçoit aucune de ces données Spotify. Spotify reçoit les requêtes directement du Mac et les traite selon sa politique de confidentialité : https://www.spotify.com/legal/privacy-policy/. Spotify voit des informations réseau telles que l’adresse IP publique du Mac. La clé API personnelle Soloist est stockée dans le trousseau. La session Connect est conservée dans un dossier privé du compte ; Soloist utilise un cache audio distinct limité à 200 MB. La clé est transmise au processus signé Soloist dans les arguments de lancement, lisibles par les autres processus du même utilisateur. Le socket de contrôle loopback de Soloist ne vérifie ni l’authentification ni Origin ; les programmes locaux ou les pages web ayant accès au loopback peuvent envoyer des commandes de lecture.

iPhone et liens

L’iPhone jumelé reçoit les métadonnées des titres, albums, artistes et playlists, l’état de la file et les commandes de lecture via la connexion chiffrée de Kinrox sur le réseau local. Il ne reçoit jamais les identifiants Spotify et n’appelle pas la Spotify Web API. Si vous touchez Ouvrir dans Spotify, l’iPhone ou le Mac ouvre l’élément concerné dans Spotify ou sur son site web. Ce transfert peut utiliser internet et relève de la politique de confidentialité de Spotify. Les métadonnées de la télécommande sont conservées en mémoire et effacées à la déconnexion ou à la réinitialisation de la source ou du compte.

Déconnexion et conservation

Dans Kinrox sur Mac, ouvrez Réglages → Spotify → Déconnecter. Kinrox arrête son processus Soloist et les requêtes, supprime l’identifiant de renouvellement, la clé API Soloist et ses propres données de session et cache audio, puis efface les données du compte en mémoire. Les identifiants non secrets des anciennes playlists de file et le moteur téléchargé sont conservés. Il arrête la reconnexion automatique. La version acceptée est une préférence sans lien avec un compte. Les modifications déjà effectuées dans Spotify, dont les playlists et favoris, y restent. La déconnexion ne révoque pas l’autorisation dans Spotify ; supprimez l’application à l’adresse https://www.spotify.com/account/apps/ pour la révoquer. Vous pouvez supprimer les playlists auxiliaires conservées directement dans Spotify. Les métadonnées en cache expirent après 7 jours sans nouvelle validation. La déconnexion supprime automatiquement le cache SQLite, ses fichiers annexes et l’association de compte enregistrée.

Cookies et données générales de Kinrox

Kinrox n’ajoute ni analyse d’utilisation ni cookies. Ses sessions d’API Spotify n’utilisent ni cookies persistants ni cache de réponses sur disque. La connexion dans le navigateur et les sites Spotify peuvent utiliser leurs propres cookies ; gérez-les dans votre navigateur et les réglages de confidentialité de Spotify. La politique générale de Kinrox explique les signets de fichiers locaux, les identifiants de jumelage, les mises à jour Sparkle et l’hébergement GitHub. Spotify est tiers bénéficiaire de cette politique et des conditions de connexion. Toute modification substantielle de ce complément sera affichée avant l’activation d’une nouvelle connexion.

La rétention et vos choix

Les informations d'identification de couplage restent jusqu'à ce que vous les supprimiez. Utilisez Oublier dans les paramètres de l'application iPhone pour supprimer les informations d'identification enregistrées de cette Mac de iPhone. Révoquez le iPhone dans les paramètres de la télécommande du lecteur Mac pour supprimer son accès au Mac. Ces actions sont indépendantes : oublier le Mac sur l’iPhone ne révoque pas l’accès enregistré sur le Mac. Vous pouvez vider la liste des fichiers récents dans le lecteur Mac. Vous pouvez désactiver l'accès au réseau local dans les paramètres système. Les entrées du trousseau peuvent survivre à la désinstallation d'une application, utilisez donc les commandes de couplage avant la désinstallation si vous souhaitez supprimer les informations d'identification enregistrées.

Support et ce site Web

Si vous choisissez de nous contacter via GitHub Issues, les informations que vous soumettez sont traitées par GitHub dans le cadre de ses règles de confidentialité et peuvent être publiques. Ne publiez pas de jetons d'appariement, de noms de fichiers privés ou d'autres informations sensibles. Ce site Web est hébergé sur GitHub Pages ; le fournisseur d'hébergement peut traiter les informations demandées telles que les adresses IP conformément à la déclaration de confidentialité de la GitHub. Kinrox n'ajoute aucun script d'analyse ni cookie.

Contact et modifications

Pour toute question relative à la confidentialité, contactez le responsable via le Kinrox outil de suivi des problèmes. Nous mettrons à jour cette page lorsque la gestion des données des applications changera.
